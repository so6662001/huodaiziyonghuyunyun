## 三、核心战略概要

### 1. 项目定位的关键转变

| 旧定位 | 新定位 |
|------|------|
| 钢贸 B2B 撮合平台（找钢网模式） | 中小钢贸采购员的 AI 工作助手 |
| 替代主供应商 | 补充渠道（应急/特殊/小单/试探） |
| 比价工具 | 关系培育器 + 工作交付物生成器 |
| 卖家越内卷越赚（佣金/比价） | 卖家越赚平台越赚（工具/数据/服务） |

### 2. 五大战略红线（永不触碰）

1. ❌ 永不做自营货权交易
2. ❌ 永不做仓储/加工/物流自建
3. ❌ 永不抽交易佣金
4. ❌ 永不做交易补贴战
5. ❌ 永不向买家个人收费

### 3. 16 条致命阻力（攻坚清单）

| 编号 | 阻力 | 解决方案 |
|---|---|---|
| B-A3 | 买家有固定供应商 | 定位"补充渠道" |
| B-C1 | 发需求一行行填太麻烦 | 极简发需求+语音+拍照 |
| B-C2 | 清单几十行填不动 | 清单原生支持 |
| B-D1 | 不知道哪家可信 | 信用体系 |
| B-E1 | 需求变更要重发 | 采购会话+动态卡片 |
| B-E2 | 议价不如微信顺 | 还价产品化+AI 识变 |
| B-F1 | 新供应商入库流程长 | 试单场景规避大单 |
| B-F3 | 担心试单出问题 | 试单激励+平台担保 |
| B-H1 | 售后无依靠 | 24h 介入+先行赔付 |
| B-I3 | 任何付费都是阻力 | 买家端 100% 免费 |
| S-B1 | 询价党泛滥 | 三级匹配池 |
| S-B3 | 比价压利润 | 盲价匹配+综合方案 |
| S-D1 | 外地低价冲击本地 | 区域保护制 |
| S-D2 | 本地同行串谋 | 卖家委员会 |
| I-1 | 微信生态绑定 | 把平台搬进微信 |
| I-2 | 打电话仍最有效 | 做电话之后的工具 |
