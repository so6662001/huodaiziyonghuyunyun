货袋子 PC 端 UI 高保真原型 v2.6

面向 PC 大屏的完整产品原型，覆盖三端：买家（采购方）、卖家（销售方）、平台运营管理员。 v2.6 新增 9 页：卖家会话沟通/报价管理/订单发货/客户CRM，买家清单管理/订单详情/采购分析，运营申诉处理。
📐 PC 端设计原则
1. 三端分离：买家 SaaS / 卖家工作台 / 运营后台 独立侧栏与导航
2. 大屏优势：用矩阵表、多栏布局、数据看板替代移动端的卡片堆叠
3. 共享设计系统：颜色 / 字体 / 圆角 / 阴影 与移动端 token 100% 一致
4. 键盘友好：批量操作、表格编辑、快捷键 → 提升效率
5. 多规格优先：所有交互默认按"清单 + 规格行"组织，单条只是 N=1 的退化

📱 与移动端的关系

PC 端与移动端共享同一套：

  • ✅ 后端 API（docs/08-技术交付物/api/openapi.yaml）
  • ✅ 数据库 DDL（docs/08-技术交付物/db/01-schema.sql）
  • ✅ 设计 token（颜色 / 字体 / 圆角 / 阴影）
  • ✅ 业务模型（DemandCard 多规格、Result<T> 响应、ErrorCode 错误码）

差异在 布局密度与交互效率：

  • 📱 移动端：单列、卡片堆叠、大字大按钮、触摸友好
  • 💻 PC 端：多栏、表格密集、键盘+鼠标、批量操作、大屏数据看板
