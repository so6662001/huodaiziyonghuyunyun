# PC 端 UI 高保真原型

> 货袋子 PC 端原型，覆盖买家 / 卖家 / 平台运营三端核心场景。
> **与 H5 移动端共享同一套后端 API、数据库、设计 token**。

```

│

│   ├── 01-dashboard.html            采购工作台（KPI + 询价 + 趋势）

│   └── 05-供应商管理.html           私有 CRM
```

## 设计原则

### 1. 三端独立侧栏

| 端 | 侧栏主色 | 用户角色 | 典型场景 |
|---|---|---|---|
| 买家 | 蓝色 #2563eb | 采购员、采购经理 | 大客户日常采购、批量询价、报表分析 |
| 卖家 | 金色 #d4a73a | 销售经理、老板 | 库存管理、报价、客户管理、利润分析 |
| 运营 | 红色 #ef4444 | 风控/客服/管理员 | 风控、审计、用户管理、数据看板 |

### 2. 大屏优势利用

```
移动端                        PC 端
─────────────              ─────────────
单列卡片堆叠                多栏并排布局
触摸大按钮                  键盘+鼠标
单条信息展示                表格/矩阵密集展示
逐行查看                    批量操作
─────────────              ─────────────

举例：
  报价对比
  移动端：单卖家详情卡片，需切换 17 次
  PC 端：17 卖家 × 8 行的完整矩阵一屏看全
```

### 3. 与 H5 共享设计系统

```css
/* PC 端 styles-pc.css 引用相同 token */
:root {
  --primary: #2563eb;        /* 同移动端 */
  --gold: #d4a73a;           /* 同移动端 */
  --warning: #f59e0b;        /* 同移动端 */
  /* ... */

  /* PC 端独有布局变量 */
  --sidebar-width: 220px;
  --header-height: 56px;
}
```

### 4. 多规格作为默认场景

所有页面都按"清单 + 规格行"组织，与移动端 v2.1 保持一致。
单条规格只是 `items.length === 1` 的退化情况。

## 关键页面说明

### 买家端 04-报价对比矩阵.html（PC 独占）

这是 PC 端最具差异化价值的页面。在移动端只能展示按行的简化矩阵，
PC 大屏可以一屏看全 **17 家卖家 × 8 行规格** 的完整报价：

- **横轴**：17 家卖家（含信用、距离、综合分）
- **纵轴**：8 行规格 + 汇总行（小计、综合分）
- **单元格**：报价金额，金色 = 最低价，绿色 = 次优
- **底部**：AI 最优组合（3 家分单方案，省 ¥18,400）
- **备选**：4 种方案对比表

### 买家端 03-采购会话详情.html（三栏）

```
┌──────────────┬────────────────────┬──────────────┐
│ 清单进展      │ 选中行的报价对比     │ 时间线         │
│ (8 行状态)    │ + 沟通记录          │ + 市场参考价   │
│              │                     │ + 卖家列表     │
└──────────────┴────────────────────┴──────────────┘
```

### 卖家端 02-询价中心.html（处理页）

PC 端卖家最高频的操作场景：

- 左侧：买家信息 + 8 行规格清单（按现货/部分/无货分色）
- 右侧：批量调价 + 利润预估 + S 级盲价透视
- 底部固定：勾选 5/8 行、总金额、利润、提交报价

## 使用方式

```bash
# 直接用浏览器打开（任何静态文件方式）
open docs/08-技术交付物/ui-prototype-pc/index.html

# 或起本地服务（推荐）
cd docs/08-技术交付物/ui-prototype-pc
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 与其他交付物的关系

- 后端 API：与移动端共享，无需新增接口
- 数据库：与移动端共享，无需新增表
- 设计 Token：与移动端 100% 一致
- 设计规范：见 `docs/13-Figma设计规范/`
- 移动端原型：见 `docs/08-技术交付物/ui-prototype/`
