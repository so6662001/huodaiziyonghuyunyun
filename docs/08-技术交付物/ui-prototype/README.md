# UI 高保真原型

## 文件

- `index.html` — 原型导航首页
- `01-发需求.html` — M2 极简发需求页
- `02-清单上传.html` — M3 清单 5 种上传方式
- `03-采购会话.html` — M2 聚合看板 + AI 识变 + 时间线
- `04-卖家接单.html` — M5 卖家端接单 + 变更响应
- `05-报价配置器.html` — M4 6 维方案配置器
- `06-清单确认.html` — M3 AI 解析极简确认
- `styles.css` — 公共样式（钢贸蓝灰风 + 暖色 CTA）

## 原型规则

1. **不实现交互**：纯展示型，按钮点击无效果
2. **真实数据感**：使用真实业务字段、卖家名、价格
3. **移动优先**：所有原型 414px 宽度内可读
4. **桌面适配**：自动居中，模拟手机外观

## 设计要点说明

### 01-发需求

- 顶部"快速发起"4 个入口（语音/拍照/清单/复制上次）
- 中部"我的常用需求"——核心：让老用户 3 秒发需求
- 表单极简化：5 个必填字段
- 加速档位独立卡片，可选不强制

### 02-清单上传

- 主上传区"📷 拍照"作为视觉焦点
- 4 种次选方式平铺
- 精确/模糊询价模式选择
- 历史清单一键复用

### 03-采购会话

- **动态需求卡片**作为顶部蓝色卡片，永远可见
- **AI 识变确认条**紫色高亮，强吸引力
- **Top 3 报价**金色突出 #1，其他 #2/#3 标准展示
- **不显示卖家真名**，匿名"优选 卖家 A"（盲价）
- **报价展示综合方案**（含运/账期/交期）而非单一价格
- 底部时间线带状态点

### 04-卖家接单

- **买家信息**顶部展示，含信用分 + 历史 + 标签
- **池子标签**「🟡 优质池」明显
- **变更通知**橙色边框，提供 4 个响应按钮
- **阶梯定价**鼓励填写（提示提高匹配度）
- **利润保护**绿色提示市场参考价

### 05-报价配置器

- 卖家卡片金色背景（S 级特殊待遇）
- 数量选择 chip 形式，带价格 delta
- 加项可勾选，已选项目蓝色高亮
- 实时计算总价 + 明细展开
- 服务标签清晰展示

### 06-清单确认

- AI 解析结果顶部统计（21 已确认/2 需确认/23 合计）
- **只展示不确定行**，21 行已确认折叠（关键设计：不让用户逐行看）
- 智能拆单预览（让用户理解平台价值）
- 一键"全部正确"按钮显眼
