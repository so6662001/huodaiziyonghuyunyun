使用说明

  • 所有原型以移动端为基础（414px 宽度），桌面端展示为居中卡片
  • 点击页面元素无真实交互（这是设计原型，非可运行 demo）
  • 用 Chrome 开发者工具切换到 iPhone 模拟可获得最佳预览
  • 原型展示的内容、数字、卖家姓名均为示例数据
  • 颜色规范：主色 #2563eb（蓝），辅色 #d4a73a（金），告警 #f59e0b（橙）
