## 使用方式（按角色）

### 前端工程师

1. 看 `ui-prototype/`，理解 UI 设计语言
2. 看 `api/openapi.yaml`，生成 TypeScript SDK
3. 看自己负责模块的 PRD（`docs/07-产品PRD-v2/`）

### 后端工程师

1. 看 `db/01-schema.sql`，建库
2. 看 `api/openapi.yaml`，实现接口
3. 看 PRD 和测试用例对照开发

### AI 工程师

1. 看 PRD M2（AI 识变）+ M3（OCR+LLM 解析）
2. 看 `test-cases/02-集成测试.yaml` 中 AI 用例
3. 看 `ops/03-监控告警.md` 中 AI 服务监控

### 测试工程师

1. 看 `test-cases/00-测试策略.md`
2. 看 `test-cases/02-集成测试.yaml`
3. 看 `test-cases/03-E2E用例.yaml`
4. 看 `test-cases/04-性能与安全.md`

### 运维 / SRE

1. 看 `ops/01-部署架构.md`
2. 看 `ops/02-CICD流程.md`
3. 看 `ops/03-监控告警.md`
4. 看 `ops/04-灾备方案.md`
5. 看 `ops/05-应急响应.md` 至少 3 遍（值班必读）

### 产品经理

1. 看 `ui-prototype/`，确认设计
2. 看 `api/openapi.yaml`，对齐接口
3. 看 `test-cases/05-验收清单.md`
