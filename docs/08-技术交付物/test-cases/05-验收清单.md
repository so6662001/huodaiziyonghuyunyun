# 上线验收清单

> 每次大版本发布前必须 100% 完成此清单。

## 一、功能验收

### V1 MVP 必须通过的 11 个核心闭环

- [ ] BC-01 新用户注册 → 营业执照认证 → 试水池
- [ ] BC-02 买家发需求 → 派单 → 卖家报价 → 联系
- [ ] BC-03 需求变更 → 卡片新版本 → 全员同步
- [ ] BC-04 AI 识变 → 弹确认 → 卡片更新
- [ ] BC-05 清单上传 → OCR+LLM 解析 → 确认 → 拆单
- [ ] BC-06 多卖家部分应答 → 最优组合算法 → 选方案
- [ ] BC-07 报价 6 维方案 → 配置器实时算价 → 还价
- [ ] BC-08 卖家流量费充值 → 扣费 → 申诉 → 退款
- [ ] BC-09 卖家会员升级 → 权益变化 → 续费
- [ ] BC-10 风控规则触发 → 处置 → 申诉 → 委员会复审
- [ ] BC-11 微信端发需求 → 跨端同步 → 桌面端查看

- [ ] 聚合视图 P95 < 1s

## 三、安全验收

- [ ] 注入：参数化查询全覆盖
