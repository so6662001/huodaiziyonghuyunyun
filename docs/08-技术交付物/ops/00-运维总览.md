# 货袋子平台运维手册总览

## 一、运维目标

- **可用性 SLA**：99.5%（每月停机 < 3.6 小时）
- **RTO**（故障恢复时间）：< 1h
- **RPO**（数据丢失容忍）：< 1h
- **P95 延迟**：达 PRD 基线
- **故障响应**：P0 故障 5 分钟内 ack，1h 内恢复

## 六、值班制度

```
工作时间（9:00-18:00）：
  全员在岗，分模块负责

非工作时间：
  SRE 7×24h 轮值（含周末/节假日）
  P0 故障：电话呼叫值班 SRE + 自动 escalation

应急响应群：
  - 企微"运维应急"群
  - 钉钉"故障作战"群
  - P0 故障必拉 CEO + CTO + 相关 VP
```

## 七、变更管理

```
变更窗口：
  ✅ 常规变更：工作日 10:00-16:00
  ✅ 紧急变更：随时（需 CTO 批准）
  ❌ 周五下午 / 周末 / 节假日不发版

变更评审：
  小版本：CTO + 产品总监 + 测试总监三方签字
  大版本：CEO + 所有 VP 签字
  重大架构变更：董事会批准

回滚预案：
  每次变更必须有回滚方案
  回滚时间 < 5 分钟（功能开关）
  数据迁移类变更必须可逆
```
