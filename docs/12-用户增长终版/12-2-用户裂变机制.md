# 用户裂变机制详细设计

> 5 大裂变机制，按资金约束精细设计。
> **核心原则**：单家邀请奖励严控，不靠补贴换增长。

## 一、5 大裂变机制概览

| # | 机制 | Y1 预算 | 预期产出 | LTV/CAC |
|---|---|---|---|---|
| **A** | 卖家邀请买家（核心） | ¥30 万 | 200 家 M4 + 1000 家 M1-M3 | 34x |
| **B** | 买家邀请买家 | ¥10 万 | 400 家新买家 | 6x |
| **C** | 内测合伙人推荐 | ¥10 万（从 A 中划） | 90 家高质量卖家 | 9-36x |
| **D** | 群主带群 | ¥15 万（从群运营中划） | 4000 家新买家 | 50x |
| **E** | KOL 引荐 | ¥5 万 | 30-50 家卖家+买家 | 难量化 |

**总预算**：¥30 + ¥10 + ¥15 + ¥5 = **¥60 万**（占用户增长总预算 40%）

## 二、裂变机制 A：卖家邀请买家（核心）

### 2.1 5 级里程碑（务实版重新校准）

| 里程碑 | 卖家奖励 | 买家奖励 | 触发条件 |
|---|---|---|---|
| M1 注册 | ¥20 | ¥30（运费券） | 营业执照认证 |
| M2 首发需求 | ¥30 | ¥20（积分） | 7 日内首次询盘 |
| M3 有效互动 | ¥80 | / | 14 日内 ≥ 3 次沟通 |
| M4 首单成交 | ¥200 | ¥150（券） | 30 日内 ≥ ¥5 万 |
| M5 月活买家 | ¥120/月 × 3 | 优质认证 | 次月活跃 |
| **总价值** | **¥690** | **¥200** | / |

**vs 旧版 ¥1080 → 调整为 ¥690（-36%）**

### 2.2 ROI 测算

```
单 M4 完整买家：
  - 卖家奖励：¥690
  - 买家奖励：¥200
  - 单买家 CAC：¥890
  - 单买家 LTV：¥30,000
  - LTV/CAC = 34x ✅

Y1 预算 ¥30 万：
  - 完整 M4 转化：¥30 万 / ¥890 = 337 家上限
  - 实际：约 200 家 M4 + 1000 家 M1-M3 = 1200 家累计触达
  - 间接拉来卖家：约 150 家（买家拉新卖家）
```

### 2.3 反作弊规则（必读）

```
单卖家月度激励上限：¥3000
单卖家年度激励上限：¥30000
超过上限部分不发

反作弊检查（结算前必跑）：
R1 邀请人和被邀请人法人同源 → 作废
R2 同设备 ID 注册 → 作废
R3 同 IP 段 24h 内注册 → 人工审核
R4 被邀请人 7 日内仅有"激活动作"无自主活动 → 作废
R5 邀请关系 3 层以上同 IP → 全链作废
R6 单卖家邀请买家 >60% 只跟该卖家成交 → 减半激励
```

### 2.4 提现规则

```
单次提现 ≥ ¥100 起
单月累计 ≤ ¥5000：自动
单月 ¥5000-¥10000：风控审核
单月 > ¥10000：财务+风控双审

到账：提现到对应营业执照法人账户
```

### 2.5 配套工具

```
每个卖家有专属：
  - 邀请二维码
  - 邀请短链 https://hdz.com/i/XXX
  - 跳转专属落地页（"XX 公司李总邀请你"）

后台看板：
  - 我邀请的（实时）
  - 各里程碑达成数
  - 奖励金额
  - 提现入口
  - 全平台排行榜（季度）
```

### 2.6 关键节奏

```
M2：机制上线，30 家种子内测
M3-M5：灰度放开，监控反作弊
M6：全网放开
M9：双 11 大促裂变（激励翻倍 1 个月）
M12：年终奖励发放
```

## 三、裂变机制 B：买家邀请买家

### 3.1 设计

```
买家 A 邀请同行买家 B：
  B 完成首单成交：
    - A 获得：¥100 运费券
    - B 获得：¥150 运费券（首单礼）

总成本：¥250/双向
单买家 CAC：¥250
LTV/CAC = 6x（合格）
```

### 3.2 ROI 测算

```
Y1 预算 ¥10 万：
  完整裂变：¥10 万 / ¥250 = 400 双向
  实际新增买家：约 400 家

间接产出：
  - 同行采购员之间的口碑（强关系传播）
  - 买家 NPS 提升
```

### 3.3 关键限制

```
单买家月度邀请上限：5 家（防刷）
邀请人 + 被邀请人不能：
  - 同公司
  - 同手机号根（前 7 位匹配）
  - 同 IP 段 24h 内

仅在 M6 后启动（成熟期）
```

## 四、裂变机制 C：内测合伙人推荐

### 4.1 设计（高质量裂变）

```
30 家 A 类商家作为"内测合伙人"，
推荐其他卖家入驻：

  推荐成功（认证+发首条库存）：¥500
  推荐成功（30 天内成交≥1 单）：¥1500（含上一档）
  
单卖家 CAC：¥500-2000
LTV/CAC = 9-36x
```

### 4.2 ROI 测算

```
30 个内测合伙人 × 3 家推荐 = 90 家新卖家

预算：¥10 万
  - 30 家 × ¥1500 平均 = ¥4.5 万（推荐奖励）
  - 其他 90 - 30 = 60 家轻量奖励 = ¥3 万
  - 内测合伙人活动/年会：¥2.5 万

ROI 极佳：
  90 家新卖家 LTV：90 × ¥18000 = ¥162 万
  ROI = 16x
```

### 4.3 内测合伙人专属权益

```
✅ 黑金会员免费 6 个月
✅ 50 条免费询价线索
✅ 后续询价 5 折（限 60 天）
✅ 优先派单
✅ 进入卖家委员会候选
✅ 平台股权激励池
✅ 每季度闭门会议（含家属年会）
```

### 4.4 启动时点

```
M3：30 家内测合伙人签约
M4-M12：持续推荐期
M12：年会 + 评选下一届
```

## 五、裂变机制 D：群主带群

### 5.1 设计

```
现有群主介绍新群进入"货袋子矩阵"：

  新群入驻：¥200 / 群（一次性）
  新群活跃 30 天：¥300 / 群（保留奖）
  新群成员入驻平台：¥10 / 人（封顶 ¥500/群）

单群成本：约 ¥1000
预期单群带来买家：30-50 家
单买家 CAC：¥20-33（极低）
```

### 5.2 ROI 测算

```
Y1 预算 ¥15 万：
  扩张到：3500-5000 群（从 2000）
  
新群预期：约 1500 个新群
每群平均带来：3 家有效买家
新增买家：约 4500 家

CAC：¥15 万 / 4500 = ¥33/家
LTV/CAC = ¥1500 / ¥33 = 45x ⭐⭐⭐⭐⭐
```

### 5.3 群主激励层级

```
普通群主（带 1 群）：¥200-300
活跃群主（带 5+ 群）：¥1000-2000 + 排行榜
头部群主（带 20+ 群）：¥5000+ + 平台合作 + 现金奖
```

### 5.4 群质量监控

```
每个新群 30 天健康度检查：
  - 人数 ≥ 50：标准
  - 日均发言 ≥ 5：合格
  - 实名认证用户 ≥ 60%：必要

不达标的群：
  - 减半激励
  - 30 天后再评估
  - 6 个月后清退（保留人但不奖励）
```

## 六、裂变机制 E：KOL 引荐

### 6.1 目标 KOL

```
钢贸圈 KOL：
  - 钢贸论坛 / 网站活跃作者
  - 抖音/视频号钢贸大 V
  - 行业媒体记者
  - 资深从业者

预期 5-10 个 KOL
```

### 6.2 合作模式

```
模式 A：内容合作 + 引荐
  - KOL 撰写货袋子使用心得
  - 在自有渠道推荐
  - 按引流量付费

模式 B：实名引荐
  - KOL 实名推荐卖家入驻
  - 推荐 1 家卖家：¥1000
  - 推荐 1 家活跃买家：¥100

模式 C：年度合作
  - 签订年度合作协议
  - 月固定费 ¥3000-8000
  - 含内容产出 + 引荐
```

### 6.3 预算分配（¥5 万）

```
5 个 KOL × ¥10000 = ¥5 万

包括：
  - 内容合作 ¥1 万
  - 引荐激励 ¥2 万
  - 年度合作 ¥1.5 万
  - 应急/拓展 ¥0.5 万
```

### 6.4 预期产出

```
30-50 家高质量卖家（KOL 背书带来的信任度）
+ 大量行业口碑（难量化但重要）
```

## 八、关键执行原则

### 1. 严控反作弊

```
所有 5 个机制都有反作弊规则
每月 1 次审查
误伤率 < 8%，漏判率 < 5%
```

### 2. 数据驱动调整

```
每月对账：
  - 各机制实际 CAC vs 计划
  - LTV/CAC 偏离预期 → 调整
  - 砍掉 ROI < 5x 的渠道
```

### 3. 不烧钱换增长

```
单机制月度预算上限：¥10 万
超过即开会评估
"砸钱拉新"是死路
```

### 4. 长期主义

```
裂变机制是长期工程
不要追求月度增长曲线
追求"卖家粘性 + 买家复购"
```
