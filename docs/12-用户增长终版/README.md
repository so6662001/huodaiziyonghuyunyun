## 关键原则（5 条，CEO 上墙）

### 1. 预算严控
¥150 万是上限，不是目标。每月超支 20% 立即降速。

### 2. 优先级清晰
卖家增长靠地推+反向邀请，买家增长靠群运营+反向邀请+内容。
不要"卖家买家平均分"。

### 3. 数据每周看
渠道 ROI 看板。红色立即处置，黄色月底复盘。

### 4. 留余地
建议 ¥130 万作为常规预算，留 ¥20 万应急。

### 5. 知道何时止损
- 实际 vs 计划 < 50% → 警告
- 累计 CAC > 计划 +30% → 启动 B 计划
- 资金跑道 < 4 月 → 启动 C 计划

## 使用方式

### CEO
1. 看 `12-1` 心里有数（资金分配 + 应急预案）
2. 每月 1 号 review `渠道ROI计算器.xlsx`
3. 触发 B/C 计划时立即开会

### CMO/COO
1. 用 `12-3` 排每月具体动作
2. 每周对账渠道 ROI
3. 调整预算分配

### CFO
1. 用 `渠道ROI计算器.xlsx` 监控
2. 与 `docs/11-务实版财务测算` 联动
3. 月报含 ROI 监控部分

1. 按 `12-3` 月度行动清单执行
2. 每周一向 COO 汇报数据
3. 触发红色预警立即上报
