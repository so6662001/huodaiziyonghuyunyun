# 12 个月行动清单（每月做什么）

> **目的**：把 ¥150 万预算 + 5 大引擎 + 5 大裂变机制，拆到具体动作。
> **节奏**：每月一次复盘 + 调整。

## 总览

| 阶段 | 周期 | 月均预算 | 累计预算 | 重点 |
|---|---|---|---|---|
| Phase 1 准备期 | M0-M2 | ¥3-5 万 | ¥10 万 | 搭建基础 |
| Phase 2 试点期 | M3-M5 | ¥10 万 | ¥40 万 | 双引擎验证 |
| Phase 3 放量期 | M6-M8 | ¥15 万 | ¥85 万 | 5 大引擎齐发 |
| Phase 4 加速期 | M9-M12 | ¥16 万 | ¥150 万 | 跨区域扩张 |

## 关键提醒

```
1. 不要超支
   ¥150 万是上限，月超支立即降速

2. 不要平均分配
   把钱给 ROI 高的渠道

3. 不要追求月度增长
   追求"卖家粘性 + 买家复购"

4. 不要忘记客户成功
   1 对 1 触达是隐藏引擎

5. 不要心存幻想
   数据没达成 → 立即触发 B/C 计划
```
