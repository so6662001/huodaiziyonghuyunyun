# 用户增长运营方案（资金约束版）

> **最终版**：基于精细务实版财务约束（Y1 预算 ¥150 万）的可执行用户增长方案。

## 一、核心约束（必须先看）

### 1.1 可投入资金

| 项 | 金额 | 占比 |
|---|---|---|
| 用户增长总预算（Y1） | **¥150 万** | 占总成本 22% |
| 启动金贡献 | ¥80 万 | M0-M6 |
| Pre-A 贡献 | ¥70 万 | M7-M12 |

**这是天花板。超出意味着资金链断裂。**

### 1.2 目标（务实精细版）

| 目标 | M12 累计 | Y1 新增 |
|---|---|---|
| 活跃付费卖家 | 854 家 | **+700 家** |
| 月活买家 | 12000-15000 家 | **+12000 家** |

### 1.3 CAC 上限（核心红线）

```
卖家 CAC：¥150 万 × 60% / 700 = ¥1286/家
买家 CAC：¥150 万 × 40% / 12000 = ¥50/家
```

**任何渠道单 CAC 超过此线 → 立即砍掉**

### 1.4 LTV/CAC 健康线

```
卖家 LTV：¥18000  /  CAC ≤ ¥1286  →  LTV/CAC ≥ 14x ✅
买家 LTV：¥1500   /  CAC ≤ ¥50    →  LTV/CAC ≥ 30x ✅
```

## 五、关键认知

### 1. 增长靠机制，不靠烧钱

```
找钢网当年：¥3 亿换 2400 家卖家（CAC ¥12.5 万/家）
我们：¥150 万换 700 家卖家（CAC ¥2143/家）

差异：60 倍

靠：
  - 反向邀请（卖家拉卖家）
  - 群运营（2000 群存量）
  - 内测合伙人（30 家深度参与）
  - 区域深耕（不全国摊大饼）
```

### 2. 5 大引擎不平均分

```
预期 ROI 排序：
  1. 反向邀请 ⭐⭐⭐⭐⭐
  2. 群运营 ⭐⭐⭐⭐⭐
  3. 内容+短视频 ⭐⭐⭐⭐
  4. 区域地推 ⭐⭐⭐⭐
  5. PR+活动 ⭐⭐⭐

→ 50% 预算给前 2 个引擎
→ 35% 给中间 2 个
→ 15% 给 PR/品牌
```

### 3. 钱不够时砍什么

```
砍的顺序：
  1. PR+活动（最先砍）
  2. 内容+短视频（次之）
  3. 区域地推（再次）
  4. 群运营（不能砍，靠人力）
  5. 反向邀请（最后砍，因为 ROI 最高）

B 计划：砍 PR+内容+地推
C 计划：只保反向邀请 + 最小群运营
```

### 4. 客户成功是隐藏引擎

```
客户成功（已在人员成本，不在 ¥150 万）：
  - 1 对 1 触达
  - 流失防止
  - 老客户复购
  - 转介绍

贡献至少 30% 的"实际新增"
→ 不要砍客户成功
```

## 九、5 条核心建议

### 1. 预算严控

```
¥150 万是上限，不是目标
能少花就少花
每月对账，超支 20% 立即降速
```

### 2. 优先级清晰

```
卖家增长靠地推 + 反向邀请
买家增长靠群运营 + 反向邀请 + 内容
不要"卖家买家平均分"
```

### 3. 数据每周看

```
渠道 ROI 看板
- 每周一 09:00 review
- 红色立即处置
```

### 4. 留余地

```
¥150 万总预算
建议 ¥130 万作为常规预算
留 ¥20 万作为应急/抓住机会
```

### 5. 知道何时止损

```
每月 1 号财务月报：
  - 实际 vs 计划增长 < 50% → 警告
  - 累计 CAC > 计划 +30% → 启动 B 计划
  - 资金跑道 < 4 月 → 启动 C 计划

按数据说话，不要心存幻想。
```
