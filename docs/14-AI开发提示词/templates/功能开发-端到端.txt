## Stage 4：后端实现

按以下顺序：
1. Entity（com.huodaizi.xxx.entity.XxxEntity）
2. Mapper（继承 BaseMapper）
3. DTO（XxxRequest / XxxResponse / XxxDTO）
4. Converter（MapStruct）
5. Service 接口 + Impl
6. Controller
7. 单元测试 + 集成测试

要求：
✓ 字段名与 DDL 一致
✓ 用 Result<T> + ErrorCode
✓ @SaCheckLogin 鉴权
✓ @Transactional 事务
✓ 关键路径 log.info
✓ 多规格场景按行处理

## Stage 5：前端实现（双端）

### 5.1 移动端
对应原型：ui-prototype/[xx].html
- 严格按原型还原
- 用 phone-frame + tab-bar
- 严格用 styles.css token

### 5.2 PC 端
对应原型：ui-prototype-pc/[xx].html
- 用 sidebar + main 布局
- 严格用 styles-pc.css token

### 5.3 端一致性
- 字段名一致
- 状态值一致
- 文案一致
- 业务规则一致

### 6.2 集成测试
