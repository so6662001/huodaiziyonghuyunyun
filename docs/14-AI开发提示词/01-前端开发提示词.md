# 01 - 前端开发提示词

> **适用**：微信小程序（uni-app）、H5、PC 后台

## 一、前端通用提示词

```text
# 前端开发约束补充

## 技术栈
- 框架：uni-app（Vue 3 Composition API）
- 状态：Pinia
- HTTP：axios（或 uni.request 封装）
- UI 组件库：uView Plus / Vant Weapp（小程序优先）
- 构建：Vite

## 目录结构（必须遵循）
src/
├── api/                    # API 调用层（一个 module 一个文件）
│   ├── user.js
│   ├── session.js
│   └── ...
├── components/             # 通用组件
│   ├── basic/              # 基础组件（按钮/输入/卡片）
│   └── business/           # 业务组件（询价卡/报价卡）
├── composables/            # 组合函数 useXxx
├── pages/                  # 页面
│   ├── buyer/              # 买家端
│   ├── seller/             # 卖家端
│   └── common/             # 通用
├── stores/                 # Pinia stores
├── styles/                 # 全局样式
│   ├── tokens.scss         # ⭐ 从 design-tokens 导入
│   ├── mixins.scss
│   └── reset.scss
├── utils/                  # 工具
│   ├── request.js          # ⭐ HTTP 封装
│   ├── auth.js
│   └── format.js
└── App.vue / main.js / pages.json

## 设计规范引用（强制）
- 颜色：必须使用 @import "@/styles/tokens.scss" 中定义的变量
- 字号：最小 12px，正文 15px，标题 18/22px
- 按钮：最小 44pt
- 圆角：参考 docs/13-Figma设计规范/components/01-基础组件.md
- 间距：4 的倍数（4/8/12/16/20/24/32）

## 代码规范

### 命名
- 文件名：kebab-case（如 demand-card.vue）
- 组件名：PascalCase（如 DemandCard）
- 变量/函数：camelCase
- 常量：UPPER_SNAKE_CASE
- 事件：on-xxx（emit 时用 update:xxx 表示双向）

### 组件
- 单文件组件 .vue
- 必须 <script setup lang="ts">（如果项目支持 TS）
- 必须 props 写完整类型 + 默认值
- 必须 emit 写完整类型
- 父子传递：props down, events up
- 跨层级共享：用 store

### 样式
- 优先 SCSS
- 必须 scoped
- 严禁内联 style="..." 写复杂样式
- 严禁硬编码颜色（必须用 token）
- 严禁字号 < 12px

### API 调用
- 必须走 utils/request.js 封装
- 必须放在 api/[module].js
- 必须返回 Promise
- 错误统一在拦截器处理

## 必须支持的能力

1. 全局 loading（操作中显示）
2. 错误 toast（API 失败统一提示）
3. 网络异常重试（用户钢贸网络差）
4. 表单防双击（避免重复提交）
5. 大输入框中文输入法兼容
6. 长列表虚拟滚动（> 50 条用 virtual-list）
7. 图片懒加载
8. 骨架屏（首屏 / 列表）
9. 下拉刷新 + 上拉加载更多
10. 错误回收（页面崩溃自动回首页）

## 钢贸用户体验红线

1. 必须支持「保存草稿」（输入到一半网络断了不能丢）
2. 必须支持「上次填的字段自动带出」
3. 关键操作必须二次确认弹窗
4. 输入数量后自动算总价
5. 严禁默认勾选「订阅/同意会员」
6. 严禁过度动画（钢贸老板讨厌花哨）
7. 错误提示要说人话（"网络不好，请重试" 而非 "ERR_CONNECTION_REFUSED"）
```

## 三、API 封装规范

要求 AI 严格按以下模板实现：

```javascript
// src/api/session.js
import request from '@/utils/request'

/**
 * 创建采购会话
 * @param {Object} data - 会话数据
 * @param {Array} data.items - 需求明细
 * @param {Object} data.deliveryInfo - 送货信息
 * @param {string} data.priority - standard/urgent/bounty
 * @returns {Promise<Session>}
 */
export const createSession = (data) => request({
  url: '/api/v1/sessions',
  method: 'POST',
  data
})

export const getSession = (sessionId) => request({
  url: `/api/v1/sessions/${sessionId}`,
  method: 'GET'
})

export const sendMessage = (sessionId, data) => request({
  url: `/api/v1/sessions/${sessionId}/messages`,
  method: 'POST',
  data
})

export const closeSession = (sessionId, reason) => request({
  url: `/api/v1/sessions/${sessionId}/close`,
  method: 'POST',
  data: { reason }
})
```

## 五、Store 开发模板

```javascript
// src/stores/session.js
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { createSession, getSession, sendMessage } from '@/api/session'

export const useSessionStore = defineStore('session', () => {
  const sessions = ref([])
  const currentSession = ref(null)
  const loading = ref(false)
  const error = ref(null)

  const activeSessions = computed(() =>
    sessions.value.filter(s => s.status === 'active' || s.status === 'matching')
  )

  async function fetchSession(sessionId) {
    loading.value = true
    error.value = null
    try {
      const res = await getSession(sessionId)
      currentSession.value = res.data
      return res.data
    } catch (e) {
      error.value = e.message
      throw e
    } finally {
      loading.value = false
    }
  }

  async function create(data) {
    loading.value = true
    try {
      const res = await createSession(data)
      sessions.value.unshift(res.data)
      return res.data
    } finally {
      loading.value = false
    }
  }

  return {
    sessions,
    currentSession,
    loading,
    error,
    activeSessions,
    fetchSession,
    create
  }
})
```
