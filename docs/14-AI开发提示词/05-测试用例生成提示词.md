# 05 - 测试用例生成提示词

> **用途**：让 AI 自动产出高质量测试用例。
> **目标**：测试覆盖率 ≥ 80%，关键路径 100%。

---

## 一、测试通用提示词

```text
# 测试约束

## 测试金字塔

```
        ┌─────────┐
        │   E2E   │  10%  慢、贵、高价值
        └─────────┘
       ┌───────────┐
       │ 集成测试  │  30%  中速、关键
       └───────────┘
      ┌─────────────┐
      │  单元测试   │  60%  快、廉价、基础
      └─────────────┘
```

## 测试覆盖目标

- 整体覆盖率 ≥ 80%
- 核心 Service 方法 ≥ 90%
- Controller 100%（每个接口必有测试）
- 异常路径 100%（每个 throw 必有测试）

## 工具栈

### Java
- JUnit 5
- Mockito 5
- AssertJ（断言）
- MockMvc（Controller 测试）
- @SpringBootTest（集成测试）
- Testcontainers（数据库 / Redis 真实容器）

### 前端
- Vitest（Vue 单元测试）
- Vue Test Utils
- Cypress / Playwright（E2E）

## 测试命名

```java
// Java
@Test
@DisplayName("创建会话 - 数量超过 100 时抛 INVALID_PARAM")
void createSession_whenItemsExceed100_throwInvalidParam() { ... }

// 前端
test('renders error message when API fails', () => { ... })
```

格式：`方法名_条件_期望`

## 测试结构（AAA）

```java
@Test
void test() {
    // Arrange（准备）
    User user = buildUser();
    when(userMapper.selectById("u_001")).thenReturn(user);

    // Act（执行）
    UserDTO result = userService.getUser("u_001");

    // Assert（断言）
    assertThat(result).isNotNull();
    assertThat(result.getUserId()).isEqualTo("u_001");
    verify(userMapper).selectById("u_001");
}
```

## 禁止的反模式

```
❌ 测试中调用真实外部 API
❌ 测试依赖网络
❌ 测试依赖时间（用 Clock 或 mock）
❌ 测试依赖顺序（每个独立）
❌ 测试使用 @Disabled 跳过
❌ 测试中 Thread.sleep
❌ 测试只跑 happy path
❌ 测试不断言
```

## 二、单元测试提示词

```text
任务：为 [ClassName] 生成单元测试

## 必须覆盖的场景

### 1. 正常路径
- 标准输入 → 标准输出

### 2. 异常路径（每个 throw 必测）
- 抛 INVALID_PARAM
- 抛 NOT_FOUND
- 抛 UNAUTHORIZED
- 抛 FORBIDDEN
- ......

### 3. 边界
- null 输入
- 空集合 / 空字符串
- 最大值 / 最小值
- 1 / 0 / -1
- 长字符串
- 特殊字符（emoji / 中英文混合）

### 4. 依赖失败
- DB 查询返回 null
- DB 抛异常
- Redis 不可用
- 远程服务超时
- 远程服务返回错误

### 5. 并发（如有）
- 并发同时调用
- 重复提交（幂等）

## 模板

```java
@ExtendWith(MockitoExtension.class)
class PurchaseSessionServiceImplTest {

    @InjectMocks
    private PurchaseSessionServiceImpl sessionService;

    @Mock
    private PurchaseSessionMapper sessionMapper;

    @Mock
    private DemandCardMapper cardMapper;

    @Mock
    private AIIntentService aiIntentService;

    // ============ createSession ============

    @Test
    @DisplayName("创建会话 - 正常 - 应成功创建并返回 sessionId")
    void createSession_normal() {
        // Arrange
        String buyerId = "u_001";
        CreateSessionRequest request = buildValidRequest();
        when(sessionMapper.insert(any())).thenReturn(1);
        when(cardMapper.insert(any())).thenReturn(1);

        // Act
        PurchaseSession result = sessionService.createSession(buyerId, request);

        // Assert
        assertThat(result).isNotNull();
        assertThat(result.getSessionId()).isNotBlank();
        assertThat(result.getBuyerId()).isEqualTo(buyerId);
        assertThat(result.getStatus()).isEqualTo(SessionStatus.ACTIVE);
        assertThat(result.getCurrentCardId()).isNotBlank();
        verify(sessionMapper).insert(any(PurchaseSession.class));
        verify(cardMapper).insert(any(DemandCard.class));
    }

    @Test
    @DisplayName("创建会话 - items 为空 - 应抛 INVALID_PARAM")
    void createSession_emptyItems() {
        // Arrange
        CreateSessionRequest request = new CreateSessionRequest();
        request.setItems(Collections.emptyList());

        // Act + Assert
        assertThatThrownBy(() -> sessionService.createSession("u_001", request))
                .isInstanceOf(BusinessException.class)
                .hasFieldOrPropertyWithValue("code", ErrorCode.INVALID_PARAM.getCode());
    }

    @Test
    @DisplayName("发送消息 - 检测到数量变更 - 应返回 aiDetected=true")
    void sendMessage_quantityChange() {
        // Arrange
        String sessionId = "ps_001";
        SendMessageRequest request = new SendMessageRequest();
        request.setType("text");
        request.setContent("再加 5 吨");

        PurchaseSession session = buildActiveSession(sessionId);
        DemandCard card = buildCard();
        when(sessionMapper.selectById(sessionId)).thenReturn(session);
        when(cardMapper.selectById(any())).thenReturn(card);

        AIIntentService.IntentDetectionResult intent = new AIIntentService.IntentDetectionResult();
        intent.intent = "quantity_add";
        intent.confidence = 0.85;
        when(aiIntentService.detectIntent(any(), any())).thenReturn(intent);

        // Act
        Object result = sessionService.sendMessage(sessionId, "u_001", request);

        // Assert
        assertThat(result).isInstanceOf(Map.class);
        Map<String, Object> map = (Map<String, Object>) result;
        assertThat(map.get("aiDetected")).isEqualTo(true);
        assertThat(map.get("requireConfirmation")).isEqualTo(true);
    }

    // ============ helper ============

    private CreateSessionRequest buildValidRequest() {
        CreateSessionRequest request = new CreateSessionRequest();
        DemandCard.DemandItem item = new DemandCard.DemandItem();
        item.setProductType("plate");
        item.setMaterialGrade("Q235B");
        item.setQuantity(new BigDecimal("50"));
        item.setQuantityUnit("ton");
        request.setItems(List.of(item));
        request.setPriority(PriorityLevel.STANDARD);
        return request;
    }

    private PurchaseSession buildActiveSession(String sessionId) {
        PurchaseSession session = new PurchaseSession();
        session.setSessionId(sessionId);
        session.setBuyerId("u_001");
        session.setStatus(SessionStatus.ACTIVE);
        session.setChangeCount(0);
        session.setCurrentCardId("card_001");
        return session;
    }

    private DemandCard buildCard() {
        DemandCard card = new DemandCard();
        card.setCardId("card_001");
        card.setVersion(1);
        return card;
    }
}
```

要求：
- @ExtendWith(MockitoExtension.class)
- @InjectMocks / @Mock 注解
- 每个测试方法只测一个场景
- 必须 @DisplayName 中文说明
- 必须 AAA 结构
- 必须验证关键 verify 调用
- 必须用 AssertJ（不要 JUnit assertEquals）
```

## 三、Controller 集成测试提示词

```text
任务：为 [Controller] 生成集成测试

## 工具
- @SpringBootTest
- @AutoConfigureMockMvc
- MockMvc
- @MockBean（mock 下层依赖）

## 模板

```java
@SpringBootTest
@AutoConfigureMockMvc
@AutoConfigureTestDatabase  // 用 H2 内存库
class PurchaseSessionControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @MockBean
    private PurchaseSessionService sessionService;

    @Test
    @DisplayName("POST /api/v1/sessions - 正常 - 应返回 200 + sessionId")
    @WithMockUser("u_001")
    void createSession_success() throws Exception {
        // Arrange
        CreateSessionRequest request = buildRequest();
        PurchaseSession session = buildSession();
        when(sessionService.createSession(any(), any())).thenReturn(session);

        // Act + Assert
        mockMvc.perform(post("/api/v1/sessions")
                        .contentType(APPLICATION_JSON)
                        .content(objectMapper.writeValueAsString(request)))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value("0"))
                .andExpect(jsonPath("$.data.sessionId").exists());
    }

    @Test
    @DisplayName("POST /api/v1/sessions - 未登录 - 应返回 401")
    void createSession_unauthorized() throws Exception {
        mockMvc.perform(post("/api/v1/sessions")
                        .contentType(APPLICATION_JSON)
                        .content("{}"))
                .andExpect(status().isUnauthorized());
    }

    @Test
    @DisplayName("POST /api/v1/sessions - items 为空 - 应返回 400")
    @WithMockUser("u_001")
    void createSession_emptyItems() throws Exception {
        CreateSessionRequest request = new CreateSessionRequest();
        request.setItems(Collections.emptyList());

        mockMvc.perform(post("/api/v1/sessions")
                        .contentType(APPLICATION_JSON)
                        .content(objectMapper.writeValueAsString(request)))
                .andExpect(status().isBadRequest())
                .andExpect(jsonPath("$.code").value("1002"));
    }
}
```

要求：
- 每个接口至少 3 个测试（成功 + 2 个失败）
- 使用 jsonPath 断言响应字段
- 使用 @WithMockUser 模拟登录
- 使用 @MockBean mock 下层 Service
```

## 四、E2E 测试提示词

```text
任务：为关键业务流程生成 E2E 测试

## 范围

只测核心业务流程，不测每个细节。

### 必测流程

1. 买家注册登录 → 发需求 → 收到报价
2. 卖家注册登录 → 配置库存 → 收到询价 → 报价
3. 议价完整链路
4. 清单上传 → AI 解析 → 拆单 → 报价
5. 支付（v2）

## 工具
- 后端：RestAssured + Testcontainers
- 前端：Cypress / Playwright

## 模板

```java
@SpringBootTest(webEnvironment = RANDOM_PORT)
@Testcontainers
class BuyerJourneyE2ETest {

    @Container
    static MySQLContainer<?> mysql = new MySQLContainer<>("mysql:8.0")
            .withDatabaseName("huodaizi_test");

    @Container
    static GenericContainer<?> redis = new GenericContainer<>("redis:7-alpine")
            .withExposedPorts(6379);

    @LocalServerPort
    private int port;

    @Test
    @DisplayName("买家完整流程：注册 → 发需求 → 收报价 → 接受")
    void buyerCompleteJourney() {
        // 1. 注册 + 登录
        String token = registerAndLogin("13800000001");

        // 2. 发需求
        String sessionId = createSession(token);

        // 3. 卖家收到询价（mock）
        triggerDispatch(sessionId);

        // 4. 模拟卖家报价
        String quoteId = mockSellerQuote(sessionId);

        // 5. 买家查看报价
        List<QuoteDTO> quotes = listQuotes(token, sessionId);
        assertThat(quotes).hasSize(1);

        // 6. 买家接受
        acceptQuote(token, quoteId);

        // 7. 验证会话状态
        SessionDetailDTO detail = getSession(token, sessionId);
        assertThat(detail.getStatus()).isEqualTo("deal");
    }
}

## 六、性能测试提示词

```text
任务：对 [API] 进行性能测试

## 工具
- JMeter / k6 / Gatling

## k6 模板

```javascript
// loadtest/create-session.js
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  stages: [
    { duration: '1m', target: 50 },    // 1 分钟到 50 并发
    { duration: '3m', target: 50 },    // 维持 3 分钟
    { duration: '1m', target: 0 },     // 退出
  ],
  thresholds: {
    http_req_duration: ['p(95)<500'],  // P95 < 500ms
    http_req_failed: ['rate<0.01'],    // 错误率 < 1%
  },
};

export default function () {
  const url = 'https://api.huodaizi.com/api/v1/sessions';
  const payload = JSON.stringify({
    items: [{
      productType: 'plate',
      materialGrade: 'Q235B',
      quantity: 50,
      quantityUnit: 'ton',
    }],
    priority: 'standard',
  });

  const params = {
    headers: {
      'Authorization': `Bearer ${__ENV.TEST_TOKEN}`,
      'Content-Type': 'application/json',
    },
  };

  const res = http.post(url, payload, params);

  check(res, {
    'status is 200': (r) => r.status === 200,
    'response time < 500ms': (r) => r.timings.duration < 500,
    'has sessionId': (r) => JSON.parse(r.body).data?.sessionId !== undefined,
  });

  sleep(1);
}
```

## 性能要求

| 接口类型 | P95 | P99 | 备注 |
|---|---|---|---|
| 登录 | < 500ms | < 1s | |
| 创建会话 | < 500ms | < 1s | |
| 列表查询 | < 300ms | < 800ms | 必须分页 |
| AI 识变 | < 3s | < 5s | 异步 |
| 派单 | < 1s | < 2s | 含推送 |
