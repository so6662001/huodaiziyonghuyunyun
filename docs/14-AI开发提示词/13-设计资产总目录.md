### 2.3 移动端 ↔ PC 端对应规范

```
原则：同一业务功能在两端必须共享：
✓ 字段名（如 sessionId、items、status）
✓ 状态值（如 pending/dispatching/quoted/locked/deal/no_supply）
✓ 业务规则（如议价 5 轮、变更 5 次上限）
✓ 文案命名（如"待发货"两端必须一致，不能一边叫"备货中"）

差异在布局密度：
✓ 移动端：单列卡片 · 触摸大按钮 · 字 ≥ 11px
✓ PC 端：多栏表格 · 矩阵密集 · 字 ≥ 12px
```

## 四、数据模型与契约（不能编造任何字段）

### 4.1 核心实体：`DemandCard`（多规格）

```typescript
// 来源：docs/07-产品PRD-v2/02-采购会话核心模块.md 第 5.2 节
// 后端：backend/.../session/entity/DemandCard.java
// 数据库：demand_cards 表

interface DemandCard {
  cardId: string;
  sessionId: string;
  version: number;

  items: DemandItem[];        // ⭐ 必须是数组（不能改成单值）

  defaults?: {                 // 整单全局默认值（每行可覆盖）
    deliveryCity?: string;
    deliveryDistrict?: string;
    deliveryDeadline?: datetime;
    paymentTerms?: string;
  };

  splitStrategy: 'auto' | 'bundle' | 'manual';
  note?: string;

  changedFields: ChangeRef[];  // 含行号的变更引用
  changedBy: 'buyer' | 'ai_assist';
  changeReason?: string;
}

interface DemandItem {
  itemNo: number;              // ⭐ 行号（1-N，删行后保持稳定）
  clientTempId?: string;       // 幂等键

  productType: string;          // plate/rebar/hbeam/coil/pipe/stainless
  materialGrade: string;       // Q235B/HRB400E/304 等
  spec: object;                // {thickness, width, length, diameter, ...}
  quantity: decimal;
  quantityUnit: 'ton'|'kg'|'piece'|'meter';

  // 行级覆盖
  deliveryCity?: string;
  deliveryDeadline?: datetime;

  targetPriceRangeMin?: decimal;
  targetPriceRangeMax?: decimal;
  priceUnit?: 'per_ton'|'per_piece';

  requireQualityCertificate?: boolean;
  requireProcessing?: string;
  note?: string;

  // 运行时（非存储）
  status?: 'pending' | 'dispatching' | 'quoted' | 'locked' | 'deal' | 'no_supply';
  matchedQuoteCount?: number;
}
```

### 4.2 状态值枚举（全平台统一）

| 枚举 | 值（不可改） | 业务含义 |
|---|---|---|
| `SessionStatus` | active / matching / quoting / negotiating / deal / expired / closed / cancelled | 会话状态 |
| `DemandItem.status` | pending / dispatching / quoted / locked / deal / no_supply | 行级状态 |
| `QuoteStatus` | active / updated / expired / withdrawn / won / lost / superseded | 报价状态 |
| `OrderStatus` | created / paid / shipping / partial_shipped / shipped / received / completed / refund | 订单状态 |
| `UserRole` | buyer / seller / both / admin | 用户角色 |
| `PoolLevel` | pilot / standard / premium | 派单池 |
| `PriorityLevel` | standard / urgent / bounty | 优先级 |
| `SellerLevel` | S / A / B / C | 卖家分级 |
| `BuyerLevel` | A / B / C / sleeping | 买家分级 |

**红线**：不准在代码中出现这些枚举值之外的字符串。

```

```
