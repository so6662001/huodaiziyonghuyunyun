# 03 - UI 高保真还原提示词

> **用途**：让 AI 写的页面**精确符合设计规范**，告别"看起来还行但细节全错"。
> **核心思想**：把设计规范"翻译成代码约束"喂给 AI。

---

## 一、UI 还原通用提示词

```text
# UI 高保真还原约束

## 必读资源（开发前必查）

1. docs/13-Figma设计规范/01-设计系统总览.md             设计哲学
2. docs/13-Figma设计规范/design-tokens/tokens.json     所有 token
3. docs/13-Figma设计规范/components/01-基础组件.md      组件规格
4. docs/08-技术交付物/ui-prototype/[xx].html           HTML 原型（参考）
5. docs/10-执行落地工具/ui-改版原型/[xx].html          改版原型（如适用）

## 还原优先级

```
HTML 原型 ＞ 设计规范文档 ＞ tokens 文件 ＞ 设计师口头描述
```

如有冲突：以最新的 HTML 原型为准。

## 强制约束（违反任何一条视为还原失败）

### 颜色

```scss
// ✅ 正确
color: $color-primary-600;
background: $color-bg-card;
border: 1px solid $color-border-default;

// ❌ 错误
color: #2563eb;       // 硬编码
background: blue;     // 颜色名
background: #2563ee;  // 自创相近色（哪怕只差一位）
```

可用颜色全列表（仅这些，禁用其他）：
- 主色：primary-{50,100,200,300,400,500,600,700,800,900}
- 警告：warning-{100,500,600}
- 危险：danger-{100,500,600}
- 成功：success-{100,500,600}
- 金色（仅 S 级）：gold-{100,500,600}
- 中性：neutral-{0,50,100,200,300,400,500,600,700,800,900}

### 字号

```scss
// ✅ 正确
font-size: $font-size-15;  // 正文
font-size: $font-size-18;  // 标题

// ❌ 错误
font-size: 14px;   // 必须用 token
font-size: 11px;   // 太小！钢贸老板看不清（除非辅助文字）
```

允许的字号：11, 12, 13, 15, 16, 18, 22, 24 px。其他不允许。

### 字重

仅以下 4 种：
- regular: 400
- medium: 500
- semibold: 600
- bold: 700

300 / 800 / 900 不允许（中文显示效果差）。

### 间距

必须是 4 的倍数：
0, 4, 8, 12, 14, 16, 20, 24, 32, 40, 48 px

其他值（如 10, 15, 22）不允许，强制 round 到最近的 token 值。

### 圆角

```
none = 0px       不用
sm   = 4px       标签 chip
md   = 6px       小按钮 / 输入框
lg   = 8px       默认按钮
xl   = 12px      卡片
2xl  = 16px      重要卡片 / 入口
full = 9999px    Chip / 头像
```

### 阴影

```scss
// ✅ 正确
box-shadow: $shadow-sm;  // 卡片
box-shadow: $shadow-md;  // hover / 弹层
box-shadow: $shadow-lg;  // modal

// ❌ 错误
box-shadow: 0 2px 8px rgba(0,0,0,0.1);  // 自创
```

### 按钮高度

```
Block:  56px  关键 CTA
Large:  44px  默认
Medium: 36px  列表内
Small:  28px  标签内
```

小于 44px 的按钮只能用在密集列表中，主操作必须 ≥ 44px。

### 输入框

```
高度：44px（与按钮一致）
字号：15px
内边距：12px 横 / 8px 纵
圆角：6px
默认边框：1px solid $color-border-default
focus 边框：1px solid $color-primary-600 + 3px 阴影
```

## 必须实现的状态

每个组件 / 页面必须支持以下状态：

```
□ 默认（default）
□ 悬停（hover）—— PC 端
□ 按下（active / pressed）
□ 聚焦（focus）—— 输入类
□ 禁用（disabled）
□ 加载（loading）
□ 空状态（empty）—— 列表/数据展示
□ 错误（error）
```

## 必须实现的边界

```
□ 长文本省略（text-overflow: ellipsis）
□ 数字千分位（如 1,234,567）
□ 价格保留 2 位小数
□ 时间相对显示（"3 分钟前"、"昨天"）
□ 图片加载失败 fallback
□ 接口失败时的 UI 反馈
```

## 钢贸用户体验红线

```
✅ 必须做
- 信息密度适中（不要堆太多）
- 关键数字大字号高亮
- 颜色克制（蓝灰为主 + 一种暖色）
- 留白足够
- 点击区域 ≥ 44pt
- 错误提示有人话解释

❌ 不准做
- 渐变滥用（仅入口卡片可用）
- 多种鲜艳颜色堆砌
- 微小图标（< 16px）
- 字号 < 11px
- 自动播放视频/音频
- 强制弹窗
```

## 移动端适配

设计基准：414px（iPhone Pro Max）
最小适配：375px（iPhone 13）

```scss
// 使用 vw 或 rem 不靠谱，建议直接 px

.container {
  padding: 16px;  // 不缩放
}

// 个别需要响应：
@media (max-width: 375px) {
  .demand-card {
    padding: 12px;
  }
}
```

## 暗黑模式

v1 不做。v2 视情况补充。
现在所有颜色按浅色模式设计。
```

```text
任务：还原 [页面名]

| 端 | 买家小程序 |
| 路由 | pages/buyer/demand/create/index.vue |

## 还原要求

### 像素级要求
- 误差容忍：±2px
- 颜色误差：0（必须 token）
- 字号误差：0（必须 token）
- 间距误差：±2px

### 交互要求

请先打开 HTML 原型，列出所有交互：
1. ......
2. ......

### 状态要求

请列出所有状态：
- 默认
- ......

## 请先回答（不要直接写代码）

1. 列出所有用到的 design token（颜色/字号/间距）
2. 列出所有用到的基础组件（Button/Input/Card/...）
3. 列出所有用到的业务组件
4. 列出所有 API 调用
5. 列出所有状态（包括边界）

## 实现顺序

1. 创建页面文件 pages/[xx]/index.vue
2. 在 pages.json 中注册路由
3. 拆解组件（按"基础组件 → 业务组件 → 页面"层级）

## 自查（产出后必须输出）

□ 与 HTML 原型对比，差异 ≤ 5%
□ 所有颜色都来自 token
□ 所有字号都来自 token
□ 所有间距都是 4 的倍数
□ 所有按钮 ≥ 44pt
□ 包含默认 / 加载 / 空 / 错 / 成功 状态
□ 包含 375 / 414 双适配截图（说明）

## 三、组件还原提示词模板

```text
任务：实现组件 [组件名]

## 任务卡

| 字段 | 值 |
|---|---|
| 设计规范 | docs/13-Figma设计规范/components/[xx].md |
| 组件类型 | 基础 / 业务 |
| 路径 | src/components/[level]/[name]/index.vue |

## 组件要求

### Variants（变体）

请按设计规范列出所有 variant：
- type: primary / secondary / warning / danger / ghost
- size: large / medium / small
- state: default / hover / disabled / loading

### Props（属性）

```typescript
interface Props {
  type?: 'primary' | 'secondary' | 'warning' | 'danger' | 'ghost'
  size?: 'large' | 'medium' | 'small'
  disabled?: boolean
  loading?: boolean
  // ...
}
```

### Events（事件）

```typescript
defineEmits<{
  click: [event: MouseEvent]
}>()
```

### Slots（插槽）

- 默认插槽：按钮文字
- icon 插槽：左侧图标（可选）

## 自查

□ 所有 variant 都实现
□ 所有 state 都实现
□ Props 有完整类型 + 默认值
□ Events 有完整类型
□ 样式用 token，BEM 命名
□ 无障碍属性（aria-*）
□ Storybook 故事（如项目使用）
```

## 四、HTML 原型转 Vue 模板提示词

```text
任务：把 HTML 原型转为 Vue 组件

## 输入

HTML 原型路径：docs/08-技术交付物/ui-prototype/[xx].html

## 转换规则

### 1. CSS 提取

- 把 HTML 中的 `<style>` 内联样式提取到 .vue 的 <style scoped> 中
- 把硬编码颜色替换为 token 变量
- 把硬编码字号替换为 token 变量
- 把硬编码间距替换为 token 变量
- 把 class 名改为 BEM 风格

### 2. 结构转换

- HTML `<div>` → Vue 的 view（小程序）或 div（H5）
- HTML `<input>` → 小程序的 input 组件 / Vant Input
- HTML `<button>` → 项目的 Button 组件（基础组件库）
- HTML 假数据 → v-for 渲染 + Mock 数据

### 3. 交互绑定

- HTML 假交互（如 alert()）→ Vue 真实事件
- HTML 表单 → reactive() 双向绑定
- HTML 按钮 → 调用 API

### 4. 状态管理

- 复杂状态 → 提取到 Pinia store
- 简单本地状态 → ref() / reactive()

## 自查

□ Vue 文件中的颜色全部用 token
□ 字号全部用 token
□ HTML 假数据已替换为 API 调用
□ 表单已绑定 + 校验
□ 包含 loading / empty / error 状态
```

## 七、AI 还原常翻车的点

整理给 AI 看，让它避免：

```
❌ 翻车 1：用了相似但不一样的颜色
  设计：#2563eb
  AI 写：#2266EE（看起来都是蓝）
  解决：强制 token

❌ 翻车 2：行高错了
  设计：行高 22px
  AI 写：line-height: 1.5（不一样）
  解决：明确指定 line-height: 22px

❌ 翻车 3：按钮太小
  设计：44px
  AI 写：36px（更紧凑好看）
  解决：明确钢贸用户手指粗

❌ 翻车 4：字号不一致
  设计：标题 18px
  AI 写：16px（凭印象）
  解决：必须查 token 文档

❌ 翻车 5：图标尺寸错乱
  设计：16px 图标
  AI 写：14px 或 18px
  解决：图标只能 16/20/24

❌ 翻车 6：忽略空状态
  设计：列表 + 空状态插画
  AI 写：只写列表
  解决：必须列状态清单

❌ 翻车 7：硬编码假数据写死
  AI 写：直接把 "张三" 写在 template
  解决：必须接 API 或用 Mock 服务
```

## 八、引用图片对照检查

如果有 Figma 截图或 HTML 原型截图，AI 应该：

```text
1. 描述截图：「这张图展示了... 包含 X 个区域，每个区域...」
2. 列出截图中的所有元素 + token
3. 写代码
4. 完成后再次描述自己写的页面会是什么样
5. 与截图对比，列出差异
6. 修复差异
```

这种"自描述对照"是减少视觉翻车的有效手段。
