## 二、群分级判定 SOP（每月 1 号执行）

```
Step 1: 数据团队跑脚本，输出每个群的下列数据：
  - 总人数
  - 30 日发言总数
  - 30 日发言独立用户数
  - 30 日"找货"自然询价次数
  - 30 日链接点击次数
  - 群主活跃度

Step 2: 套用判定规则（S/A/B/C 四档）

Step 3: 输出 Excel 给运营负责人

Step 4: 运营负责人按分级分配运营策略：
  - S 级：作为"撮合主战场"，重点投入悬赏找货
  - A 级：维持内容+引导发需求
  - B 级：钩子重启计划
  - C 级：合并或重建

Step 5: 月底复盘升降级情况，列入运营专员考核
```

## 四、死群重启计划（B 级群）

```
Week 1：基础修复
  Day 1: 群主清理僵尸号
  Day 3: 群改名（去掉"老XX群"等老旧字眼）
  Day 7: 推送"群升级公告"

Week 2：内容唤醒
  - 每天只发 1 条精选内容（不发广告）
  - 关注互动反馈，第一个回复的群成员私聊感谢+赠送积分

Week 3：钩子激活
  - 发起 1 次"行情问答红包"
  - 发起 1 次"独家数据放送"

Week 4：评估
  - 恢复到 A 级 → 进入正常运营
  - 仍 B/C 级 → 进入合并清单

复活率预期：30-40%
```

## 六、应急流程

### 1. 事件分级

| 等级 | 定义 | 响应时间 | 处理人 |
|------|------|---------|--------|
| P0 | 政治/违法/重大负面 | 5 分钟内 | 群运营 + 公关 + 法务 |
| P1 | 大量投诉、群体抵制 | 30 分钟内 | 群运营组长 + 客服 |
| P2 | 个别用户冲突、骚扰 | 2 小时内 | 群运营专员 |
| P3 | 一般咨询、答疑 | 当日内 | 群运营专员 |

### 2. P0 事件处理

```
T+0    群运营专员发现 → 截图 → 通报组长 → 组长通报负责人
T+1min 负责人通报 COO + 公关 + 法务
T+3min 群运营撤回（如可撤）+ 私聊涉事人停止
T+5min 必要时禁言 + 踢出
T+10min 全员通报口径
T+30min 复盘 + 文档归档

绝对不能做：
❌ 在群里对峙
❌ 删除证据
❌ 私下处理不上报
```

### 3. P1 事件：群体投诉处理

```
Step 1: 主动接管话题（不要回避）
  「@所有人 我是货袋子运营 @XX，注意到这个问题，平台立刻介入」

Step 2: 把战线拉到私聊
  「@买家 @卖家 请加我私聊，立刻拉三方电话会议」

Step 3: 群内通报进度（30 分钟内）

Step 4: 闭环处理（24 小时内）

Step 5: 复盘 + 优化（一周内）
```

### 4. P1 事件：群主突然消失/反水

```
处理思路：
1. 立刻私聊群主，了解原因
2. 经济补偿 / 情感沟通 / 权益升级
3. 如群主坚持离开，让他体面退出：
   - 转让群主权
   - 保留他在群里的核心地位
   - 不公开撕破脸
4. 如群已被破坏，迅速建新群+迁移成员

绝对不要：
❌ 公开抨击群主
❌ 强行夺群
❌ 让其他群主感到"得罪平台没好下场"

钢贸圈很小，每一个被你得罪的群主都会变成长期阻力
```

### 5. 系统故障应急

```
T+0  技术发现 + 通报
T+5min  群运营全员收到通报，立即在所有群发：
  「【临时通知】平台系统正在维护升级，预计 X 小时恢复
   期间如有找货需求，请直接私聊我，人工对接」

T+30min  每 30 分钟在 S/A 级群更新进展

T+恢复后  补偿通知
```

## 七、质量控制

### 1. 群发内容三审制

```
一审：内容编辑自检（写完后通读 3 遍）
二审：内容主编审核（每天 06:00 前完成早报、12:30 前完成午报）
三审：抽查制度（运营负责人每周抽 20% 内容做事后审核）

红线：
- 政治敏感词
- 错别字
- 数据错误（价格、品名）
- 链接错误
- 调性不符
```

### 2. 群运营专员能力评估

每月底过下列考核：

| 维度 | 考核方式 | 权重 |
|------|---------|------|
| 业务能力 | 模拟 5 个典型场景，看处理动作 | 30% |
| 数据成绩 | 见绩效 KPI | 50% |
| 用户口碑 | 抽 20 个用户做满意度调查 | 10% |
| 团队协作 | 360 度评估 | 10% |
