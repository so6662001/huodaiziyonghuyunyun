# 产品/网站 Review 自检 Checklist

> 用于产品经理对照走一遍，能发现 80% 的产品体验问题。

## 一、注册登录环节

| 检查项 | 标准 | 自评 |
|--------|------|-------------|
| 注册流程总步数 | ≤ 3 步 | ☐ |
| 手机号一键登录 | 必须有 | ☐ |
| 微信登录 | 必须有（钢贸圈微信生态深） | ☐ |
| 营业执照 OCR 自动识别 | 必须有 | ☐ |
| 注册时是否要求选择身份（买家/卖家） | 必须有 | ☐ |
| 注册后新手引导 | 必须有，3-5 步 | ☐ |
| 注册转化率监控 | 必须有埋点 | ☐ |

## 二、首页与导航

| 检查项 | 标准 | 自评 |
|--------|------|--------|
| 首页 5 秒能让用户知道"这是什么平台" | 是 | ☐ |
| 首屏是否有清晰的"找货" CTA | 是 | ☐ |
| 首屏是否有清晰的"发资源"入口 | 是 | ☐ |
| 是否区分买家/卖家不同的首页 | 是 | ☐ |
| 是否有今日行情/数据展示 | 是 | ☐ |
| 是否有"近期成交动态" | 是 | ☐ |
| 移动端首屏加载 | ≤ 2 秒 | ☐ |

## 十二、最容易踩的 5 个产品坑

1. **导航做得像 C2C 电商** ← 钢贸不是淘宝，简洁专业
2. **强制注册才能浏览** ← 钢贸老板讨厌注册，应让游客先看到价值
3. **价格不展示** ← 钢贸最敏感的就是价格，必须透明
4. **没有手机端深度体验** ← 钢贸 70% 流量来自手机
5. **缺少"找货"反向场景** ← 这是接下来要做的核心

## 十三、自检完成后的行动

1. 把"☒"和"☐ 不达标"的项整理成一张表
2. 按"对用户体验影响"打分（1-5）
3. 按"开发成本"打分（1-5）
4. **优先做"影响 ≥ 4 + 成本 ≤ 3"的项**
5. 形成产品迭代 backlog，每周认领 5 项
