# 反作弊规则详细引擎

## 一、引擎架构

```
事件源（注册/发需求/报价/邀请/支付）
    ↓
特征采集层（设备指纹/IP/营业执照/行为序列）
    ↓
规则引擎层（30+ 规则同时跑）
    ↓
决策层（通过/限流/人工审核/拦截/封号）
    ↓
处置层（执行+通知+申诉入口）
    ↓
反馈学习层（人工复核结果回流到规则迭代）
```

## 二、风险维度全景图

| 维度 | 风险点 | 规则数 |
|------|--------|--------|
| 注册环节 | 假账号、批量注册 | R001-R005 |
| 反向邀请 | 自邀自、薅羊毛 | R006-R012 |
| 发需求 | 询价党、探价 | R013-R018 |
| 报价 | 同质化、串价 | R019-R023 |
| 联系沟通 | 跳单、骚扰 | R024-R027 |
| 成交回填 | 虚假成交 | R028-R031 |
| 流量费 | 套现、刷线索 | R032-R036 |

## 三、注册环节（R001-R005）

### R001：设备/IP 同源检测

```
IF 同一设备指纹（IDFA/IMEI/设备 hash）24h 内注册 >2 个账号
THEN 该设备所有账号进入人工审核池
   AND 设备指纹拉黑 48h
```

### R002：营业执照唯一性

```
IF 营业执照统一社会信用代码已存在
THEN 拒绝注册，提示"该企业已注册"
ELSE IF 法人姓名+身份证号已绑定其他账号
THEN 标记为"关联账号"，权限受限（不能参与邀请激励）
```

### R003：信息完整度评分

```
score = (营业执照完整度 + 联系方式真实度 + 头像真实度) / 3

IF score < 50
THEN 限制功能（只能浏览，不能发需求/报价）
   通知 24h 内补全资料
```

### R004：批量注册识别

```
IF 同一时间窗（10 分钟）内同 IP 段（/24）注册 >3 个账号
   OR 同一时间窗注册账号有 >50% 字段相似度
THEN 全部进入人工审核 + 邀请人受影响
```

### R005：黑名单关联

```
IF 法人姓名/身份证号/手机号/营业执照 与黑名单匹配
THEN 直接拒绝注册 + 通报关联账户

黑名单来源：
- 历史封号
- 公开失信被执行人
- 行业黑名单（与其他平台合作）
```

## 四、反向邀请（R006-R012）

### R006：自邀自闭环检测

```
邀请人 A、被邀请人 B 满足任一：
- A.legal_person == B.legal_person
- A.legal_person_id_card == B.legal_person_id_card
- A.bank_account == B.bank_account
- A.address 与 B.address 同栋楼内

THEN 关系作废 + 奖励冻结 + 关联账号标记
```

### R007：设备同源邀请

```
IF A 邀请 B，且 B 是在 A 的设备上完成注册
   OR B 注册后 7 日内有 >50% 行为在 A 的设备上
THEN 关系作废
```

### R008：邀请关系链异常

```
IF A 邀请 B → B 邀请 C → C 邀请 A（闭环）
   OR 邀请关系超过 3 层都在同一 IP 段
THEN 全链奖励冻结，进入人工审核
```

### R009：被邀请人行为异常

```
IF 被邀请人 B 注册后 7 日内仅有"邀请关系激活"动作
   AND 无任何其他自主行为
THEN B 的"激活"状态不算数，奖励不发放
```

### R010：高速激活异常

```
IF 被邀请人注册 → 发需求 → 联系卖家 → 成交 全部在 1 小时内完成
   AND 成交对方就是邀请人
THEN 视为虚假闭环，全链奖励冻结
```

### R011：单卖家邀请异常集中

```
IF 卖家 A 邀请的买家中，>60% 的需求只跟 A 自己有沟通
   OR >50% 的成交都是与 A 完成
THEN 该卖家进入"过度自循环"标记
   邀请激励减半，超过 80% 直接停止激励
```

### R012：奖励提现风控

```
单次提现 >¥1000：人工审核
单月累计提现 >¥5000：人工审核
单月累计提现 >¥10000：财务+风控双审

提现到账户必须与营业执照法人匹配
```

## 五、发需求（R013-R018）

### R013：询价党识别

```
IF 买家 30 日发需求数 >30
   AND 30 日自报成交数 == 0
   AND 30 日联系卖家数 / 发需求数 < 30%
THEN 标记为"询价党"
   降低派单优先级
```

### R014：探价行为识别

```
IF 同一买家 24h 内发布相同品类+规格需求 >5 次，且每次都不联系
THEN 视为探价 → 暂停该买家发需求权限 24h
```

### R015：竞品探价识别

```
IF 买家账户营业执照行业关键词包含 "钢贸/钢材/贸易"
   AND 该买家从未在平台采购
   AND 该买家高频发需求
THEN 标记为"潜在竞品"，进入人工识别
```

### R016：异常字段填写

```
IF 需求中 数量 >1000 吨 但 期望账期 == "现款"
   OR 期望价格远低于市场参考价 20% 以上
   OR 备注栏出现"竞品名"、"找钢网"等敏感词
THEN 标记，需求降权派单
```

### R017：测试账号识别

```
IF 营业执照名包含"测试"、"DEMO"、"试用"
   OR 注册手机号是平台内部号段
THEN 标记为测试，不计入业务数据
```

### R018：需求重复推送防控

```
IF 同一买家在 72 小时内发布相同需求
THEN 视为同一需求，合并处理，不重复推送给已报价卖家
   且不重复扣流量费
```

## 六、报价环节（R019-R023）

### R019：异常报价检测

```
基准价 = 该品类该区域过去 7 日中位数报价
IF 报价 > 基准价 × 1.15  OR 报价 < 基准价 × 0.85
THEN 标记"异常报价"，提示卖家确认
   连续 3 次报异常价 → 进入限制池（72 小时降权派单）
```

### R020：同质化报价（串价）

```
IF 同一需求收到 N 条报价，方差 < 0.5%
   AND N ≥ 3
THEN 怀疑串价，人工抽查
   命中后涉事卖家加入"串价观察名单"
```

### R021：机器报价识别

```
IF 卖家平均响应时间 < 5 秒
   AND 报价金额都是整百整千
   AND 同时跟单多个需求（>20 单/小时）
THEN 触发人机校验
   连续触发 3 次 → 暂停接单
```

### R022：报价撤回滥用

```
IF 单日撤回报价数 >5
   OR 撤回率 >30%
THEN 该卖家次日接单数减半 24h
```

### R023：恶意低价扰乱

```
IF 卖家报价低于基准价 15% 以上
   AND 该卖家无对应库存
   AND 该卖家近 90 日无该规格成交
THEN 判定为"诱单低报"，警告
   累计 3 次 → 禁言 30 天 + 信用扣分
```

## 七、联系沟通（R024-R027）

### R024：跳单识别（核心）

```
信号采集：
- IM 中出现微信号/电话号
- 通话中关键词识别（"加我微信"、"私下聊"）
- 双方 IM 突然停止但都未关闭需求

打分模型：
跳单分 = 0.3×直接联系方式出现 + 0.3×停止平台沟通 + 0.4×需求未关闭

IF 跳单分 > 0.7
THEN 推送平台增值服务提醒（电子合同、账期金融）
     标记需求为"疑似跳单"
     7 日后回访询问"是否成交"

注意：不能强制阻断跳单，只能"引导回归"
```

### R025：骚扰识别

```
IF 卖家对同一买家发起 >10 次联系/24h
   AND 买家有 >50% 的回复包含"别打了/不需要"等关键词
THEN 限制该卖家联系该买家
   该卖家"过度联系"标签 +1
   累计 5 次 → 平台介入培训
```

### R026：黑话/灰产识别

```
IM 关键词扫描，触发任一即上报：
- 涉及"票"（增票走票）的金融违规
- 涉及代缴/虚开等违规
- 政治敏感词
- 涉黄涉赌涉毒

T+0 即时屏蔽该消息 + 双方账号进入人工审核
```

### R027：垃圾内容防控

```
IF 卖家在 IM 中发送 >3 个无关链接/图片/小程序
   OR 群发同一内容给 >5 个买家
THEN 警告 + 限制单日发送条数
```

## 八、成交回填（R028-R031）

### R028：虚假成交检测

```
IF 双方都未在平台 IM 沟通过 > 5 轮
   AND 突然回填一笔大额成交
   AND 双方公司有关联关系
THEN 拒绝认证该成交，需要补充证据：
   - 合同照片
   - 物流单据
   - 银行流水部分截图
```

### R029：成交金额异常

```
IF 回填金额 > 该需求询价中位数 × 2
   OR 回填金额 < 中位数 × 0.5
THEN 进入人工核验
```

### R030：单方面成交回填

```
卖家单方回填，48h 内买家未确认 → 成交状态为"待确认"，不计入业绩
72h 内买家仍未确认 → 自动失效，奖励不发放
```

### R031：刷成交防控

```
IF 卖家月度回填成交数 > 月均询盘数 × 2
   OR 与同一买家月度成交 >5 次
THEN 全部进入抽查（抽 30%）
   抽查未通过 → 全部成交作废
```

## 九、流量费规则（R032-R036）

### R032：自买自卖刷线索

```
IF 卖家 A 收到的线索中，买家 B 是与 A 关联的（设备/营业执照/资金）
THEN 该线索不计费 + 该卖家流量费余额冻结审查
```

### R033：申诉滥用

```
IF 卖家月度申诉率 >25%
   AND 申诉通过率 <20%
THEN 该卖家进入"高申诉"标签
   后续申诉需补充更多证据
   累计 3 个月超阈值 → 限制申诉权限
```

### R034：线索质量异常

```
平台监控线索质量分布
IF 某品类某区域线索的"卖家联系成功率" < 30%（连续 7 日）
THEN 自动暂停该品类该区域的 CPL 收费
   触发数据团队调查
```

### R035：充值套现

```
IF 充值后 7 日内未消耗，但申请退款
THEN 收 10% 手续费
   累计 2 次 → 不再支持退款
```

### R036：扣费幂等

```
所有扣费动作必须幂等：
- 同一线索 ID 只扣一次
- 重试不重复扣
- 系统故障期间的扣费全部回滚

技术实现：
- 数据库唯一约束 + 业务幂等键
- 扣费日志全留痕
- 每日财务对账自动跑
```

## 十、处置体系

### 处置分级

| 等级 | 处置动作 | 触发规则示例 |
|------|---------|-----------|
| L0 | 提示+教育 | R013 第一次询价党 |
| L1 | 限流（功能降级 24h） | R022 报价撤回过多 |
| L2 | 限制（暂停某功能 7-30d） | R023 恶意低价 |
| L3 | 暂停（账号 72h） | R026 黑话灰产 |
| L4 | 封号（永久） | R005 黑名单/严重违规 |

### 申诉机制

```
所有 L1-L3 处置必须可申诉
申诉入口：App 内 + 客服热线
处理时效：24h 内出结论
申诉通过率监控：维持在 15-25% 区间
```

### 规则迭代

```
每周：规则团队 review 误伤率/漏判率
每月：规则版本升级
每季度：与外部反作弊厂商对标
每半年：第三方安全审计
```

## 十一、数据看板

风控团队核心看板必须包括：
- 各规则触发量趋势
- 各处置等级账号数趋势
- 申诉率、申诉通过率
- 误伤率（事后人工复核）
- 漏判率（事后用户举报）
- 损失金额（钱已经付了但是欺诈）
