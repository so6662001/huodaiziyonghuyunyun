# 采购会话产品模型

> 解决 B2B 平台第四个生死命门：真实采购是连续对话式的，需求会反复变更，平台离散的"需求-报价"模型反人性。

## 一、问题本质

真实采购沟通的"还原现场"：

```
13:45 采购：李总，我要 50 吨热轧 Q235B 5.5 厚到天津，啥价
13:46 李总：4280 含运
13:47 采购：哦对了，可能要 80 吨
13:48 李总：80 吨 4260
13:50 采购：客户说 6mm 也行
13:50 李总：6mm 我有现货 4220
13:51 采购：到货时间能赶上周三吗
13:51 李总：可以，加 200 运费
13:52 采购：那先报个 6mm 80 吨周三到天津
13:52 李总：4420 含运
13:55 采购：我跟客户确认下
       ...（半天后）...
17:30 采购：客户说先来 50 吨试试
17:32 李总：50 吨我让到 4380
17:33 采购：行 下单
```

**30 个回合、3 次需求变更、2 次规格调整、1 次议价**，全部在 5 分钟有效对话时间内完成。

而在传统平台上：**5 个完整的"发需求-收报价"循环、跨 5 个卖家的 IM 切换、需要 1-2 小时**。

**这不是"平台麻烦"，是底层模型出了根本性问题**。

## 二、真实采购的 5 个本质特征

| 特征 | 真实采购 | 现行平台模型 |
|------|---------|----------|
| 时间形态 | 连续流（对话） | 离散原子 |
| 信息完备性 | 模糊→明确（边谈边定） | 一开始就要全填 |
| 决策路径 | 多轮反复 | 线性流程 |
| 变更频率 | 极高 | 变更=重新走一遍 |
| 关键沟通载体 | IM/语音/电话 | 结构化表单 |

## 三、战略转向：从"需求-报价"升级到"采购会话"

### 旧模型

```
买家发需求 → 卖家报价 → 买家选 → 联系 → 成交
   ↑__________________|
   每次变更都要重来
```

### 新模型

```
买家发起"采购会话" → 系统生成动态需求卡片
                       ↓
              N 个卖家接入会话
                       ↓
        多方实时对话 + 动态报价 + 一键变更
                       ↓
                确认 → 成交
```

**关键转变**：把"需求-报价"两个原子单位，融合成一个**"采购会话"**的连续过程。

## 四、10 个核心机制

### 机制 1：「采购会话」核心产品形态

```
一个"采购会话"包含：
- 1 个动态需求卡片（可随时编辑）
- N 个参与卖家（系统派单）
- N 条对话流（每个卖家一条，并行）
- 1 个聚合看板（买家看所有卖家的最新状态）
- 1 个历史时间线（变更/报价/对话全留存）
```

### 机制 2：「动态需求卡片」一键变更全员同步

```
买家点击需求卡片任何字段 → 直接修改 → 自动同步全员

例：买家把数量从 50 改成 80
   ↓
所有已参与卖家收到推送：
   "买家把数量调整为 80 吨"
   附带原报价：¥4280
   动作选项：
   - 维持原价 ¥4280（一键）
   - 调整为 ¥4260（输入新价）
   - 退出会话（一键）

3 秒钟搞定
```

**字段级变更**：

| 变更类型 | 卖家可选响应 |
|---------|-----------|
| 数量变更 | 维持单价 / 调整单价 / 设阶梯价 |
| 规格变更 | 同价 / 调整 ±N 元 / 退出 |
| 交期变更（变急） | 维持 / 加急费 +X 元 / 退出 |
| 到货地变更 | 维持 / 调整运费 / 退出 |
| 账期变更 | 维持 / 加价 / 退出 |

**变更次数限制**：

```
免费变更次数：5 次/会话
超过 5 次：每次自动给所有参与卖家 ¥3 积分补偿
超过 10 次：标记买家为"反复变更"，提醒卖家
```

### 机制 3：「报价组合配置器」卖家一次报，买家自由选

```
卖家初次报价时填"价格组合"：

数量阶梯：
  50 吨 → ¥4280/吨
  80 吨 → ¥4260/吨
  100 吨 → ¥4240/吨

规格调价：
  5.5mm → 基础
  6mm → -¥60
  8mm → -¥100

加项：
  含运 → +¥150
  加急（3 天内） → +¥200
  开普票 → +¥80
  开专票 → +¥120
  30 天账期 → +¥40

有效期：4 小时
```

**买家端**：勾选不同选项，系统实时计算总价。

**效果**：

| 项 | 旧模式 | 新模式 |
|---|------|------|
| 对话回合数 | 5-10 轮 | 1-2 轮 |
| 卖家报价工作量 | 反复改 | 一次报准 |
| 买家比较成本 | 切换多个卖家手动算 | 一目了然 |
| 变更响应速度 | 几小时 | 即时 |

### 机制 4：「智能识变」IM 中说话就能改需求

```
买家在 IM 输入："要不改成 6mm 吧"
   ↓
AI 解析 + 上方弹出确认条：
   ┌─────────────────────────────────┐
   │ 🤖 您是要把规格从 5.5mm 改为 6mm 吗 │
   │ [✓ 是，更新需求]  [否，继续聊]    │
   └─────────────────────────────────┘
   ↓
买家点击 ✓ → 需求卡片自动更新 → 全员同步
```

**识别场景**：

| 买家说的话 | AI 识别 |
|---------|------|
| "要不要 80 吨" | 数量变更 50 → 80 |
| "改 6mm 吧" | 规格变更 |
| "周三能到吗" | 交期变更 |
| "开专票多少钱" | 增加发票要求 |
| "能不能 4260" | 议价 |

**实现**：LLM API（GPT/通义千问），准确率初期 85% 可接受。

### 机制 5：「快速询价模板」老客户/老需求 3 秒发出

```
📋 我的常用需求（自动学习）
   - 热轧 Q235B 5.5mm 50 吨 天津（用了 12 次）[一键发]
   - 螺纹 HRB400E ¢18 100 吨 唐山（用了 8 次）[一键发]

📋 最近发过的需求
   - [上周] 热轧 Q235B 5.5mm 50 吨 天津  [复制+修改]

📋 客户/项目维度
   - 项目 A：常用规格组合 [一键发]

✏️ 新建需求
```

### 机制 6：「采购清单」一次发多个相关需求

```
买家一次性发"采购清单"：
  📋 项目 A 采购清单
   1. 热轧 Q235B 5.5mm × 50 吨
   2. 螺纹 HRB400E ¢18 × 30 吨
   3. 镀锌 SGCC 0.5mm × 10 吨

卖家可选择：
  ☑ 我能供 1，报价 ¥X
  ☑ 我能供 2，报价 ¥Y
  ☐ 我能供 3

平台自动撮合：
  最优组合 A：卖家 X+Y 各供一部分（综合最低）
  最优组合 B：卖家 Z 一家通包（管理最省事）
```

### 机制 7：「还价产品化」3 秒议价

```
买家在卖家报价卡片上点【还价】：

卖家原报价：¥4280/吨
您希望：¥[4250]/吨
理由（可选）：
  ○ 数量较大  ○ 现款支付  ○ 老客户  ○ 自己写

卖家收到：
[接受 ¥4250]  [拒绝]  [反提议 ¥____]

议价限制：单卖家议价上限 2 次/会话
```

### 机制 8：「老客户快速通道」重复采购不走撮合

```
买家进入"我的老卖家"列表：

⭐ 李总 钢贸 (唐山)
   合作 6 次，累计 ¥120 万
   最近：3 天前 50 吨热轧
   [一键询价]  [发新需求]  [查询历史价]

点击 → 直接发起"指向李总一人"的会话
   ↓
李总收到："老客户 XX 来询价"
   ↓
直接报价、谈、定（中间没人插队）
```

**平台的作用**：不抢老客户生意，提供工具价值（历史价、变更记录、发票/合同管理）。

### 机制 9：「会话克隆」类似需求秒克隆

```
在历史会话页：
   [📁 5 月 23 日：50 吨热轧 Q235B 5.5mm 天津]
   └ 已成交：李总，¥4280

   操作：
   - 克隆为新会话（含所有原参与卖家）
   - 只通知老卖家（一键续单）
   - 修改后发新单
```

```
   "@货袋子 我要 50 吨热轧 Q235B 5.5 到天津"

   匹配中... 预计 10 分钟内 5+ 家报价
   [查看会话]"

10 分钟后机器人 @ 买家：
   "您的会话有 6 家报价，最低 ¥4260
   [一键查看]"

买家可以：
   - 直接在微信里看报价
   - 在微信里和卖家聊（IM 直连）
   - 在微信里改需求（"@小助手 改成 80 吨"）
```


## 六、B2B 平台的本质认知升级

### 不要做"把微信电子化的事"

如果货袋子的核心价值是"让买家不用微信"，那一定输。微信太顺手了。

### 要做"把微信做不到的事电子化"

| 微信能做 | 微信做不到 → 平台的真正价值 |
|------|--------------------|
| 即时沟通 | 结构化报价比较 |
| 转发图文 | 历史价格数据库 |
| 发红包 | 信用体系 |
| 一对一 | 一对多并行撮合 |
| 临时关系 | 长期供应商管理 |
| 口头议价 | 合规留痕电子合同 |
| 报销凭证 | 自动开票/分类账单 |

### 货袋子的最终定位

> **"货袋子是一个长在微信里的钢贸采购助手。
> 它不取代你的微信群，
> 它让你的微信沟通变得更高效、更专业、更可追溯。"**
