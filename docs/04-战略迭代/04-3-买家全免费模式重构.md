# 买家全免费模式重构

> 解决 B2B 平台第三个生死命门：买家不愿付费询价（企业流程慢、个人不愿掏钱），任何付费门槛都会扼杀流量。

## 一、问题本质

"询价付费"在中国 B2B 冷启动期根本走不通：

1. ¥9.9 / ¥99 这种小额，企业根本走不动报销流程
2. 采购员个人不愿掏钱（"凭什么我个人贴钱给公司办事？"）
3. 用户面对"付费门槛"时，最自然的选择就是去打电话、去找钢网、去 1688
4. 收费 = 直接扼杀冷启动期的买家流量

## 二、我犯的最常见 B2B 错误

| 错的设计 | 对的设计 |
|---|---|
| 准入有门槛（付费才能用） | 准入零门槛（人人能用） |
| 用钱筛真假 | 用算法+行为筛真假 |
| 想一次性把"询价党"挡在外面 | 让"询价党"进来但拿不到优质资源 |
| 收费来过滤 | 服务来分层 |

## 三、重新认清 B2B 买家

| 类型 | 占比 | 心理 |
|------|------|------|
| **采购员/采购经理**（中小厂多数） | 60% | 我给公司办事，凭啥自己掏钱？审批比省下来的钱还麻烦 |
| **小厂老板自己采购** | 40% | 自己花钱可以，但 ¥9.9 让我网上付费？没必要 |

**两类用户都不会为询价掏钱**。

## 四、新方案核心：买家全免费 + 智能分级

```
买家端：100% 免费 + 0 门槛 + 极致简单
卖家端：付费但自愿 + 有选择权 + 不被骚扰
过滤逻辑：算法分级 + 行为门槛 + 卖家选择
商业化：卖家侧 + 数据侧 + 增值服务侧
```

## 五、10 个具体机制

### 机制 1：买家所有核心功能全免费

- ✅ 注册免费、发需求免费（不限次）、查看报价免费
- ✅ 联系卖家免费（IM 通话）、浏览资源免费
- ✅ 行情查看免费（基础版）

**唯一可能付费的环节（且非必需）**：

- 高级行情订阅（深度分析）→ 仅针对真有需求的研究型用户
- 担保交易服务（V3 阶段）→ 按效果付费
- 大客户专属买手服务 → 企业级用户、对公付费

### 机制 2：用"算法分级"代替"付费筛选"（核心）

#### 三级匹配池

```
🔵 试水池（低质询价）
  - 触发：新买家首单 / 信用分 <60 / 历史 0 成交
  - 推送范围：3-5 家"愿意接询价练手"的卖家
  - 卖家界面：以"灰色"展示
  - 期待成交率：1-3%

🟢 标准池（正常需求）
  - 触发：默认池
  - 推送范围：10-15 家匹配卖家
  - 期待成交率：8-15%

🟡 优质池（高质需求）
  - 触发：历史成交 ≥2 单 / 30 天联系卖家≥3 次 / 信用分≥80
  - 推送范围：Top 15-20 家精准卖家
  - 卖家界面：以"金色"突出 + 通知"优质买家来询"
  - 期待成交率：25-40%
```

**关键设计**：

- 买家完全不知道自己在哪一级
- 采购员体验完全一样
- 但卖家看到的标签不一样

### 机制 3：卖家"接单偏好"是过滤的最后一道关

```
我愿意接的询价类型：
☑ 优质买家（必接）
☑ 标准买家（默认接）
☐ 试水池（询价练手）
   └─ 如果接，平台每条询价给 ¥1-3 积分

我专注的品类：☑ 螺纹 ☑ 热轧 ☐ 镀锌 ☐ 管材...
我专注的区域：☑ 唐山 ☑ 天津 ☐ 其他
我接单的时间：☑ 工作日 9-18 点 ☐ 晚间/周末
每天最大接单数：[20]
```

**关键**：卖家"响应率"只算他愿意接的池子，不会因为不接询价党被惩罚。

### 机制 4：买家"行为型门槛"代替"金钱门槛"

#### A. 第一次发需求：完整资料

```
- 上传营业执照（OCR 自动识别）
- 选择行业
- 选择企业规模
- 完善联系人信息

这一步过滤掉 30% 探价用户
```

#### B. 发需求强制详细字段

```
填得越详细，需求自动升级到更高匹配池
（买家不知道这个机制，但会"被引导"详细填）
```

#### C. 信用分体系

```
买家信用分 = 60 起步

+10  营业执照认证
+10  完整填写资料
+10  首次成交
+5   联系卖家≥3 轮
+3   每次成交确认
+2   给卖家好评
+0   询价但不联系（中性）
-5   联系卖家后超过 7 天无任何反馈
-10  反复发同需求 ≥5 次不成交
-20  虚假询价被核实

60-79：标准池
80+：优质池
<60：试水池
```

### 机制 5：试单激励——让首次成交无障碍

```
买家首次成交（¥3000-¥50000）：
- 平台补贴买家 ¥200-¥500 现金券
- 平台补贴卖家 ¥300
- 平台亏损 ¥500-¥800，但收获：
  * 买家有"试过"的体验，复购率提升 4-5 倍
  * 买家信用分跳到 80+，进入优质池
  * 后续 12 个月平台收益 ¥3000+

财务测算：
  M3 试单 200 笔 × 800 元亏损 = 16 万投入
  这 200 笔带来的 12 月 LTV ≈ 200 × ¥3000 = 60 万
  ROI ≈ 3.75x
```

**对买家的吸引话术**：

```
"首次合作，平台给您兜底：
✅ 平台垫付 ¥200 运费券
✅ 卖家货物质量平台担保
✅ 7 天内有任何问题平台全额介入
✅ 不增加您任何审批流程

试一单小的，体验后您再决定要不要长期用"
```

### 机制 6：免费价值——行情数据让买家上瘾

```
所有买家免费可以看到：
- 今日钢厂出厂价（10 家主流）
- 今日区域成交价
- 价格走势曲线（过去 7/30/90 天）
- 自己品类的"市场参考价"

每天定时推送：
- 早 8 点行情快报
- 下午行业新闻
- 晚 8 点低价资源

让买家："就算今天不买，每天也要打开看看"
```

### 机制 7：让买家发需求"比打电话还省事"

**目标：30 秒发需求**

- 步骤 1：选品名 / 输入规格（联想匹配，5 秒）
- 步骤 2：输入数量 + 到货地（5 秒）
- 步骤 3：（可选）补充账期、交期等（10 秒）
- 步骤 4：点击发布（即时）

**三大极简神器**：

#### A. "复制上次需求"功能（3 秒搞定）

#### B. 语音发需求
> "我要 50 吨热轧 Q235B 5.5 厚的，到唐山，3 天内交"

#### C. 拍照发需求
> 拍下技术单/生产单，AI 自动识别

**对比**：

| 方式 | 时间 |
|------|------|
| 打电话问 5 家 | 30 分钟 |
| 找钢网发需求 | 3 分钟 |
| 货袋子发需求 | 30 秒 |
| 货袋子复制上次 | 3 秒 |

### 机制 8：把"老供应商"也搬到货袋子上

```
"我的供应商"功能：

- 上传老供应商的名片/联系方式
- 标记每家的优势（"账期好"/"质量好"/"价格便宜"）
- 平台帮忙邀请这些供应商入驻

发需求时可选：
- 📤 公开发布
- 📋 指定我的老供应商
- 📊 同时发：老供应商 + 平台匹配（最常用）
```

**商业模式插入点**：
- 平台帮买家维护"供应商档案"（采购历史、质量记录、纠纷记录）
- 这是企业级买家愿意付费的功能（对公审批容易通过）
- 价格：¥3000-¥10000/年/企业

### 机制 9：直击采购员"个人价值"

```
1. 个人成长账户
   - 你的所有采购历史沉淀（即使换公司也带走）
   - 你的"市场行情专家"等级
   - 你的"采购效率"数据（用于跳槽简历）

2. 个人荣誉体系
   - 月度优秀采购榜（公开）
   - "金牌采购"认证（可写进简历）
   - 钢贸圈采购员俱乐部（线下活动）

3. 个人收益（合规！）
   - 邀请同行加入 → 个人现金奖励
   - 帮平台做内容 → 现金奖励
   - 参加行业活动 → 平台赞助
```

**找钢网当年完全忽略的角度——他们只把买家当公司账号，没把采购员当个人**。

## 六、商业模式彻底重构

### 抛弃买家询价付费，重新设计

| 收入项 | 谁付费 | 怎么付 | 占比目标（M12） |
|------|------|-------|-----------|
| 卖家年费会员 | 卖家 | 个人/对公转账 | 20% |
| 卖家流量费 | 卖家 | 充值预付 | 25% |
| 卖家增值服务（CRM、营销） | 卖家 | 月付/年付 | 15% |
| 买家企业级账户（供应商管理 SaaS） | 买家公司 | 对公付费、年付 | 15% |
| 数据服务（行情订阅、研报） | 第三方/双边 | 订阅制 | 10% |
| 金融分润（账期、保理、采购贷） | 合作机构分润 | 后期上线 | 15% |

### 买家付费的"合理化包装"

买家付费产品必须满足两个条件：

1. **对公审批容易通过**：是"采购管理工具"而不是"信息咨询费"
2. **价格够大**：¥3000-¥10000/年起步，走年度采购预算

### 错误的买家付费形态

- ❌ ¥9.9 询价费
- ❌ ¥99 加急费
- ❌ ¥199 月卡
- ❌ 任何小额、高频、个人感支付

### 正确的买家付费形态

- ✅ ¥3000/年「供应商管理 SaaS」（对公采购）
- ✅ ¥10000/年「企业采购管理套件」（对公）
- ✅ ¥30000/年「大客户专属买手服务」（对公）
- ✅ ¥299/年「金牌买家会员」（个人成长投资）

## 七、对应的 KPI 调整

| 指标 | 旧 KPI | 新 KPI |
|------|------|------|
| 买家注册量 | 1500（要付费门槛） | 5000（无门槛） |
| 月活买家 | 800 | 3000 |
| 月成交数 | 500 | 1500 |
| 首单成交率 | 15% | 25%（试单激励发力） |
| 复购率 | 40% | 60% |
| 平台收入（M3） | ¥30 万 | ¥25 万 |
| 平台收入（M12） | ¥200 万 | ¥250 万 |

短期看营收少 5 万/月，但长期增长更稳。

## 八、核心战略心智

> **B2B 平台的冷启动期，永远不要试图用"买家付费"来过滤询价党。
> 钱要从卖家、企业级买家、数据服务、金融分润这四个方向赚。
> 买家端，永远要追求"零摩擦、零门槛、零负担"，
> 用算法分级 + 行为门槛 + 卖家选择来解决质量问题。**
