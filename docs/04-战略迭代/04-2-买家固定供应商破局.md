# 买家固定供应商破局方案

> 解决 B2B 平台第二个生死命门：买家都有固定供应商，新平台主要被用于"询价不买"，卖家失去积极性。

## 一、问题本质

工业采购和消费者购物本质上是两个物种：

| 维度 | 消费者购物 | B2B 工业采购 |
|------|---------|----------|
| 决策驱动 | 价格+品牌 | 关系+信任+稳定性 |
| 单笔金额 | 几十到几千 | 几万到几百万 |
| 输不起的风险 | 退货就完了 | 停产/纠纷/法律 |
| 供应商更换成本 | 0 | 极高 |
| 决策周期 | 几分钟 | 几天到几个月 |
| 单一买家供应商数 | 无限 | 通常 2-5 家固定 |

**承认事实**：B2B 询价"7 成不买"是行业常态，不是平台失误。

## 二、买家询价的 7 种真实动机

| 比例 | 动机 | 性质 | 平台可转化 |
|------|------|------|----------|
| 30% | 摸底市场价 | 自利型 | ❌ |
| 20% | 应急 / 找现货 | 补充型 | ✅ |
| 15% | 特殊规格 / 偏门品类 | 补充型 | ✅ |
| 10% | 小额尾货 / 测试单 | 试探型 | ⚠️ |
| 10% | 比价后还价 | 利用型 | ❌ |
| 8% | 备用渠道储备 | 储备型 | ⚠️ |
| 5% | 新公司 / 新业务 | 真采购 | ✅ |
| 2% | 替换老供应商 | 真采购 | ✅ |

**关键洞察**：
- 真实"主渠道采购"只有 7%
- **45% 是"补充需求"** → 这是货袋子的真实战场
- 40% 是"利用型"，要用产品机制过滤

## 三、战略转向：从"颠覆者"到"补充者"

| 错的目标（找钢网） | 对的目标（货袋子） |
|----------------|----------------|
| 让买家把全部采购挪到平台 | 让买家把补充采购挪到平台 |
| 替换买家固定供应商 | 成为买家的"第三只眼" |
| 追求高客单大单 | 追求高频小单+特殊单 |
| 看 GMV | 看 take rate + 卖家 NPS |

### 重新定位三大核心场景

#### 场景 A：应急供货（"老供应商交不出货怎么办"）
- 周二接到订单要周五交货，老供应商交期 10 天
- 特征：紧急、价格不敏感、卖家利润高

#### 场景 B：特殊规格（"老供应商没这个货"）
- 客户突然要 6mm 厚的板材，老供应商常做 5mm 或 8mm
- 特征：偏门规格、卖家少、价格自然高

#### 场景 C：小额补充（"零散小单老供应商不愿做"）
- 工程尾期还差 30 吨杂规格货
- 特征：小额、高频、买家不挑剔

### 让出去的场景（不硬抢）

- ❌ 大单主供应（让给老供应商）
- ❌ 长期合约（不是平台擅长）
- ❌ 大型工程招标（流程太重）

## 四、12 个解决"询价不买"机制

> ⚠️ 注：本文档中关于"买家付费筛选"的部分（如机制 1）后续被推翻，详见 `04-3-买家全免费模式重构.md`。

### 机制 1：~~买家询价需要"成本"~~（已推翻）

详见 `04-3`，最终改为买家全免费。

### 机制 2：买家分层 + 卖家选择权（保留）

买家系统标签：

```
🟢 主力买家｜90 天成交 5+ 单
🟡 活跃买家｜90 天成交 1-2 单
🔵 新买家｜首次询价，资料完整
🟠 高潜买家｜询价 5+，已联系 3+
⚪ 探价买家｜询价 10+，0 联系
🔴 询价党｜询价 30+，0 成交
```

卖家"接单偏好"：

```
我愿意接：
  ☑ 主力买家（必接）
  ☑ 活跃/新买家
  ☐ 探价买家（关闭）
  ☐ 询价党（关闭）
```

**效果**：卖家心理从"被强制应付"变成"我有权决定"。

### 机制 3：询价质量公开 + 信用分制度

```
买家信用分 = 100 起：
+10  成交确认
+5   有效互动（联系卖家≥3 轮）
+3   及时回复卖家
+0   询价但未联系
-5   联系卖家后超过 7 天无反馈
-10  虚假询价
-20  反复发同需求不成交

低于 60 分 → 询价党池
低于 40 分 → 暂停发需求
```

### 机制 4：分流场景——"询价"和"采购"分开

| 产品 | 名字 | 给买家 | 给卖家 |
|---------|-----|------|------|
| 比价宝 | 摸价格用的 | 免费、限次、不开放联系方式 | 自愿参与、积分奖励 |
| 找货宝 | 真采购用的 | 无门槛、Top 10 推送、开放联系 | 主战场 |
| 悬赏单 | 急/特殊需求 | 优先级最高 | 优先抢单 |
| 指定询价 | 给老客户 | 指定 2-3 家卖家 | 不进公开池 |

### 机制 5：成交分级 + 价格底线保护

详见 `04-1-反卖家反弹方案.md` 机制 5。

### 机制 6：卖家激励——让"陪聊不成交"也有回报

```
卖家每接一次有效询价 → +5 积分（无论成交）
卖家每被买家点击查看报价 → +1 积分
卖家每被买家联系 → +10 积分

积分用途：
- 兑换平台流量曝光位
- 抵扣会员费/流量费
- 兑换数据报告
- 兑换实物奖品
```

**卖家私域 CRM**：每个买家询过价，自动沉淀到该卖家的 CRM 里。

### 机制 7：买家"试单"机制（破冰转化）

```
首次成交（¥1000 起即可）：
  - 买家：¥200 现金券（覆盖运费）
  - 卖家：¥300 现金 + 信用分 +20
  - 平台：补贴 ¥500，但获得：
    * 双方真实交易数据
    * 买家信用从未知 → 高潜
    * 后续 12 个月复购概率提升 4 倍

第 2-5 单：
  - 买家：每单 ¥50 券
  - 卖家：信用分加权

第 5 单后（建立长期关系）：
  - 进入"老客户通道"
  - 平台收益最大化
```

### 机制 8：把"询价数据"本身变成产品

```
【货袋子行情卡】¥99/月 或 ¥999/年

权益：
- 每日 5 个主流品种实时价格
- 区域价差报告
- 钢厂排产/出厂价变化
- 趋势分析

进阶版：¥299/月
- 自定义关注品种（10 个）
- 月度深度报告
- 群组私聊行情解读
- "我要询价 30 次/月" 套餐
```

**转化逻辑**：探价党 → 行情卡用户 → 应急买家 → 长期客户

### 机制 9：垂直深耕"高补充需求"品类

| 品类 | "补充型采购"占比 | 平台契合度 | 入场顺序 |
|------|--------------|---------|--------|
| 特种钢/合金 | 90%+ | ⭐⭐⭐⭐⭐ | 第 1 |
| 不锈钢卷板 | 80%+ | ⭐⭐⭐⭐⭐ | 第 1 |
| 无缝钢管 | 75%+ | ⭐⭐⭐⭐⭐ | 第 1 |
| 异型材/定制 | 90%+ | ⭐⭐⭐⭐⭐ | 第 1 |
| 管材（焊管/方管） | 60%+ | ⭐⭐⭐⭐ | 第 2 |
| 型材（H 型/工字/角槽） | 50%+ | ⭐⭐⭐⭐ | 第 2 |
| 冷轧/镀锌 | 40% | ⭐⭐⭐ | 第 3 |
| 热轧卷板 | 30% | ⭐⭐ | 第 4 |
| 螺纹钢 | 20% | ⭐ | 第 5（最难） |

### 机制 10：买家"承诺采购"机制（高级玩法）

```
【货袋子优采计划】 - 针对企业级买家

买家承诺：
  - 月度采购预算 ¥200 万-¥1000 万
  - 至少 30% 通过平台

平台提供：
  - 专属买手（钢贸老炮）一对一服务
  - 定制化卖家匹配（不进公开池）
  - 价格保护
  - 担保账期（30-90 天）
  - 财税票据合规支持
```

### 机制 11：明确告诉卖家"询价不买是常态"（预期管理）

入驻协议明确写：

```
《货袋子卖家入驻须知》

请您理性预期：
- 钢铁 B2B 行业特性决定，买家询价的总体成交率约 10-15%
- 这是行业客观规律，不是平台失误
- 平台帮您做的是：把这 15% 的真实需求精准匹配到您

我们承诺：
- 帮您过滤掉 60% 的低质询价
- 把您的报价匹配给最有可能成交的买家
- 帮您积累私域客户池，长期培养

我们不承诺：
- 100% 询价都会成交
- 短期内大幅提升业务
```

### 机制 12：长尾激励——询价激活金

```
卖家每被有效询价 1 次（哪怕不成交）：
  - 系统记录 1 次"潜在客户接触"
  - 平台拨入 ¥1-3 元到卖家"询价激活金"
  - 累计可用于：
    * 抵扣会员费
    * 兑换流量曝光
    * 提现（满 ¥500 起）

资金来源：买家付费询价费、平台流量费、会员费的一部分
```

## 五、调整后的商业模式

| 收入项 | 占比目标（M12） | 来源 |
|--------|------------|------|
| 卖家会员费 | 20% | 基础服务 |
| 买家询价付费 | 25% | 比价宝/找货宝/悬赏单 |
| 行情订阅 | 15% | 摸价党变现 |
| 流量曝光费 | 20% | 卖家差异化营销 |
| 增值服务（CRM/担保/数据） | 15% | 双边都付 |
| 大客户专属服务 | 5% | 优采计划 |

## 六、5 个判断时刻（不能让步）

1. 买家投诉"询价太贵" → **不能让步**。免费是 B2B 平台的毒药。
2. 业绩压力大放宽询价规则冲 GMV → **不能让步**。
3. 投资人要看"撮合 GMV" → **教育投资人**，B2B 看 take rate 和卖家 NPS。
4. 竞品用低价补贴 → **让他们烧**，你做服务深度。
5. 大客户要"独家撮合"或"自营" → **可以做"专属服务"但绝不做"自营"**。

## 七、核心战略心智

> **B2B 平台想"全面替代"买家固定供应商是死路。
> 把自己定位成"补充渠道"——应急、特殊、试探、小单——是活路。
>
> 接受买家"7 成询价不买"是行业常态，但用产品机制把这 7 成里：
> - 70% 筛走（询价分级/信用分/卖家选择）
> - 20% 转化为长尾价值（数据/订阅/积分）
> - 10% 慢慢培养成长期客户
>
> 让卖家从"被询价折磨"变成"积累客户池"。
> 让买家从"白嫖摸价"变成"渐进试单"。
> 让平台从"撮合工具"变成"关系培育器"。**
