# 四大增长引擎详细方案

> 货袋子的飞轮模型由四个引擎驱动，缺一不可。

## 飞轮模型

```
卖家增加 → 资源丰富 → 买家来 → 询盘增加 → 卖家收益 → 卖家续费 + 邀请新卖家
        ↑                                ↓
   反向邀请                          流量费变现
        ↑                                ↓
   群运营激活买家  ←——————————  数据沉淀&工具
```

四大引擎：
1. **悬赏找货**（撮合核心）
2. **企微群激活**（流量入口）
3. **反向邀请**（裂变引擎）
4. **流量费**（变现引擎）

---

## 引擎一：悬赏找货（撮合核心）

### 1. 为什么这是最关键功能

当前货袋子只有"卖家发库存（橱窗）"单向通道——本质是**展示型平台**。而钢贸买家的真实采购路径是"我有具体需求 → 让多家来报价 → 选一家成交"。

**没有它，买家来一次就走，留不下来**。

### 2. 核心用户故事

> 作为一个钢结构厂采购经理，**我需要**周一上午快速拿到 5 家以上唐山热轧 Q235B 5.5mm 现货报价，**以便**当天下午定生产排程。

### 3. 完整流程

```
[买家] → 发布需求（30秒填完）→ 系统智能派单 → [N个匹配卖家手机推送]
   ↓                                                    ↓
   |←──── 10-30 分钟内聚合报价 ←──── [卖家秒级响应报价]
   ↓
[买家] 比价/查看卖家信用 → 主动联系 1-3 家 → 线下议价 → 成交回填
   ↓
[平台] 沉淀需求数据、报价数据、成交数据 → 反哺定价/匹配算法
```

### 4. 关键产品要素

- **买家发需求页**：要求 30 秒填完，9 个字段（5 个必填）
- **卖家接单页**：强通知（App + 短信 + 企微机器人三通道）
- **买家收单页**：报价聚合，按价格升序，**不显示卖家电话**（强制走平台 IM/电话中继）

### 5. 智能派单算法（MVP 规则版）

```
score = 0.35 × 品类匹配度
      + 0.20 × 距离衰减
      + 0.15 × 卖家活跃度
      + 0.15 × 卖家信用分
      + 0.10 × 响应速度
      + 0.05 × 库存匹配度
```

### 6. 「悬赏」加价层

| 档位 | 价格 | 权益 |
|------|------|------|
| 普通 | 免费 | 30 个卖家推送、30 分钟聚合 |
| 加急 | 9.9 元 | 60 个卖家推送、10 分钟必有 ≥3 报价 |
| 悬赏 | 99 元 | 全网精准匹配、置顶、卖家可见悬赏标识 |

> ⚠️ **注**：买家付费方案在 `04-3` 中被推翻，最终改为买家全免费。

### 7. 防脱媒机制

- 联系方式中继（虚拟号 + 平台 IM 前 3 次必走）
- 报价水印（PDF 带追踪码）
- 成交回填激励（双方各得积分/服务券）
- 服务深度锁定（电子合同、磅单、运费比价、账期金融）

### 8. 三阶段路线图

| 版本 | 周期 | 核心 |
|------|------|------|
| V1 MVP | 4-6 周 | 发需求 + 规则派单 + 聚合报价 + IM 中继 |
| V2 | 8-12 周 | 悬赏档位 + 卖家信用分 + 电子合同 + 运费聚合 |
| V3 | 16-24 周 | 智能比价 + 历史价格曲线 + 担保交易 + 账期对接 |

详细 PRD 见 `02-1-悬赏找货PRD-v1.md`，后续被 `04-4` 升级为「采购会话」模型。

## 引擎二：2000 企微群激活

### 1. 重要性

2000 个企微群覆盖 ~10 万钢贸圈用户。行业第三方平均启动新群成本：¥8000/群。这块资产价值的市场估值：**¥1.6 亿（沉默资产）**。

### 2. 分级与运营策略

| 分级 | 标准 | 占比目标 | 策略 |
|------|------|------|------|
| S 级 | 群人数≥80 且日均发言≥30 | 15% | 撮合主战场 |
| A 级 | 群人数≥50 且日均发言 5-30 | 25% | 内容唤醒 |
| B 级 | 群人数≥30 且日均发言 1-5 | 35% | 钩子重启 |
| C 级 | 死群 | 25% | 合并/重建 |

### 3. 内容日历

**每日**：
- 07:50 早安+今日钢厂出厂价
- 09:30 区域成交价快讯
- 14:00 行业要闻+点评
- 16:30 收盘行情+明日预判
- 20:00 今日低价货

**每周**：
- 周一 上周区域成交分析
- 周三 悬赏找货案例
- 周五 周末闭门会预告
- 周日 钢厂排产/检修汇总

**每月**：
- 月初 区域行情白皮书
- 月中 线上行情闭门会
- 月末 月度采购明星榜单

### 4. 人力配置

| 角色 | 人数 | 月成本 |
|------|------|------|
| 内容主编 | 1 | ¥2-3 万 |
| 内容编辑 | 2 | ¥1.6-2.8 万 |
| 群运营专员 | 5-8 | ¥3-8 万 |
| 数据/工具 | 1（兼） | ¥1-1.5 万 |
| 外部分析师 | 2-3（兼） | 按篇 |
| **合计** | **9-12** | **¥8-15 万/月** |

### 5. 群裂变机制

- 群主介绍新群进入平台，提供：每日免费行情包、群主排行榜+奖品、官方"金牌群主"认证
- 目标：6 个月内从 2000 群扩到 4000 群（**不靠投放，靠群主带群**）

详细执行 SOP 见 `03-2-运营SOP操作手册.md`。

## 引擎三：反向邀请（裂变引擎）

### 1. 设计原则

1. **双边激励**：只奖卖家、不给买家好处，卖家拉不动
2. **分梯度**：拉来人不算数，要"有行为"才算数
3. **可结算**：当周结算、当周到账
4. **有上限**：单卖家月度上限保护财务

### 2. 五级激励梯度

| 里程碑 | 判定 | 卖家奖励 | 买家奖励 |
|--------|------|---------|---------|
| M1 注册 | 买家完成注册+认证 | 30 元券 | 50 元运费券 |
| M2 首发需求 | 7 天内首次询盘 | 50 元券 | 30 元积分 |
| M3 有效互动 | 14 天内有效沟通 | 100 元券 | / |
| M4 首单成交 | 30 天内 ≥5 万元 | 300 元现金 | 200 元券 |
| M5 月活买家 | 次月仍活跃 | 200 元/月×3 个月 | 优质买家认证 |

总价值：拉一个真实买家，卖家最高 ¥1080，买家最高 ¥280。

### 3. LTV/CAC 测算

- 单买家月均下单 GMV：¥50 万
- 平台 take rate：0.5%
- 单买家 LTV ≈ ¥30,000
- 卖家最高奖励 ¥1080 ≈ **CAC 占 LTV 的 3.6%**（远低于行业 30% 健康线）

详细财务模型见 `02-3-反向邀请财务模型.md`。

### 4. 反作弊规则

- 法人/身份证/银行账号同源 → 关系作废
- 同设备指纹 → 作废
- 同 IP 24h 内多账号 → 人工审核
- 被邀请人 7 天内仅有邀请关系激活动作 → 作废
- 单卖家邀请买家中 >60% 只跟自己沟通 → 标记并减半激励

详细反作弊见 `03-3-反作弊规则引擎.md`。

## 引擎四：流量费（变现引擎）

### 1. 为什么必须做、必须现在做

会员费是"租位费"，但卖家真正想付费的是「**线索/订单**」——这是高确定性的回报。流量费产品是把会员的"概率性收益"变成"按效果计价"。

> 找钢网当年没把流量费打磨好，靠会员+少量增值勉强支撑，take rate <0.3%。**你的窗口在这里**。

### 2. 产品矩阵

| 产品 | 形态 | 定价 |
|------|------|------|
| CPL 线索包（核心） | 充值，按有效线索扣费 | 8-30 元/条 |
| CPM/CPC 曝光位 | 自助竞价/保量套餐 | CPM 30-80 元/千次 |
| 精准订阅 | 月费订阅匹配品类+区域 | 199-999 元/月 |

### 3. 三步走

| 阶段 | 周期 | 重点 |
|------|------|------|
| 定价测试 | M0-M3 | 30 家封闭测试，目标续充率≥60% |
| 放量 | M4-M6 | 全网放开，差异化定价 |
| 精细化 | M7-M12 | 竞价系统、ROI 看板、增值服务 |

### 4. 关键规则

- **会员保底**：会员卖家每月送 30-100 条免费线索
- **新卖家保护期**：新入驻 30 天内免费 50 条
- **线索分配公平**：竞价+信用+响应速度排序，不能纯钱多者得
- **退款 SLA**：申诉 24h 内处理、48h 内退款

详细定价见 `02-4-流量费定价表.md`。

## 跨模块联动

```
       ┌──────────────────────┐
       │  企微群（2000→5000）  │ ← 流量入口
       └──────────┬───────────┘
                  │ 转化
                  ↓
       ┌──────────────────────┐
       │   悬赏找货（撮合核心）  │ ← 留存场景
       └──────────┬───────────┘
                  │ 沉淀数据
                  ↓
       ┌──────────────────────┐
       │  反向邀请（裂变引擎）   │ ← 卖家驱动买家
       └──────────┬───────────┘
                  │ 验证商业价值
                  ↓
       ┌──────────────────────┐
       │   流量费（变现引擎）   │ ← 商业闭环
       └──────────────────────┘
```

**联动节奏**：
- M1：先做企微群分级 + 悬赏找货 MVP
- M2：反向邀请 + 群运营 SOP 跑通
- M3：流量费灰度测试
- M6：四块完整联动，进入规模化期
