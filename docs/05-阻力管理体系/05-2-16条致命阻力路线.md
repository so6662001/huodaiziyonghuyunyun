## 项目治理结构

```
CEO（终极负责人）
   ├── FA-12 卖家委员会（亲自牵头）
   └── 周度 Review 全部 16 个项目

每周一 10:00 项目协调会（45 分钟）
   - 16 个项目 Owner 站会
   - 每人 2 分钟：进度、风险、求助

每月最后一周 大 Review（2 小时）
   - 项目延期 → CEO 介入
   - 数据未达标 → 复盘原因
   - 跨部门资源 → 总动员协调
```
