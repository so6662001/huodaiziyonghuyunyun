# 卖家委员会议题包

## 一、运作机制

### 1.1 委员会构成

```
首届委员会：21 人
任期：1 年（季度评估，半年可补缺）
津贴：每年 ¥3-5 万咨询费 + 平台股权激励池

构成原则：
- 区域代表 9 人（唐山 3、天津 3、聊城 2、邯郸/临沂 1）
- 品类代表 8 人（板材 2、螺纹 2、管材 2、型材 2）
- 规模代表 4 人（头部 1、中型 2、小型 1）

不进入委员会的人选：
- 平台员工
- 平台投资人
- 直接竞品的关联方
```

### 1.2 会议节奏

```
正式闭门会议：每季度 1 次（2 天，封闭式酒店）
线上月度沟通会：每月 1 次（2 小时）
临时议题会议：重大事件 48 小时内召集
年度大会：每年 1 次（含晚宴，含家属）
```

### 1.3 决策机制

```
A 类（必须委员会通过）：
- 平台收费/定价规则变更
- 卖家利益相关规则
- 重大产品功能影响交易的
通过门槛：21 票中 ≥ 14 票

B 类（委员会评议但平台保留终决）：
- 平台战略方向调整
- 重大融资动作
- 新业务拓展
评议方式：意见列入决议

C 类（仅通报）：
- 日常运营动作
- 营销活动
- 不涉及卖家利益的产品更新
```

### 1.4 议事规则

```
1. 主持人：CEO 或 COO 主持，但不主导意见
2. 发言顺序：抽签决定，避免"老大哥效应"
3. 投票：匿名电子投票（保护少数派）
4. 录音：所有正式会议录音，归档保存
5. 纪要：每次会议出纪要，48 小时内全员确认
6. 决议执行：CEO 必须出"执行计划"，下次会议汇报
```

第一条：永不与卖家竞争
  - 平台永不做自营货权交易

  - 平台永不强制独家入驻

- 这三条够不够？还有什么应该加进去？

## 四、临时议题召集机制（应急预案）

```
触发条件（满足任一即可临时召集）：

A. 卖家集体反弹信号：
   - 某区域响应率突降 > 20%
   - 一周内同区域 ≥ 5 名卖家退会员
   - 商会发函或公开质疑

B. 重大规则变更：
   - 收费上调
   - 大型功能调整
   - 隐私/合规重大变化

C. 委员会成员 1/3 联名提议

召集 SOP：
T+0     CEO 紧急联络全体委员
T+48h   线上紧急会议
T+72h   决议出炉
T+1w    决议执行启动
```

## 五、委员候选人提名标准（用于第 3 周提名）

## 七、委员会的政治智慧

```
1. 永远把委员当"自己人"，不要当"对立面"
2. 委员的反馈无论多刺耳，必须公开记录、48h 内回应
3. 委员违反保密义务（如泄露竞争数据），开除
4. 委员的家庭/生日/重要日子，CEO 个人记账
5. 委员退出时给"光荣退役"待遇，不撕破脸
6. 不要试图收买委员，钢贸圈最讨厌"被收买"的感觉
7. 让委员之间彼此熟悉（含家属），形成"货袋子委员会"的圈子文化
```
