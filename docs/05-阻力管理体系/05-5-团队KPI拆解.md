# 每个团队的专属阻力 KPI 拆解

## 团队总览

```
产品团队：负责 35 条阻力（操作/交互/产品功能类）
运营团队：负责 18 条阻力（心理/认知/关系/活动类）
技术团队：负责 8 条阻力（性能/移动端/集成类）
风控团队：负责 12 条阻力（信任/合规/作弊类）
商务团队：负责 14 条阻力（制度/付费/大客户类）
法务/合规：负责 6 条阻力（政策/数据/合规类）
CEO 直管：4 条致命阻力（战略/政治）
```

| 阻力 | 等级 | 直管原因 |

### CEO 个人 OKR

```
O1：守住战略红线
```

## 八、跨团队协作机制

### 每周一上午 10:00：阻力清单 Weekly

```
时长：45 分钟
参会：所有 VP + 阻力 Owner + CEO

议程：
1. 78 条阻力中"状态变化"项过一遍（10 分钟）
2. 致命阻力 16 条本周进展（20 分钟）
3. 红色/橙色预警信号处置（10 分钟）
4. 跨团队协作事项（5 分钟）
```

### 每月最后周五：阻力清单 Monthly Review

```
时长：2 小时
参会：全员

议程：
1. 月度用户访谈洞察分享（20 分钟）
2. 阻力状态全面更新（30 分钟）
3. 新发现阻力录入（20 分钟）
4. 优先级重新排序（20 分钟）
5. 下月攻坚项目 Owner 分配（30 分钟）
```

### 每季度：阻力清单战略对齐

```
时长：半天
参会：核心团队 + 部分卖家委员

议程：
1. 季度阻力清单大盘点
2. 战略调整建议
3. 下季度 OKR 与阻力联动
4. 关键人事/组织调整
```
