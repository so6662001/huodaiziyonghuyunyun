# 用户阻力全清单（78 条）

> 货袋子项目最重要的战略文档。每周更新，月底审视。这份清单的设计目标：团队任何成员（产品/运营/技术/CEO）都能拿来用；任何新功能上线前都可以对照检查；任何用户流失/数据下滑都可以快速定位。

## 一、总览

```
买家侧阻力（38 条）：从认知到深度使用的全旅程
卖家侧阻力（24 条）：从入驻到长期留存的全旅程
组织/制度阻力（6 条）：企业流程层面的硬约束
行业生态阻力（5 条）：微信/找钢网/商会等外部生态
技术/产品阻力（3 条）：移动端/网络/学习成本
宏观环境阻力（2 条）：周期/政策不可抗力
```

## 二、严重性分级

| 等级 | 标记 | 含义 | 数量 |
|------|------|------|------|
| 致命 | 🔴 | 不解决项目就死 | 16 条 |
| 严重 | 🟠 | 不解决留存崩盘 | 23 条 |
| 中等 | 🟡 | 不解决体验差 | 31 条 |
| 轻度 | 🟢 | 后期优化即可 | 8 条 |

## 三、解决状态

| 标记 | 含义 |
|------|------|
| ✅ | 已有方案 |
| 🔧 | 部分覆盖 |
| ❓ | 待解决 |
| ⚠️ | 监控中（暂无完美解法） |

## 十、使用机制

### 1. 新功能上线前的"阻力体检"

任何 PRD 评审前，先做这套题：

```
□ 这个功能解决了哪些阻力？（列编号）
□ 这个功能会引入新的阻力吗？（列编号）
□ 致命阻力中有几条被解决/缓解？
□ 是否经过卖家委员会评议？（如涉及）
□ 是否经过买家小样本测试？
```

### 2. 每周一的运营周会

```
1. Review 24 个监控信号，红/橙色立即处置
2. 上周新发现的阻力（动态更新清单）
3. 致命阻力 16 条的进展百分比
4. 矩阵图第一象限项目的本周交付
```

### 3. 每月一次的"用户阻力深访"

- 抽样 10 个卖家、10 个买家做 1 对 1 深访
- 必问问题："过去 30 天，用平台时最让你不爽的事是什么？"
- 新发现阻力 → 加入清单
- 已解决阻力 → 标记 ✅

详见 `05-3-用户深访问卷.md`。

### 4. 每季度的"清单大盘点"

- 重新评估每条阻力的等级
- 删除已经过时的阻力
- 新增近期发现的阻力
- 更新解决方案
- 给 CEO + 董事会做战略汇报

### 5. 团队分配

```
产品团队：所有"操作/交互"类阻力（B-C/D/E、S-B/C）
运营团队：所有"心理/认知/关系"类阻力（B-A、S-A/D）
技术团队：所有"性能/移动端"类阻力（T-1/2/3）
风控团队：所有"信任/合规"类阻力（B-D5、S-C4）
商务团队：所有"组织/制度"类阻力（O 全部）
CEO 直管：所有 🔴 致命阻力 + 区域风险信号
```

详见 `05-5-团队 KPI 拆解.md`。

## 十一、还有哪些阻力可能漏了？（开放命题）

以下场景需要团队补充：

1. **会计/财务实务**：钢贸圈的票据潜规则（如"票货分离"）
2. **黑灰产风险**：钢贸圈是否存在"刷单/洗钱/虚开"等灰色业务
3. **采购员"个人收益"的合规边界**：钢贸圈历史上的"回扣文化"
4. **特殊地域文化**：天津、唐山、聊城三地的钢贸圈文化差异
5. **女性采购员/年轻采购员的比例**：行业人口结构对产品设计的影响
6. **大宗物流的真实痛点**：货物运输、磅单、保险的具体阻力

建议列入下次卖家委员会和买家深访的核心议题。

## 十二、终极价值

> **第 1 句**：货袋子能不能跑通，不取决于产品有多漂亮，**取决于 16 条致命阻力能不能解决**。
>
> **第 2 句**：每解决一条致命阻力，是一次"破局"；**每忽视一条致命阻力，是一道"催命符"**。
>
> **第 3 句**：**这份清单要每周看、每月更新、每季度大盘点**。它比 OKR 更重要、比 PRD 更基础，是货袋子真正的"宪法附件"。
