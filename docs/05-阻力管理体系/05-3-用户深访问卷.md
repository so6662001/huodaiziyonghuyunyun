# 用户阻力深访问卷模板

## 使用说明

| 项 | 内容 |
|---|---|
| 频次 | 每月 1 次，每次 20 个用户（10 买家 + 10 卖家） |
| 方式 | 1 对 1 电话访谈（45-60 分钟），录音征得同意 |
| 访谈人 | 用户研究/产品/运营轮值 |
| 输出 | 文字纪要 + 阻力清单更新 + 月度报告 |
| 报酬 | 受访者获得 ¥200 京东卡 |

---

## 一、买家深访问卷（采购员/采购经理版）

### 第一部分：暖场（5 分钟）

```
Q1. 您好张总，先跟您聊几句轻松的，您在公司主要负责什么品类的采购？

Q2. 您从事钢贸采购多久了？

Q3. 您每天大概花多少时间在询价和采购沟通上？

Q4. 您最常用的采购沟通工具是什么？（微信/电话/邮件/平台）
   - 排序 Top 3

Q5. 在所有沟通工具里，您最喜欢的是哪个？为什么？
```

### 第二部分：现状探测（10 分钟）

```
Q6. 我们看您注册货袋子是 X 月，到现在用了 Y 次需求。
    您还记得第一次用的感受吗？

Q7. 您发完需求后多久收到第一条报价？
    跟您打电话比，您觉得快还是慢？

Q8. 您觉得平台上的卖家可信吗？您是怎么判断的？

Q9. 您一般找采购线索的渠道有几个？平台是排第几？

Q10. 您最近的一笔大额采购是怎么完成的？
     有没有上货袋子？没有的话原因是什么？
```

### 第三部分：阻力探测（25 分钟）

#### A. 发需求/操作阻力

```
Q11. 您觉得在货袋子上发需求快吗？跟微信对比怎么样？
     - 听到"麻烦/慢/不顺"的关键词，深挖。

Q12. 如果您要发一张 20 行的清单，您会怎么做？
     - 看回答是 Excel/拍照/平台填，记录他的真实路径。

Q13. 您发完需求后，需求变了的话您怎么改？
     - 探测"重新发"vs"修改"的具体动作。
```

#### B. 报价/对比阻力

```
Q14. 您拿到多家报价后，是怎么对比的？
     - 探测"看不懂/难比"的痛点。

Q15. 您怎么挑哪家卖家可信？您看什么信息？
     - 探测信用分/视频/历史成交是否管用。

Q16. 价格最低的那家您一定会选吗？还是看综合？
     - 探测综合方案 vs 单纯比价的真实决策。
```

#### C. 沟通/议价阻力

```
Q17. 您和卖家议价的时候，平台上的体验怎么样？
     - 跟微信比哪个顺？

Q18. 平台 IM 您用得多吗？还是直接打电话？
     - 探测使用习惯。
```

#### D. 决策/试单阻力

```
Q19. 您试单一般什么情况下会下决心？
     - 探测"老供应商没货"vs"价格差很大"的真实驱动。

Q20. 第一次跟新卖家成交，您最担心什么？

Q21. 您试单成交后会跟老板汇报吗？老板怎么反应？
     - 探测内部阻力。
```

#### E. 长期使用阻力

```
Q22. 您未来会更多用货袋子，还是更多打电话/找钢网？

Q23. 什么情况下您会推荐同行也来用？

Q24. 您觉得货袋子哪里值得收费？哪里收费您不愿付？
```

#### F. 致命阻力直击

```
Q25. 假设您公司明天要换 1 个新供应商，要走多少流程？
     - 探测"入库流程"的真实周期。

Q26. 您个人在公司用货袋子，会不会担心同事/老板有意见？
     - 探测面子/政治阻力。

Q27. 如果出了质量问题，您觉得货袋子能管用吗？
```

### 第四部分：开放追问（10 分钟）

```
Q28. 您觉得货袋子最值得的一个功能是什么？为什么？

Q29. 您觉得货袋子最让您"不想用"的地方是什么？为什么？

Q30. 如果让您给货袋子提一个最重要的改进建议，您会提什么？

Q31. 如果您是货袋子的 CEO，您会怎么打开钢贸圈采购员的市场？
```

### 第五部分：结尾与确认（5 分钟）

```
Q32. 我们今天聊的内容能用于产品改进吗？您是否同意？

Q33. 后续如果产品有重大更新，我们可以单独发您体验吗？

Q34. 您愿意被推荐为"用户体验顾问"吗？（季度报酬 ¥500）

Q35. 您身边有没有其他采购员朋友也愿意聊一聊？
```

## 二、卖家深访问卷（贸易商老板/业务员版）

### 第一部分：暖场（5 分钟）

```
Q1. 王总您好，您家公司主营什么品类？
Q2. 您做钢贸多少年了？
Q3. 您家公司一年的销售量大概多少吨？
Q4. 您每天大概接多少询价电话？多少微信？
Q5. 您觉得现在做钢贸最难的事情是什么？
```

### 第二部分：入驻/认知阻力（10 分钟）

```
Q6. 您当初是怎么知道货袋子的？

Q7. 您当时听到"线上平台"的第一反应是什么？
   - 探测"又是找钢网"的心智阴影。

Q8. 您交了会员费后心里有底吗？担心啥？

Q9. 您身边的同行有几个用货袋子？大家私下怎么聊？
   - 探测同行口碑。

Q10. 您家老板（如果不是老板）对货袋子怎么看？
```

### 第三部分：使用阻力（20 分钟）

#### A. 接单阻力

```
Q11. 您每天收到几条平台询价？有响应吗？

Q12. 您觉得收到的询价里，多少是真买家？多少是问问的？
     - 探测询价党感知。

Q13. 您一般什么样的询价愿意花心思报？什么样的直接跳过？

Q14. 您接单后，买家改需求的情况多吗？您怎么处理？
```

#### B. 利润阻力

```
Q15. 您觉得在平台上做生意，利润比线下高还是低？
     - 直击核心阻力。

Q16. 您报价的时候敢报真实底价吗？

Q17. 您觉得"比价"对您是好事还是坏事？

Q18. 您身边的同行有没有抱怨过平台压利润？
```

#### C. 区域/同行阻力

```
Q19. 您觉得货袋子上的外地卖家会抢您本地客户吗？

Q20. 您和本地同行私下有"价格联盟"或者"互相介绍"的习惯吗？

Q21. 您觉得货袋子如果做得越来越大，您和同行的关系会怎么样？
```

#### D. 商业模式阻力

```
Q22. 您觉得货袋子收会员费合理吗？多少合理？

Q23. 如果货袋子按"线索付费"收费，您愿意吗？

Q24. 您最希望货袋子提供什么服务来"帮您赚钱"？
```

#### E. 致命阻力直击

```
Q25. 假设货袋子哪天搞了一个让您不满的规则，您会怎么做？
     - 探测反弹路径（默默退出/找运营/找商会/串联同行）

Q26. 您听说过找钢网当年发生的事情吗？您怎么看？

Q27. 您身边有没有同行因为受不了平台而退出的？为什么？

Q28. 您觉得货袋子和找钢网的最大区别是什么？
     - 探测差异化定位是否传达到位。
```

### 第四部分：开放追问（10 分钟）

```
Q29. 您最希望货袋子帮您做的一件事是什么？

Q30. 您最不希望货袋子做的一件事是什么？

Q31. 假设您是货袋子的 CEO，您会怎么对待卖家？

Q32. 您愿意加入"卖家委员会"吗？为什么？
```

### 第五部分：结尾（5 分钟）

```
Q33. 我们今天聊的内容能用于产品改进吗？
Q34. 后续您可以接受我们每月一次的回访吗？
Q35. 您身边的同行有没有谁也愿意聊？
```

## 三、访谈结果月度分析模板

```
《货袋子用户阻力月度报告 - YYYY-MM》

1. 本月访谈概览
   - 买家 10 名：覆盖 X 行业 / Y 区域 / Z 规模
   - 卖家 10 名：覆盖 A 品类 / B 区域 / C 规模

2. 阻力命中分布（柱状图）
   - Top 5 高频阻力
   - 上月对比变化

3. 新发现的阻力
   - 新阻力 1
   - 新阻力 2

4. 已"解决"阻力的真实反馈
   - 用户是否感受到改进？

5. 阻力等级调整建议
   - 哪些阻力等级应提升？哪些可降低？

6. 关键用户故事（3-5 个真实案例）

7. 下月行动建议
```

## 四、访谈技巧（给访谈人）

1. **不要引导**：不要问"您觉得货袋子很好用吧？"，问"您觉得货袋子怎么样？"
2. **多用 Why**：用户说"麻烦"，追问"具体哪里麻烦？最近一次是什么场景？"
3. **真实故事 > 抽象描述**：让用户回忆"最近一次发生的事"
4. **沉默是金**：让用户充分表达，不要打断
5. **录音先征同意**：开始前明确告知"为了我们更准确记录，能录音吗？"
6. **不要辩解**：用户批评产品时，不要为产品辩护
