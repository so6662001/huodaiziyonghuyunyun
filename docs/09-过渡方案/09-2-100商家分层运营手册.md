# 100+ 商家分层运营手册

> 配套 `09-1-双引擎过渡方案.md` 使用。**这是落地的执行手册**。

## 一、分层基本盘（M0 准备）

### 1.1 数据拉取（Week 0）

由数据团队从平台数据库拉取：

```sql
SELECT
  c.company_id,
  c.name AS 商家名,
  c.city AS 城市,
  c.industry AS 主营,
  m.created_at AS 入驻日,
  m.end_date AS 会员到期日,
  -- 活跃度
  (SELECT COUNT(*) FROM login_logs WHERE user_id=u.user_id AND created_at > NOW() - INTERVAL 30 DAY) AS 月登录次数,
  (SELECT COUNT(*) FROM inventory WHERE seller_id=u.user_id AND created_at > NOW() - INTERVAL 30 DAY) AS 月发库存数,
  (SELECT COUNT(*) FROM inventory WHERE seller_id=u.user_id AND status='active') AS 当前库存条数,
  -- 业务量
  (SELECT SUM(amount) FROM deals WHERE seller_id=u.user_id AND created_at > NOW() - INTERVAL 90 DAY) AS 90日成交额,
  -- 联系信息
  u.phone AS 手机,
  u.name AS 联系人,
  m.tier AS 会员级别
FROM companies c
JOIN user_company_mappings ucm ON ucm.company_id=c.company_id AND ucm.role='owner'
JOIN users u ON u.user_id=ucm.user_id
LEFT JOIN memberships m ON m.seller_id=u.user_id AND m.status='active'
WHERE c.verified=1
ORDER BY 月登录次数 DESC, 月发库存数 DESC;
```

### 1.2 分层规则

| 分层 | 月登录 | 月发库存 | 90日成交 | 预计占比 |
|---|---|---|---|---|
| **A 核心活跃** | ≥ 10 次 | ≥ 20 条 | 任意 | 20-30 家 |
| **B 稳定活跃** | 5-9 次 | 5-19 条 | 任意 | 30-40 家 |
| **C 低频** | 1-4 次 | 1-4 条 | 任意 | 20-30 家 |
| **D 休眠** | 0 次（30 日内） | / | / | 20+ 家 |

### 1.3 输出格式（飞书表格）

```
| 商家ID | 商家名 | 城市 | 分层 | 月登录 | 月发库存 | 90日成交 | Owner | 状态 | 备注 |
|--------|--------|------|------|--------|---------|---------|-------|------|------|
| c_001  | 唐山 X | 唐山 | A    | 23     | 45      | ¥86万   | CEO   | 待联系 |      |
| c_002  | 天津 Y | 天津 | A    | 18     | 38      | ¥120万  | CEO   | 待联系 |      |
| ...    |        |      |      |        |         |         |       |       |      |
```

## 二、A 类商家：核心活跃（CEO 亲自打）

### 2.1 名单原则

- 数量上限：30 家（CEO 时间精力有限）
- 优先级排序：90 日成交额 > 月发库存数 > 月登录次数
- 排除：与货袋子有过严重纠纷的（先内部沟通）

### 2.2 CEO 拜访 SOP

#### 准备工作（拜访前 24h）

```
查阅：
  ✅ 该商家入驻历史
  ✅ 历史发库存数据
  ✅ 历史成交记录
  ✅ 客户成功的沟通记录
  ✅ 是否有过投诉

准备资料：
  ✅ 一张写有商家专属数据的卡片（如：累计帮您发布 234 条库存）
  ✅ 一份"内测合伙人"邀请函（PDF）
```

#### 拜访话术（电话或上门）

##### 开场（5 分钟）

```
"王总您好，我是货袋子 CEO 张三。我专门留出时间想跟您聊聊。

您从 X 月入驻以来，累计发布了 234 条库存，
是货袋子在唐山热轧品类排名前 5 的卖家。

我今天来的目的有 3 个：
  1. 听听您对货袋子这几个月的真实评价
  2. 给您介绍我们正在做的一个升级
  3. 邀请您做'内测合伙人'

您方便聊 30 分钟吗？"
```

##### 听声音（15 分钟）—— 最关键

CEO 主动问，**不要急着推销**：

```
问题 1（开放）：
  "您在货袋子上目前最不满意的是什么？"

问题 2（深挖）：
  "您每天的真实工作流是什么样的？您怎么找新客户的？"

问题 3（痛点）：
  "您觉得平台最应该改什么？"

问题 4（同行）：
  "您身边的同行也用货袋子吗？他们怎么评价？"

问题 5（期望）：
  "如果货袋子半年后做得很好，您希望它是什么样的？"

记录所有反馈，不打断，不辩解，不解释。
```

##### 介绍新模式（5 分钟）

```
"非常感谢您坦诚的反馈。我听到您说 [总结他的核心痛点]。
其实这也是我们这次升级的方向。

我们正在做一个新功能：
  - 之前是您发库存，等买家来看
  - 现在多了一个能力：买家可以主动来询您货的价

您不用做任何新操作。
您之前发的库存自动接到询价系统里。
就像您接电话一样，回复个价就行。

我们邀请您做'内测合伙人'，前 30 天免费送 50 条线索包。
不喜欢随时关掉，对您没有任何风险。

您觉得怎么样？"
```

##### 处理疑虑

| 卖家问题 | CEO 回应 |
|---|---|
| "和找钢网什么区别？" | "我们不抽佣，不下场自营，不挖您的客户。我会把这写进协议。" |
| "会不会让我利润变薄？" | "我们用'盲价'设计——买家看不到全网最低价，看的是综合方案。" |
| "我已经交了年费，新功能要再交吗？" | "免费送给您，老会员到期续费可选择新模式。" |
| "我能完全不用新功能吗？" | "完全可以，一键关闭。不会影响您的任何老权益。" |
| "外地卖家会抢我本地客户吗？" | "我们设了区域保护，您的本地客户不会被冲击。" |

##### 结束（5 分钟）

```
"非常感谢您今天的时间。

我承诺：
  1. 您今天反馈的所有问题，我会个人跟进
  2. 一周内给您一个详细回复
  3. 您是我们的'内测合伙人'，所有重大产品变更前会先听您意见

如果您愿意，我建议把您加入'卖家委员会'候选名单。
这个委员会有 21 人，对平台重大规则有评议权。
您愿意吗？"
```

### 2.3 拜访后行动（24h 内）

```
1. 整理拜访纪要（结构化）
   - 真实痛点（按优先级）
   - 期望
   - 担忧
   - 对新功能的态度

2. 录入"卖家声音库"（飞书表格）

3. 关键反馈分发给产品/运营

4. 24h 内给卖家发感谢信 + 关键反馈的回复

5. 7 天内邀请加入"内测合伙人"群（限 30 人）
```

### 2.4 A 类商家激励

| 项 | 内容 |
|---|---|
| 称号 | 「货袋子内测合伙人」（电子证书） |
| 物质 | 黑金会员免费 6 个月（市值 ¥3000+） |
| 流量 | 询价线索 50 条 + 5 折后续优惠 |
| 优先 | 优质池优先派单 |
| 影响 | 进入卖家委员会候选名单 |
| 长期 | 平台股权激励池（M12+ 评定） |

## 三、B 类商家：稳定活跃（客户成功 1 对 1）

### 3.1 时间安排

- 开始时点：M4 中（A 类种子运行验证通过后）
- 每天每个客户成功 4-5 家
- 8 个客户成功 × 5 天 = 80-100 家联系完毕

### 3.2 客户成功培训前置

每个客户成功上岗前必须培训：

```
培训内容（4 小时）：
  - 双引擎过渡方案完整理解
  - 新功能 demo + 实操
  - 100 个典型问题应答
  - 沟通话术 + 拒绝话术

考核：
  - 角色扮演（客户成功 vs 卖家）通过
  - 笔试 80 分以上
```

### 3.3 客户成功沟通 SOP

#### 联系节奏

```
Day 1: 短信预告
  "王总，我是货袋子客户成功小李。
   平台升级啦，您发的库存现在能自动接询价。
   我想约您 15 分钟简单介绍一下，您方便什么时候？"

Day 2-3: 电话沟通（15 分钟）
Day 4-7: 跟进 + 答疑
Day 14: 使用情况回访
Day 30: 价值复盘（您本月接到 X 条询价）
```

#### 电话话术（15 分钟版）

##### 第 1 分钟：自我介绍 + 价值钩子

```
"王总您好，我是货袋子小李，您的专属客户成功。

我打这通电话有件好事跟您说：
您之前发的库存，现在能自动接收买家询价了。
不用您学新东西，平台直接帮您匹配。

我跟您过一遍，5 分钟就懂。"
```

##### 第 2-5 分钟：演示

```
1. 让卖家打开手机
2. 引导进入「我的询价」标签
3. 演示一条样例询价
4. 演示「一键报价」功能
5. 演示「设置」中的开关位置（让他知道可以关）
```

##### 第 6-10 分钟：填写偏好

```
"我帮您把偏好设置好：
  - 您主营什么品类？[勾选]
  - 您服务哪些区域？[勾选]
  - 每天最多接多少单？[默认 20]
  - 工作时间外要不要接单？[默认否]

3 分钟就设置好了。"
```

##### 第 11-13 分钟：激励

```
"我们给老用户准备了专属礼包：
  - 50 条免费线索包（市值 ¥1000）
  - 后续询价 5 折（限 60 天）
  - 老用户专属客服群

这个礼包默认开通给您了。
您本周如果有任何问题，直接找我。"
```

##### 第 14-15 分钟：底线承诺

```
"最后我再跟您确认一下：
  - 您原来的会员权益完全不变
  - 您发的库存功能完全不变
  - 新功能您随时可以关闭
  - 不影响您任何老的服务

如果半个月后您觉得新功能不好用，告诉我，我帮您关掉。"
```

### 3.4 客户成功 KPI

| 指标 | 目标 |
|---|---|
| 联系成功率 | ≥ 80%（电话通） |
| 完成培训率 | ≥ 60% |
| 开通新功能率 | ≥ 50% |
| 30 天使用率 | ≥ 40% |
| 老用户投诉率 | < 5% |
| 老用户退会员率 | < 3% |

## 四、C 类商家：低频（自动化引导）

### 4.1 引导策略

```
不主动电话（节省人力）
通过自动化推送：

1. 推送（App push）：
   "您的库存可以自动接询价了，了解下？"

2. 短信（前 3 天）：
   "【货袋子】平台升级！您发的库存自动接询价。
    登录查看「💬 我的询价」，5 折线索礼包等您。"

3. 平台 banner：
   登录后首页置顶提示

4. 一键开通：
   - 平台后台默认勾选「接收询价」
   - 老用户首次登录看到引导浮层
   - 一键确认后开通
```

### 4.2 节奏

```
M5 Week 1:  全 C 类 + D 类推送
M5 Week 2:  跟进无反应的（再推一次）
M5 Week 3:  仍无反应的 → 默认开通
M5 Week 4:  自动监控使用情况
```

### 4.3 简化 KPI

| 指标 | 目标 |
|---|---|
| 推送送达率 | ≥ 95% |
| 7 日内查看率 | ≥ 30% |
| 30 日内使用率 | ≥ 20% |

## 八、典型问答库（FAQ）

### Q1：货袋子和找钢网什么区别？

```
"3 个区别：
  1. 我们永远不抽佣（找钢网巅峰期抽 0.3%）
  2. 我们永远不下场自营（找钢网做自营烧了几十亿）
  3. 我们有'卖家委员会'，所有重大规则都得过卖家评议"
```

### Q2：会不会让我利润更薄？

```
"我们设计了 5 道保护机制：
  1. 盲价匹配——买家看不到全网最低，看综合方案
  2. 区域保护——外地低价不会冲击本地
  3. 价格底线——低于市场价 8% 默认隐藏
  4. 卖家匿名——您报价不暴露真名
  5. 利润预警——报价时提示利润率

实际数据：我们种子卖家测试期间，利润率维持甚至提升。"
```

### Q3：我已经交了年费，新功能要再交吗？

```
"完全不用。
  - 您现在的会员费完全保留
  - 新功能在您会员期内免费用
  - 到期续费时可以选择继续老套餐 或 升级新套餐
  - 老用户专属升级价：黑金会员原价 ¥9800，老用户 ¥6800"
```

### Q4：我能完全不用新功能吗？

```
"完全可以，一键关闭。
  - 关闭后不影响任何老功能
  - 不影响会员权益
  - 不影响信用分
  - 我们 3 个月内不会再推送新功能消息给您
  - 您随时可以重新开启"
```

### Q5：买家发询价后，我能选择不接吗？

```
"完全可以。
  - 您可以设置「接单偏好」，只接您愿意接的
  - 您可以设置「不接询价池」（系统不会推询价党给您）
  - 您可以屏蔽特定买家
  - 您可以设置每日最多接单数"
```

### Q6：外地卖家会不会抢我本地客户？

```
"不会。我们设了区域保护：
  - 默认本地匹配（半径 300km 内优先）
  - 跨区匹配需要买家明确请求
  - 跨区卖家标记「跨区竞争者」
  - 监控跨区成交占比，过高时调整规则"
```

### Q7：找钢网当年发生的事会重演吗？

```
"我们对此非常警惕，写了 5 道红线：
  ❌ 永不做自营货权
  ❌ 永不做仓储/物流自建
  ❌ 永不抽交易佣金
  ❌ 永不做补贴战
  ❌ 永不向买家个人收费

这 5 条写进公司宪法，董事会决议级别。
您也可以加入卖家委员会，监督我们。"
```

## 九、关键执行原则（团队上墙）

1. **不打扰**：M1-M2 完全不打扰现有商家
2. **不破坏**：老功能 100% 保留，不删除任何东西
3. **不强迫**：新功能可关闭，老用户用熟悉的方式
4. **不偏袒**：老用户优先享有新功能补贴
5. **不一刀切**：按使用习惯分层运营
6. **不抽佣**：永远不抽交易佣金
7. **不下场**：永远不做自营
