# M7：卖家工具包

## 1. 模块目标

让卖家从"被动接询价"变成"主动经营客户"——平台不只是流量入口，更是卖家的**业务工具**。

子模块：
1. 接单偏好（M5 已涉及）
2. 私域 CRM（沉淀买家、跟进、复购）
3. 利润保护包（5 大保护功能）
4. 收益看板（ROI 可视化）
5. 视频/营销工具（库存展示、品牌推广）
6. 反向邀请工具（卖家拉买家）

## 2. 子模块 1：私域 CRM

### 2.1 设计理念

每一次询价（即使没成交），都是一次"潜在客户接触"。平台把这些接触自动沉淀到卖家的 CRM 里。

**心智转变**：卖家从"等饭吃"变成"自己挖矿"。

### 2.2 功能清单

```
我的客户列表
  ├── 全部买家（曾经询过价的）
  ├── 高潜买家（联系过 ≥3 次但未成交）
  ├── 成交客户
  ├── 老客户（成交 ≥3 单）
  └── 黑名单

对每个客户：
  - 询价历史（含规格、数量、价格）
  - 联系记录（IM/电话）
  - 成交记录
  - 标签（自定义 + 系统打标）
  - 跟进任务（日历提醒）
  - 备注（私密，仅卖家可见）

CRM 操作：
  - 一键发起新报价
  - 一键发促销通知（合规：仅老客户）
  - 一键查询历史价格
  - 一键导出客户档案
```

## 3. 子模块 2：利润保护包

### 3.1 5 大保护功能

#### 1. 利润预警

```
卖家报价时实时提示：

┌─────────────────────────────────────┐
│  💡 利润保护                          │
│                                     │
│  市场参考价：¥4280-4350/吨           │
│  您的报价：¥4280/吨                   │
│  估算利润率：约 1.8%                  │
│                                     │
│  ⚠️ 您的报价低于市场底线 8%以上       │
│     该报价可能被平台默认隐藏          │
└─────────────────────────────────────┘
```

#### 2. 价格底线红线（卖家自设）

```
卖家可设：
  - "我最低报价不低于 ¥4200/吨"
  - 低于此价的需求直接不参与（系统过滤）
  - 跨品类/区域可单独设置
```

#### 3. 品类锁定

```
"我只做螺纹钢" → 其他品类需求不打扰
  即使系统觉得"匹配度高"，也不会推送
```

#### 4. 客户屏蔽

```
- 黑名单买家（曾经爆雷）
- 询价党买家
- 同行买家（疑似探价）

被屏蔽的买家发需求时，卖家完全收不到通知
```

#### 5. 沉默时段

```
"周末/晚上 22:00 后不接单"
  - 仅紧急/悬赏单除外（可独立配置）
  - 卖家也要休息
```

## 5. 子模块 4：视频/营销工具

### 5.1 视频展示

```
卖家可上传：
  - 仓库实拍（必备）
  - 生产线（如有）
  - 团队介绍
  - 近期到货
  - 客户合作

每视频 ≤ 30 秒
平台 AI 自动质检（真实性、品质）
通过审核后展示在卖家详情页 + 提升信用分
```

### 5.2 库存动态

```
卖家可发布"库存动态"：
  - 新到货：[图片/视频] + 规格 + 数量
  - 促销：限时低价
  - 钢厂排产
  - 行业洞察

发布后：
  - 推送到老客户 CRM
  - 进入平台"今日低价货"池
  - 在卖家详情页公开
```

### 5.3 抖音/视频号分发

```
平台帮卖家把库存动态自动同步到：
  - 视频号
  - 抖音
  - 快手

可一键操作，文案 AI 生成。
```

## 8. 核心接口

```
# CRM
GET    /api/v1/sellers/me/customers              客户列表

POST   /api/v1/sellers/me/customers/{id}/tags    打标签
POST   /api/v1/sellers/me/customers/{id}/notes   备注
POST   /api/v1/sellers/me/follow-ups             创建跟进任务

# 利润保护
GET    /api/v1/sellers/me/protection             查询保护设置
PUT    /api/v1/sellers/me/protection             更新保护设置

# 收益看板

# 视频/营销

```
