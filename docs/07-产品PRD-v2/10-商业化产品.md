# M10：商业化产品

## 1. 模块目标

落地 6 大收入引擎，但**永不向买家个人收费**：

```
1. 卖家会员费（M0 已有）
2. 卖家流量费 CPL + CPM（M4 启动）
3. 卖家订阅（精准订阅，M6）
4. 卖家增值服务 CRM/营销工具（M9）
5. 买家企业 SaaS 供应商管理（M12）
6. 数据服务 + 金融分润（M18+）
```

### 2.3 升级路径

```

       └→ 普通会员（¥3000）
            └→ 黑金会员（升级补差价）
```

## 8. 子模块 7：金融分润

### 8.1 启动时点：M18+

**前提**：

- 已有 12 个月真实交易数据
- 已对接 1-2 家持牌金融机构
- 已通过监管合规审查

### 8.2 服务形态（合规优先）

```
平台不直接放贷，与持牌机构合作：

账期金融：
  - 买家延期付款 → 平台介绍保理公司
  - 卖家收当期款 → 保理公司接管账期
  - 平台分润 30-40%

采购贷：
  - 买家信用额度 → 来自银行/小贷
  - 平台提供数据（账期、复购、信用）
  - 平台分润 10-20%
```

### 8.3 风控红线

- ❌ 平台不放贷
- ❌ 平台不做资金池
- ❌ 平台不刚兑
- ✅ 仅做"数据 + 撮合"
- ✅ 仅与持牌机构合作

## 12. 商业化关键认知

### 12.1 商业模式与卖家利益对齐

| 错的设计 | 对的设计 |
|---|---|
| 抽交易佣金（卖家越累平台越赚） | 按服务收费（卖家赚钱平台才赚） |
| 卖家排名收费（鼓励内卷） | 按效果收费（CPL + 增值服务） |
| 强制收会员费 | 会员可选 + 试用 + 退款 |

### 12.2 买家付费的"合理化包装"

买家付费产品必须满足：

1. **对公审批容易通过**：是"采购管理工具"而不是"信息咨询费"
2. **价格够大**：¥3000/年起步，走年度采购预算

**禁止形态**：
- ❌ ¥9.9 询价费 / ¥99 加急费
- ❌ 任何小额、高频、个人感支付

**鼓励形态**：
- ✅ ¥3000+/年「供应商管理 SaaS」（对公）
- ✅ ¥30000+/年「大客户专属买手服务」（对公）

### 12.3 永远不做的事

- ❌ 抽交易佣金
- ❌ 自营
- ❌ 资金池
- ❌ 强制独家
- ❌ 个人买家收费

## 13. 价格调整机制

```
每月最后一周自动评估：
- 线索申诉率 > 18% → 该品类降价 10%
- 线索申诉率 < 6% 且供给紧张 → 涨价 10%
- 充值续充率 < 50% → 整体降价 + 推套餐

季度大盘评估：CMO 牵头评审

价格变动透明：
- 提前 15 天通知卖家
- 老客户有 30 天过渡期
- 重大调价需经卖家委员会评议
```
