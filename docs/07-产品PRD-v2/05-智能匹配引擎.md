# M5：智能匹配引擎 ⭐

> 平台的"大脑"。决定每个需求被谁看到、按什么顺序展示、什么时候推送。这是反卖家反弹 + 反询价党的核心机制。

## 1. 模块目标

- **算法分级**代替"付费筛选"（买家全免费）
- **盲价 Top 3** 代替"全网最低价排序"
- **区域保护**优先（防外地低价冲击本地）
- **卖家选择权**贯穿（不强迫接询价党）

## 2. 三级匹配池设计（核心创新）

### 2.1 三池规则

```
🔵 试水池（低质询价）
  触发条件：
    - 新买家首单（信用分默认 60）
    - 信用分 < 60
    - 历史 0 成交
    - 反复探价行为（同需求 ≥5 次）

  推送范围：3-5 家"愿意接询价练手"的卖家
  卖家视图：以"灰色卡片"展示，标"询价池"
  期待成交率：1-3%

🟢 标准池（默认池）
  触发条件：
    - 信用分 60-79
    - 完成基础认证

  推送范围：10-15 家匹配卖家
  卖家视图：正常展示
  期待成交率：8-15%

🟡 优质池（高质需求）
  触发条件：
    - 历史成交 ≥ 2 单
    - 30 天内联系卖家 ≥ 3 次
    - 信用分 ≥ 80

  推送范围：Top 15-20 家精准卖家
  卖家视图：以"金色卡片"突出 + 通知"优质买家来询"
  期待成交率：25-40%
```

**重要**：买家**完全不知道**自己在哪一级。

### 2.2 卖家分级

```
卖家信用分 = 100 起步，按行为加减：
+10  完成实地核验
+10  上传视频展示
+5   每月响应率 ≥ 80%
+3   每单按时交货
+2   每个好评
-5   未按时响应 ≥3 次
-10  报价偏离市场参考价 >15%（连续 3 次）
-20  被买家投诉且核实

分级：
  S 级（≥90）：优质池优先 + 大客户分配
  A 级（70-89）：标准池主力
  B 级（60-69）：试水池接单 + 标准池补位
  C 级（<60）：仅试水池，限制接单
```

## 3. 派单算法

### 3.1 综合匹配度公式（盲价匹配的核心）

```python
match_score = (
    0.30 * price_reasonableness(quote, market_ref)
  + 0.25 * seller.credit_score / 100
  + 0.15 * distance_decay(seller.location, demand.delivery_city)
  + 0.10 * historical_relationship(seller, buyer)
  + 0.10 * seller.response_speed_score
  + 0.10 * seller.value_added_services_score
)

# 重要：价格只占 30%！不是越低越好，越接近中位数越好
def price_reasonableness(quote, market_ref):
    deviation = abs(quote.price - market_ref) / market_ref
    if deviation < 0.05:
        return 100  # 接近中位价，满分
    elif deviation < 0.15:
        return 70   # 偏离合理
    elif deviation < 0.25:
        return 30   # 偏离较大
    else:
        return 0    # 异常报价（可能诱单低报）
```

### 3.2 派单流程

```python
def dispatch(session_id):
    session = get_session(session_id)
    demand = session.current_card
    buyer_pool = determine_buyer_pool(session.buyer)  # 试水/标准/优质

    # Step 1: 候选池筛选（硬条件）
    candidates = SellerRepo.filter(
        category__matches=demand.product_category,
        status='active',
        is_blacklisted=False,
        accept_pool__includes=buyer_pool,  # 卖家是否愿意接此池
    )

    # Step 2: 区域过滤（默认本地）
    candidates = filter_by_region(candidates, demand.delivery_city,
                                   default_radius_km=300)

    # Step 3: 个性化打分
    for seller in candidates:
        seller.match_score = calculate_match_score(seller, demand, session.buyer)

    # Step 4: 排序 + 池大小决定
    sorted_list = sorted(candidates, key=lambda s: -s.match_score)
    pool_size = {
        'pilot': 5,       # 试水池
        'standard': 15,   # 标准池
        'premium': 20,    # 优质池
    }[buyer_pool]

    top_n = sorted_list[:pool_size]

    # Step 5: 单卖家每日接单上限
    top_n = apply_daily_quota(top_n)

    # Step 6: 多通道推送
    for seller in top_n:
        SellerParticipation.create(session_id, seller, dispatch_score)
        push_to_seller(seller, demand, channels=['app', 'sms', 'wechat'])

    # Step 7: 30 分钟后兜底
    schedule_fallback(session_id, after_minutes=30)
```

## 4. 盲价 Top 3 展示

### 4.1 报价聚合策略

```python
def get_buyer_aggregated_view(session_id):
    quotes = get_all_quotes(session_id)

    # Step 1: 过滤 - 价格底线保护
    market_ref = get_market_reference(session.demand)
    quotes = [q for q in quotes if q.price > market_ref * 0.92]  # 隐藏低于市场价 8% 的

    # Step 2: 综合评分（不只是价格）
    for q in quotes:
        q.display_score = calc_display_score(q, session.demand)

    # Step 3: 排序 + 限量
    sorted_quotes = sorted(quotes, key=lambda q: -q.display_score)

    # Step 4: Top 3 展示（默认）
    top_n = sorted_quotes[:3]

    # Step 5: 其他报价"折叠"，需买家手动展开
    return {
        'top_quotes': top_n,
        'other_quotes_count': len(sorted_quotes) - 3,
        'show_more_unlocked': False  # 默认不展示其他
    }
```

### 6.2 偏好对派单的影响

```python
def filter_by_seller_preference(seller, demand, pool):
    pref = seller.preferences

    # 池子偏好
    if pool not in pref.accept_pools:
        return False

    # 品类
    if demand.category not in pref.categories:
        return False

    # 区域
    if demand.delivery_city not in pref.regions:
        return False

    # 时间
    if not in_time_window(now(), pref.time_window):
        return False

    # 接单数
    if seller.today_count >= pref.daily_max:
        return False

    return True
```

## 11. 异常处理

| 场景 | 处理 |
|---|---|
| 候选卖家不足 5 家 | 扩大半径 + 兜底（24h 后人工介入） |
| 全部卖家拒单 | 通知买家"系统正在为您寻找更多卖家" + 转人工 |
| 报价方差过低（疑似串价） | 触发 M11 风控审查 |
| 跨区成交占比过高 | 区域保护规则评议（卖家委员会） |
| 卖家偏好过严（无单可接） | 提示卖家"您的设置过严，建议放宽" |
