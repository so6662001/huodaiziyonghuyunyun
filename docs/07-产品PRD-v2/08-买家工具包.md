# M8：买家工具包

## 1. 模块目标

让买家"用一次后还想再来"——让平台成为采购员的**桌面工具**。

子模块：
1. 行情中心（基础免费，进阶订阅）
2. 我的供应商（SaaS 化付费产品入口）
3. 个人成长账户（采购员个人价值）
4. 项目档案（详见 M3）
5. 比价单导出（工作交付物）
6. 老客户通道（避免重复比价）

## 2. 子模块 1：行情中心

### 2.1 免费基础版（所有买家可用）

```
今日行情
  - 钢厂出厂价（10 家主流，T 日更新）
  - 区域成交价（自动定位用户所在区域）
  - 价格走势曲线（7/30/90 天）
  - 自定义关注品种（最多 5 个）

每日定时推送：
  - 早 8:00 行情快报
  - 下午 行业要闻
  - 晚 8:00 低价资源

来源：
  - 平台自有交易数据
  - Mysteel / 上海钢联（采购）
  - 钢厂官网（爬虫）
```

### 2.2 付费进阶版（¥99-299/月）

```
《货袋子行情卡》

基础版（¥99/月）：
  - 关注 10 个品种
  - 月度报告
  - 钢厂排产/出厂价变化

进阶版（¥299/月）：
  - 关注 30 个品种
  - 月度深度报告（含趋势预判）
  - 群组私聊行情解读（与分析师 1 对 1）
  - "我要询价 30 次/月" 套餐
```

**关键**：用付费行情服务**承接探价党**——他们想要的本来就是"市场价"，把这个需求产品化、收费化。

## 3. 子模块 2：我的供应商（核心 SaaS 入口）

### 3.1 设计理念

不强迫买家"替换老供应商"，而是**把所有供应商集中到平台来管理**。这是 B2B 平台真正能锁住企业级买家的产品形态。

### 3.2 功能

```
买家可在平台维护"我的供应商列表"：

📂 我的供应商
  ├── 老供应商（自己上传名片/手动添加）
  ├── 平台撮合卖家（自动归入）
  └── 推荐供应商（平台推荐潜在）

每个供应商：
  - 联系方式（脱敏存储）
  - 主营品类
  - 历史合作（采购历史、平均价、按时率、纠纷）
  - 信用评分（个人维度的私密评分）
  - 标签（"账期好"/"质量稳"/"价格便宜"）
  - 跟进备注（私密）

操作：
  - 平台帮邀请此供应商入驻
  - 一键发起询价（仅推送给指定供应商）
  - 一键比较多家供应商方案
  - 历史采购台账导出
```

### 3.3 发需求时的供应商选择

```
发需求页面新增选项：

发需求范围：
  ○ 公开发布（让平台匹配新卖家）
  ● 同时发：老供应商 + 平台匹配（推荐）
  ○ 仅指定我的老供应商
  ○ 仅平台撮合
```

### 3.4 商业化：企业级 SaaS

```
《货袋子 - 工程采购管理 SaaS》
¥3000-¥10000/年/企业

✅ 无限供应商管理
✅ 项目档案管理
✅ 多人协作（采购+技术+财务）
✅ 历史价格曲线
✅ 月度采购报表
✅ 对账单/发票自动归集
✅ 比价单一键生成
✅ 审批流（可选，按公司流程配置）

这是"采购管理工具"，不是"信息咨询费"
→ 对公审批容易通过
→ 企业愿意按年付费
```

**关键**：买家付费的产品形态，**永远不是"询价费"**，而是"长期管理工具"。

## 4. 子模块 3：采购员个人成长账户

### 4.1 设计理念

B2B 采购的钥匙不在公司，在**采购员个人**。如果货袋子让采购员个人受益，他们会自发推荐、自发使用、自发维护。

### 4.2 三层价值

#### A. 个人成长数据（可带走）

```
我的成长账户：

📊 累计数据
  累计询价：234 单
  累计成交：45 单
  累计省钱：约 ¥86 万 vs 市场价
  累计合作供应商：18 家

🎯 我的等级
  当前等级：熟手采购员
  下一级：专家采购员（还需 ¥200 万成交额）

🏅 我的徽章
  - 月度活跃 ×6
  - 项目管理达人
  - 行情研究员（已订阅行情卡 6 个月）

🎓 平台认证
  - "金牌采购员" 认证（可写进简历）

📥 一键导出
  即使换公司，所有数据可带走
```

#### B. 个人荣誉体系

```
月度优秀采购榜（公开）
  - 唐山 Top 10
  - 天津 Top 10
  - 全国 Top 100

季度大奖
  - 季度 MVP 采购员（行业大会公开表彰）
  - 现金/奖品

行业 IP 培养
  - 优秀采购员可受邀做"行业分享"
  - 帮平台做内容，获得现金奖励
```

#### C. 个人收益（合规！）

```
📤 邀请奖励（合规）
  邀请同行加入 → ¥50-300 / 个（按里程碑）
  上限：¥3000 / 月

📝 内容奖励
  写采购心得 → ¥50-500 / 篇
  做行业分享视频 → ¥500-2000 / 期

🎁 平台活动
  参加线下论坛 → 路费报销
  受邀闭门会议 → 行业人脉
```

**合规底线**：

- 个人收益必须合规（不能变相回扣）
- 邀请奖励 ≤ ¥500 / 个，必须明面付款
- 内容奖励基于真实内容质量
- 所有奖励个税合规

## 6. 子模块 5：比价单导出（工作交付物）

### 6.1 设计理念

采购员的真实工作场景：**比完价要给老板汇报**。

平台主动提供"工作交付物"——比价单 PDF/Excel。

### 6.2 比价单内容

```
《XX 项目钢材采购询价比对单》

时间：2026-05-23
项目：XX 工程
采购员：张三

清单概要：
  23 行物料，预算 ¥130 万

询价过程：
  共收到 6 家卖家报价
  平均报价偏差：3.2%
  最低报价：¥123.5 万（卖家 A+B+C 组合）

详细比价表：
  [表格：23 行 × 6 家卖家的报价矩阵]

最优组合方案：
  方案 A（推荐）：3 家组合 ¥123.5 万 节省 ¥6.5 万
  方案 B（管理便利）：1 家通包 ¥128 万

推荐方案：方案 A
推荐理由：综合成本 vs 管理复杂度的最佳平衡

平台风险评估：
  3 家卖家均通过实地核验，信用 A 级
  历史无重大纠纷

平台认证印章 + 时间戳
```

### 6.3 价值

- 采购员**用平台 = 工作交付物自动生成**
- 满足招投标合规要求（三方比价）
- 给老板留下"专业"印象
- **采购员愿意主动用平台的根本原因**

## 7. 子模块 6：老客户通道

### 7.1 设计

```
买家与某卖家成交 ≥3 次 → 自动建立"长期合作关系"
   ↓
享受"老客户通道"：
  - 买家下次发需求，老客户卖家优先且独家收到 30 分钟
  - 30 分钟内老客户报价 → 不再开放给其他卖家
  - 老客户成交平台收费减半
  - 历史价格曲线给买家参考
  - 一键续单/补单
```

### 7.2 UI

```
我的老卖家 ⭐

⭐ 李总 钢贸 (唐山)
   合作 6 次，累计 ¥120 万
   最近：3 天前 50 吨热轧
   平均节省：vs 公开询价 +¥30/吨
   [一键续单] [发新需求] [查询历史价]

⭐ 张总 (天津)
   合作 4 次，累计 ¥80 万
   [一键续单]
```

### 7.3 平台收益逻辑

**为什么老客户成交收费减半？**

- 老客户复购概率高 = 平台 LTV 高
- 让买卖双方都觉得"在平台合作划算"
- 减少跳单（私下交易后买家还会回来用工具）

## 9. 核心接口

```
# 行情中心
GET    /api/v1/market-data/today                 今日行情
GET    /api/v1/market-data/trends                价格走势
GET    /api/v1/market-data/watched               关注品种行情
POST   /api/v1/market-data/subscribe             订阅付费版

# 我的供应商
GET    /api/v1/buyers/me/suppliers               供应商列表
POST   /api/v1/buyers/me/suppliers               添加供应商
PATCH  /api/v1/buyers/me/suppliers/{id}          更新
POST   /api/v1/buyers/me/suppliers/{id}/invite   邀请该供应商入驻平台

# 个人成长账户
GET    /api/v1/users/me/growth-account           我的成长账户
POST   /api/v1/users/me/growth-account/export    导出
GET    /api/v1/leaderboards                      排行榜

# 项目档案
GET    /api/v1/buyers/me/projects                项目列表
POST   /api/v1/buyers/me/projects                新建项目
GET    /api/v1/projects/{id}                     项目详情
GET    /api/v1/projects/{id}/ledger              项目台账

# 比价单导出
POST   /api/v1/procurement-lists/{id}/export     生成比价单
  body: { format: 'pdf'|'excel', template: 'simple'|'detailed'|'bid_compliant' }

# 老客户通道
GET    /api/v1/buyers/me/preferred-sellers       我的老卖家
POST   /api/v1/purchase-sessions/quick-order     一键续单
```
