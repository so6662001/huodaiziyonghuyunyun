# M4：报价系统模块

## 1. 模块目标

把报价从"单一价格"升级为"结构化方案 + 阶梯定价 + 议价交互"：

- 卖家**一次报价**，覆盖买家可能的多种选择（数量阶梯/规格调价/加项）
- 买家用"配置器"自由组合，**系统实时算价**
- 议价从"反复打字"变成"3 秒还价"
- 报价与需求卡片**版本绑定**，变更时一键调整

## 2. 用户故事

```
US-4.1（一次报准）
作为一个卖家，我希望初次报价就把"可能的所有情况"都报出来
（50/80/100 吨阶梯，5.5/6/8mm 调价，含运/加急/账期），
而不是被买家追问 5 轮才报清楚。

US-4.2（综合方案）
作为一个采购员，我希望看到的不是"5 个价格"，
而是"5 个综合方案"（含价格/账期/交期/服务），
让我看清谁是真的最适合。

US-4.3（3 秒还价）
作为一个采购员，我希望点一下"还价 ¥4250"按钮就能议价，
卖家也能一键"同意/拒绝/反提议"，
而不是用文字反复说明。
```

## 4. 数据模型

### 4.1 Quote（报价主表）

```typescript
interface Quote {
  quote_id: string;
  session_id: string;
  card_version: number;            // 关联的需求卡片版本
  seller_id: string;
  status: 'active'|'updated'|'expired'|'withdrawn'|'won'|'lost';

  // 基础报价
  base_unit_price: decimal;
  available_qty: decimal;
  valid_until: timestamp;

  // 阶梯定价（可选）
  tier_pricing: TierPricing[];

  // 规格调价
  spec_adjustments: SpecAdjustment[];

  // 加项
  add_ons: AddOn[];

  // 备注
  notes: string;

  // 元数据
  created_at: timestamp;
  updated_at: timestamp;
  viewed_by_buyer_at?: timestamp;

  // 利润保护数据
  market_reference_price?: decimal;
  estimated_profit_margin?: number; // 估算利润率
}

interface TierPricing {
  quantity_threshold: decimal;
  unit_price: decimal;
}

interface SpecAdjustment {
  spec: string;                    // 如 "6mm"
  price_delta: decimal;            // 相对基础价的增减
}

interface AddOn {
  type: 'include_freight'|'urgent_delivery'|'normal_invoice'|'special_invoice'|'payment_term_30d'|'quality_certificate'|'custom';
  label: string;
  price_delta: decimal;
  description?: string;
}
```

## 6. 实时算价逻辑

```python
def calculate_price(quote_id, selection):
    quote = get_quote(quote_id)

    # Step 1: 基础单价（按阶梯定价）
    base = quote.base_unit_price
    for tier in sorted(quote.tier_pricing, key=lambda t: t.quantity_threshold):
        if selection.quantity >= tier.quantity_threshold:
            base = tier.unit_price

    # Step 2: 规格调价
    spec_adj = 0
    for adj in quote.spec_adjustments:
        if adj.spec == selection.spec:
            spec_adj = adj.price_delta

    # Step 3: 加项
    addon_total = sum(
        addon.price_delta for addon in quote.add_ons
        if addon.type in selection.add_ons
    )

    # Step 4: 综合单价
    unit_price = base + spec_adj + addon_total

    # Step 5: 总价
    total_price = unit_price * selection.quantity

    return {
        'unit_price': unit_price,
        'total_price': total_price,
        'breakdown': { 'base': base, 'spec_adj': spec_adj, 'addons': addon_total }
    }
```

卖家选择后：

## 8. 利润保护提示

```python
def get_profit_protection_hint(quote, seller, demand_card):
    # 从 M11 风控获取市场参考价
    market_ref = get_market_reference_price(
        demand_card.product_category,
        demand_card.material_grade,
        demand_card.spec,
        demand_card.delivery_city,
        timeframe_days=7
    )

    if quote.base_unit_price < market_ref * 0.85:
        return {
            'level': 'warning',
            'message': '您的报价低于市场底线，可能存在风险',
            'market_range': f'{market_ref * 0.92}-{market_ref * 1.08}',
            'estimated_margin': estimate_profit_margin(quote, market_ref)
        }
    elif quote.base_unit_price < market_ref * 0.92:
        return {
            'level': 'info',
            'message': '价格偏低，利润空间较小',
            'estimated_margin': estimate_profit_margin(quote, market_ref)
        }
    else:
        return {
            'level': 'ok',
            'estimated_margin': estimate_profit_margin(quote, market_ref)
        }
```

## 9. 议价规则

```
单卖家议价上限：2 次/会话
  - 防止反复纠缠
  - 历史议价记录公开（防止双方失忆）

议价回应有效期：30 分钟
  - 超时自动 rejected

反提议：卖家拒绝后可"反提议"（仅一次）
  - 反提议后买家需在 30 分钟内回应
  - 否则成交意向消失

议价不强制让步：
  - 平台不"撮合让步"
  - 议价是产品工具，不是协商引擎
```

## 11. 状态机

### Quote

```
draft → active → ready_for_view → viewed_by_buyer
                                    ↓
                              negotiating
                                    ↓
                  won / lost / expired / withdrawn
                                    ↓
                              superseded（卡片变更后被新报价替代）
```

### Negotiation

```
pending → accepted（成交）
       → rejected（结束）
       → counter_offered（反提议）→ accepted / rejected / expired
```

## 12. 异常处理

| 场景 | 处理 |
|---|---|
| 卖家报价时市场价已变化 | 提示"市场参考价已更新，请确认" |
| 买家选择无效组合（如不存在的规格） | 前端校验 + 后端兜底 |
| 报价过期但买家选择 | 提示"该报价已过期，请联系卖家更新" |
| 议价超过上限 | 提示"已达本会话议价次数上限" |
| 卖家撤回报价但买家已选择 | 通知双方 + 平台介入 |
