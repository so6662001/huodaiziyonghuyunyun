# M6：信用与信任体系

## 1. 模块目标

建立双边（买家+卖家）信用分体系，让 B2B 信任可视化、可量化、可申诉：

- 买家信用分影响匹配池
- 卖家信用分影响排序权重
- 视频/实地核验 + 历史成交 + 好评机制
- 申诉机制（24h SLA）
- 双向"屏蔽"功能

## 2. 双边信用分模型

### 2.1 卖家信用分

```
基础分：100
最高分：100
最低分：0

加分项：
+10  完成实地核验（平台地推团队上门）
+10  上传 3 个以上库存视频/现场视频
+10  完成黑金会员认证（高级认证）
+5/月 月度响应率 ≥ 80%
+3/单 按时交货
+2/好评 收到买家好评
+1/月 全月零投诉

减分项：
-5/次  未按时响应（超 30 分钟）
-10/次 报价偏离市场参考价 >15%
-10/次 撤回报价（24h 内 >3 次）
-15/次 收到买家投诉（核实后）
-20/次 货物质量问题
-30/次 跑单（接单后失联）
-50    严重违规（虚假宣传/欺诈）

分级：
  S（90+）：优质池优先 + 大客户专属通道 + 流量费 7.5 折
  A（70-89）：标准池主力 + 流量费 9 折
  B（50-69）：试水池接单 + 限制大单
  C（< 50）：限制接单 + 强制培训
```

### 2.2 买家信用分

```
基础分：60
最高分：100
最低分：0

加分项：
+10  营业执照认证
+10  完整填写企业资料（含规模、行业）
+10  首次成交
+5   每次成交确认
+3   联系卖家 ≥3 轮
+2   给卖家好评
+5/月 月度活跃买家（≥3 次询价 + ≥1 次成交）

减分项：
-5   联系卖家后 7 天无任何反馈
-10  反复发同需求 ≥5 次不成交
-15  被卖家投诉"虚假询价"（核实后）
-20  跑单（确认后不付款）

分级：
  优质池（≥80）：精准匹配、卖家高响应
  标准池（60-79）：默认池
  试水池（<60）：少量推送、卖家可选不接
```

## 4. 实地核验流程

### 4.1 触发条件

```
- 卖家主动申请（解锁 S 级）
- 平台抽查（每月 5% 卖家）
- 投诉触发（被投诉的卖家强制核验）
- 大客户专属（B-F1 阻力的解法）
```

### 4.2 核验流程

```
Step 1: 卖家提交申请
  - 营业地址
  - 联系人 + 联系电话
  - 预约时间窗口
  - 上传简介资料

Step 2: 平台地推派单（运营 + 兼职老炮）
  - 距离最近的地推人员领取
  - 1 周内完成

Step 3: 现场核验
  - 实地拍照（仓库/办公场所）
  - 营业执照原件核对
  - 法人/负责人面谈（10-15 分钟）
  - 库存抽样
  - 行业问询（确认非空壳）

Step 4: 报告
  - 现场照片 ≥ 10 张
  - 文字总结 + 评分（A/B/C 三档）
  - 上传到 SellerVerification 表

Step 5: 信用分更新
  - A 级 → +10 分 + S 级标签
  - B 级 → +5 分
  - C 级 → 拒绝（资料造假等）
```

## 5. 申诉机制

### 5.1 申诉对象

- 买家可申诉：卖家恶意低报、跑单、质量问题
- 卖家可申诉：买家虚假询价、跑单、恶意投诉
- 双方可申诉：信用扣分、限制处置

### 5.2 申诉流程

```
T+0    提交申诉（含证据：截图/录音/物流单）
T+4h   客服首次响应（"已受理"）
T+24h  风控+客服初步结论
T+48h  双方意见沟通
T+72h  最终决定（可申请委员会复审）
```

### 5.3 复审机制

```
重大争议（金额 > ¥5 万 或 涉及违规）
  → 走"卖家委员会"复审
  → 委员会 21 人投票，14 票通过即生效
  → CEO 不能单方面否决
```

## 6. 数据模型

```typescript
interface CreditScore {
  user_id: string;
  role: 'buyer'|'seller';
  current_score: number;
  level: string;             // S/A/B/C 或 优质/标准/试水
  base_score: number;
  adjustments: ScoreAdjustment[];
  computed_at: timestamp;
}

interface ScoreAdjustment {
  reason_code: string;       // 如 SELLER_FIELD_VERIFIED
  delta: number;
  evidence: object;
  applied_at: timestamp;
  appealable: boolean;
}

interface SellerVerification {
  verification_id: string;
  seller_id: string;
  type: 'field'|'video'|'document';
  status: 'pending'|'completed'|'rejected';
  verifier_id: string;
  verification_date: timestamp;
  photos: string[];
  report: string;
  rating: 'A'|'B'|'C';
  notes: string;
}

interface VideoShowcase {
  showcase_id: string;
  seller_id: string;
  category: 'warehouse'|'production'|'team'|'recent_inventory'|'customer';
  video_url: string;
  duration_sec: number;
  approved: boolean;
  view_count: number;
  uploaded_at: timestamp;
}

interface Appeal {
  appeal_id: string;
  appellant_id: string;
  respondent_id?: string;
  target_type: 'rating'|'credit_score'|'penalty'|'transaction';
  target_id: string;
  reason: string;
  evidence: string[];
  status: 'submitted'|'reviewing'|'first_decision'|'appeal_committee'|'closed';
  first_decision: object;
  committee_decision?: object;
  created_at: timestamp;
  resolved_at?: timestamp;
}

interface Review {
  review_id: string;
  reviewer_id: string;
  reviewee_id: string;
  session_id: string;
  rating: number;            // 1-5
  comment: string;
  tags: string[];            // 报价快/品质好/...
  created_at: timestamp;
  visible: boolean;
}

interface Blacklist {
  blacklist_id: string;
  owner_id: string;
  blocked_user_id: string;
  reason: string;
  created_at: timestamp;
}
```

## 7. 核心接口

```
# 信用分
GET    /api/v1/users/{id}/credit-score             查询信用分
GET    /api/v1/users/me/credit-history             我的信用历史

# 卖家核验
POST   /api/v1/sellers/me/verification/apply        申请核验
GET    /api/v1/sellers/me/verifications             我的核验记录
POST   /api/v1/admin/verifications/{id}             平台填写核验报告

# 视频展示
POST   /api/v1/sellers/me/showcases                 上传视频
GET    /api/v1/sellers/{id}/showcases               卖家视频列表
DELETE /api/v1/showcases/{id}                       删除

# 评价
POST   /api/v1/reviews                              提交评价
GET    /api/v1/users/{id}/reviews                   用户评价列表

# 申诉
POST   /api/v1/appeals                              发起申诉
GET    /api/v1/appeals/me                           我的申诉
PATCH  /api/v1/appeals/{id}/escalate                提交委员会复审

# 黑名单
POST   /api/v1/blacklists                           拉黑某用户
DELETE /api/v1/blacklists/{id}                      取消
GET    /api/v1/blacklists/me                        我的黑名单
```

## 8. 信用分计算定时任务

```
每天 03:00 跑全量重算
每小时 增量更新（基于行为事件）

  for user in all_active_users:
    score = base_score
    for adj in user.adjustments_30d:
      if adj.is_expired_for_recalc:
        continue
      score += adj.delta
    user.current_score = clamp(score, 0, 100)
    user.level = determine_level(score)
    if level_changed:
      trigger_pool_update(user)  # 通知 M5 更新池子
```

## 9. 反作弊与防刷

| 场景 | 防控 |
|---|---|
| 卖家互相刷好评 | 同一买家 30 天内对同一卖家好评 ≥3 个 → 标记 + 风控审查 |
| 买家恶意差评 | 买家差评率 > 30% → 风控审查 |
| 假视频展示 | 视频上传前 AI 审核（图像识别） + 人工抽检 |
| 假实地核验 | 地推人员轮换 + 双人核验 + GPS 打卡 |
