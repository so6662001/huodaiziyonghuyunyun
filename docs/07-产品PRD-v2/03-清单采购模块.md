# M3：清单采购模块 ⭐

> 货袋子相对找钢网的**最大产品差异化**。这是采购员愿意主动用平台的关键钩子。

## 0. 与 M2 的关系（v2.1 修正）

> ⚠️ **关键澄清**：M2「采购会话」从 v2.1 起已经**默认支持多规格清单**（`DemandCard.items` 数组）。
> 本模块的核心价值不是"支持多规格"，而是**让用户用更省力的方式录入多规格**：

```
M2 是产品骨架：会话 + 多规格需求卡 + 报价矩阵 + 按行成交
M3 是录入加速器：让用户不用一行行手敲，就能产生 M2 的多规格需求卡

5 种录入方式 → 都产生统一的 DemandCard：
  1. 手动多行（M2 原生支持）
  2. Excel 一键导入（本模块）⭐
  3. PDF/图片 OCR 识别（本模块）⭐
  4. 微信转发解析（本模块）⭐
  5. 语音连续报清单（本模块）⭐
```

## 1. 模块目标

把真实采购的**清单原物**（拍照/Excel/PDF/微信转发）做成产品的一等公民：
- 5 秒上传，10 秒解析
- AI 自动识别 20+ 行，准确率 ≥ 90%
- 解析后产物：**M2 DemandCard 的 items 数组**（与手动录入完全一致）
- 智能拆单：按品类自动分发给专精卖家
- 最优组合：多家部分应答 → 自动算最优方案

## 2. 用户故事

```
US-3.1（拍照即询价）
作为一个采购员，甲方发我一张工程清单（PDF/图片），
我希望拍一张照片就能发起询价，
而不是把 30 行物料一个个手动敲进平台。

US-3.2（部分应答）
作为一个卖家，收到 23 行清单时，
我希望只对我能供的 10 行报价（板材），
而不是被强制"全包才能接单"。

US-3.3（最优组合）
作为一个采购员，5 家卖家各报了不同行，
我希望平台自动算出"最优组合方案"（最便宜/最快/一家通包），
而不是我自己手动比对。

US-3.4（项目档案）
作为一个采购员，一个项目有 3 期补单，
我希望平台帮我管理"项目"维度，
而不是每次重新发清单。
```

## 3. 整体流程

```
买家上传清单（拍照/Excel/PDF/微信转发）
   ↓

   ↓
极简确认页（10% 不确定行高亮，10 秒确认）
   ↓
平台自动拆单（按品类）
   ↓
每个品类生成独立 PurchaseSession
   ↓
推送给专精卖家 → 部分应答
   ↓
平台计算最优组合（4 种方案）
   ↓
买家选择 → 成交回填
   ↓
归档到项目档案（可后续复用）
```

## 9. 最优组合算法（核心创新）

### 9.1 算法目标

给定清单 N 行 + M 家卖家各报部分行，求"最优组合方案"。

数学模型：**多目标整数规划**

```
变量：x[i][j] ∈ {0, 1}
  x[i][j] = 1 表示第 i 行由第 j 家卖家供应

目标函数：
  方案 A（最低成本）：min Σ price[i][j] × x[i][j]
  方案 B（一家通包）：选一个 j 使覆盖率最高
  方案 C（最快交期）：min max(delivery_days[j])
  方案 D（最高信用）：max Σ credit[j] × x[i][j] / N

约束：
  - 每行只能选一个卖家：Σ x[i][j] = 1（对所有 i）
  - 卖家必须报过价：x[i][j] ≤ has_quote[i][j]
  - 数量满足：available_qty[i][j] ≥ qty[i]
```

### 9.2 算法实现

```python
import pulp

def calculate_optimal_combo(list_id, strategy='lowest_cost'):
    lines = get_lines(list_id)
    quotes = get_quotes(list_id)  # 所有卖家所有行的报价

    # 构建变量
    sellers = unique_sellers(quotes)
    x = pulp.LpVariable.dicts('x', (lines, sellers), 0, 1, pulp.LpBinary)

    # 创建问题
    prob = pulp.LpProblem('OptimalCombo', pulp.LpMinimize)

    # 目标函数
    if strategy == 'lowest_cost':
        prob += pulp.lpSum(
            x[i][j] * quote_price(quotes, i, j) * lines[i].qty
            for i in lines for j in sellers if has_quote(quotes, i, j)
        )
    elif strategy == 'one_stop':
        # 优先一家全包
        prob += pulp.lpSum(... 类似)
    # ... 其他策略

    # 约束
    for i in lines:
        prob += pulp.lpSum(x[i][j] for j in sellers if has_quote(quotes, i, j)) == 1

    # 求解
    prob.solve(pulp.PULP_CBC_CMD(msg=0))

    # 提取结果
    return extract_combo(x, lines, sellers, quotes)
```

```
  - 卖家给"参考价"，不进入成交承诺
  - 用于"摸底"
  - 标记给卖家：这是"参考询价"，不强制响应
```

## 12. 状态机

```
ProcurementList:
  uploaded → parsing → ready_for_confirm → confirmed → dispatched → quoting → combo_calculated → deal/closed/expired
                                              ↓
                                          cancelled
```

## 13. 异常处理

| 场景 | 处理 |
|---|---|
| OCR 解析失败（图片质量太差） | 引导用户重新拍照 + 提供手动输入兜底 |
| LLM 服务超时 | 降级为规则引擎（提取标准化字段） |
| 用户上传非清单（如普通文档） | 解析后无表格结构 → 提示"未识别到清单" |
| 卖家完全没人应答 | 24h 后人工运营介入 |
| 部分行无卖家应答 | 标黄"该行暂无卖家"，仍可发起对其他行的成交 |
| 最优组合算法求解超时 | 降级到贪心算法（10ms 出方案） |
