# 基础组件库

> 设计师可在 Figma 中按本文档精确复现的基础组件。

## 一、Button 按钮

### 1.1 Primary Button（主按钮）

```
属性：
  尺寸：宽自适应 × 高 44px（默认）
  内边距：horizontal 20px / vertical 0
  圆角：8px
  字号：15px / 字重 500
  
默认态：
  背景：#2563eb
  文字：#ffffff
  
hover 态（仅 Web）：
  背景：#1e40af
  
按下态：
  背景：#1e3a8a
  缩放：0.98
  
禁用态：
  背景：#e5e7eb
  文字：#98a1b3
  
Block（满宽）：
  宽：100%
  高：56px（关键 CTA）
  字号：16px
```

#### Figma 创建步骤

1. 创建 Frame，宽自适应高 44px
2. 填充 #2563eb
3. 圆角 8px
4. 添加文字 15px / 500 / #ffffff
5. 添加 Auto Layout（horizontal）
6. 创建 Variants：
   - Type: Primary
   - Size: Large / Medium / Small
   - State: Default / Hover / Disabled

## 二、Input 输入框


## 十六、组件状态总结

每个组件应该支持的状态：

```
□ Default 默认
□ Hover 悬停（仅 Web）
□ Active 按下
□ Focus 聚焦（输入框）
□ Disabled 禁用
□ Error 错误（输入框）
□ Loading 加载（按钮）
□ Empty 空状态（列表）
```

## 十七、复制使用

设计师可以：

1. 在 Figma 中创建上述组件
2. 创建 Variants
3. 发布到 Team Library
4. 后续设计页面时直接复用

每个组件名称用英文 + 类型，如：
- Button/Primary/Large
- Input/Default
- Tag/Success

便于团队搜索。
