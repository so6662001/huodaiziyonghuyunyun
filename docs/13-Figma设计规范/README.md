**Figma 复现流程**：
1. 先看本目录的设计系统
2. 在 Figma 中导入 design-tokens
3. 按 pages/ 中的规格复现页面
4. 对照 HTML 原型校对

## 三、使用 Figma Tokens 插件导入

```
1. 在 Figma 安装插件「Figma Tokens」
2. Settings → JSON file → 导入 design-tokens/tokens.json
3. 应用 token 到 Style
4. 后续修改 token 自动同步所有应用处
```

## 四、设计原则

1. **移动优先**：414px 基础宽度
2. **钢贸专业风**：蓝灰主调 + 暖色 CTA
3. **简洁高效**：减少不必要装饰
4. **大字大按钮**：考虑 40-55 岁用户
5. **数据可视**：信用、库存、价格清晰

## 五、字号体系（适配中老年用户）

| 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 标题 1 | 22px | 30 | 600 |
| 标题 2 | 18px | 26 | 600 |
| 标题 3 | 16px | 24 | 600 |
| 正文大 | 15px | 22 | 400 |
| 正文小 | 13px | 20 | 400 |
| 辅助文字 | 12px | 18 | 400 |
| 极小（仅次要信息） | 11px | 16 | 400 |

**注**：所有字号都比 C 端产品大 1-2px，考虑钢贸老板视力。

## 六、关键设计差异（与一般 C 端 App）

| 维度 | 一般 C 端 | 货袋子（B2B 钢贸） |
|---|---|---|
| 配色 | 活泼鲜亮 | 蓝灰沉稳 + 金色重点 |
| 字号 | 13-14px 主 | 15px 起步 |
| 按钮 | 紧凑 | 44pt 起 |
| 图片 | 大图为主 | 数据为主 |
| 信息密度 | 高 | 适中（避免眼花） |
| 动效 | 丰富 | 极简 |
| 转化路径 | 短 | 长（多步骤可接受） |
