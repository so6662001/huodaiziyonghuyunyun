# CEO 拜访 A 类商家行程总规划

> **目的**：在 M3 灰度种子启动前，CEO 亲自走访 25-30 家 A 类核心商家。
> **战略意义**：建立信任 + 收集真实反馈 + 培育种子合伙人。
> **时长**：约 4-5 个工作日（分 2 次出行，覆盖三地）

## 一、行程总览

| 行程 | 日期 | 区域 | 拜访数 | 备注 |
|---|---|---|---|---|
| Trip 1 | Week 4 周一-周二 | 唐山 | 10-12 家 | 重点区域 |
| Trip 2 | Week 4 周三-周四 | 天津 | 10-12 家 | 重点区域 |
| Trip 3 | Week 5 周一 | 聊城 | 5-8 家 | 单日往返 |
| Buffer | Week 5 周二-周三 | 补访 + 总结 | 3-5 家 | 没拜访到的 + 紧急约见 |

**总目标**：拜访 28-37 家。**目标值 30 家**。

## 六、单次拜访 SOP（每家约 90 分钟）

### 准备（拜访前 24h）

```
助理负责：
  ✅ 确认拜访时间（提前 24h 致电确认）
  ✅ 准备路线 + 司机
  ✅ 准备资料包：
     - 该商家的入驻数据卡
     - 内测合伙人邀请函
     - 货袋子双引擎升级说明
     - 礼品（CEO 亲签贺卡 + 唐山土特产）
  ✅ 准备录音设备（征得对方同意）
```

### 拜访流程（90 分钟）

```
00:00-00:05  到达 + 寒暄（CEO + 助理 + 1 名记录员）
00:05-00:15  自我介绍 + 表示感谢
00:15-00:45  听卖家声音（CEO 不主动推销，30 分钟纯倾听）
00:45-01:15  介绍双引擎方案（30 分钟）
01:15-01:30  邀请内测合伙人 + 礼物 + 合影
01:30        告别
```

### 关键话术（CEO 必读）

#### 开场（5 分钟）

```
"王总您好。我是货袋子 CEO 张三。

我个人专门留出 1 个半小时跟您聊聊。
您从 [X 月] 入驻以来，累计发布了 [234] 条库存，
是货袋子在唐山热轧品类排名前 [5] 的卖家。

今天来的目的有 3 个：
  1. 当面感谢您一直支持
  2. 听您对货袋子最真实的评价
  3. 给您介绍一个升级，邀请您做'内测合伙人'

您方便聊吗？"
```

#### 听声音（30 分钟，最关键）

CEO **主动问 5 个问题**，**不要急着推销**：

```
Q1（开放问题，3 分钟）：
"您在货袋子上目前最不满意的是什么？"

Q2（深挖痛点，5 分钟）：
"您每天的真实工作流是什么样的？您怎么找新客户的？"

Q3（同行视角，5 分钟）：
"您身边的同行也用货袋子吗？他们怎么评价？"

Q4（期望，5 分钟）：
"如果货袋子半年后做得很好，您希望它是什么样？"

Q5（红线，5 分钟）：
"您最担心的事情是什么？什么样的事情会让您离开平台？"

[留 7 分钟自由发挥，CEO 跟着聊]

笔记原则：
  ✅ 不打断
  ✅ 不辩解
  ✅ 不解释
  ✅ 不承诺什么都改
  ✅ 用对方原话记录关键句
```

#### 介绍新模式（30 分钟）

```
[听完声音后，CEO 自然过渡：]

"非常感谢您的坦诚。我听到您说 [总结他的核心 1-2 个痛点]。

其实这也是我们这次升级的方向。

我们做了一个新功能：
  - 之前是您发库存，等买家来看
  - 现在多了：买家可以主动来询您货的价

最重要的是：您不用做任何新操作。
您之前发的库存，自动接到询价系统。
就像您接电话一样，回复个价就行。

我现在用手机演示一下..."

[实际打开手机，演示 5 分钟]

"我们邀请您做'内测合伙人'。具体权益是：
  - 黑金会员免费 6 个月（市值 ¥3000+）
  - 50 条免费询价线索（市值 ¥1000）
  - 后续询价 5 折（限 60 天）
  - 进入'卖家委员会'候选名单
  - 平台股权激励池（M12+ 评定）

[强调底线]
最重要的：您不喜欢随时关闭，对您没有任何风险。"
```

#### 处理疑虑

| 卖家问 | CEO 回应 |
|---|---|
| "和找钢网什么区别？" | "3 点：永不抽佣 / 永不自营 / 永不挖客。这些都会写进协议。" |
| "会不会让我利润变薄？" | "我们设了 5 道保护：盲价、区域保护、价格底线、卖家匿名、利润预警。" |
| "我已经交了年费，新功能要再交吗？" | "完全不用。新功能在您会员期内免费用。" |
| "我能完全不用新功能吗？" | "完全可以。一键关闭，不影响您任何老权益。" |
| "外地卖家会不会抢我本地客户？" | "默认本地匹配，跨区需要买家明确请求。我们监控跨区成交占比。" |
| "你们后台数据是不是会泄露给同行？" | "您的报价、客户、利润数据都加密存储，连员工都看不到原始数据。" |
| "我能加入卖家委员会吗？" | "您是我候选名单上的人。委员会 21 人，季度轮换。我希望您能加入。" |

#### 邀请 + 收尾（15 分钟）

```
"王总，时间过得快。我做最后 3 件事：

1. 给您一个'内测合伙人'电子证书（手机展示）

2. 您今天提到的 [具体痛点]，我个人承诺：
   - 一周内给您详细回复
   - 30 天内有改进方案
   - 您是第一批知道结果的人

3. 我希望您加入卖家委员会候选名单。
   委员会有评议平台规则的权力。
   您觉得呢？

[等回应]

[结束话术]
'非常感谢您今天的时间。我下周让助理跟您联系，给您发 50 条线索礼包。
   有任何问题，您直接打我电话 [手机号]。'"
```

```
❌ 不要打断卖家说话
```
