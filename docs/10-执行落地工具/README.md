## 使用方式（按角色）

### CEO

1. 看 `ceo-拜访行程/CEO拜访行程总规划.md` → 安排 4-5 天行程
2. 看 `财务影响测算/100家财务影响测算.md` → 心里有数
3. 看 `kpi看板/KPI看板设计.md` → 知道每周看什么

### 产品总监

1. 用 `ui-改版原型/` → 浏览器打开 `index.html` 看完整原型
2. 把 HTML 转 Figma 给设计师
3. 监督前端按原型实现

### 运营负责人

1. 用 `客户成功培训/` → 培训 5-8 名客户成功
2. 用 `kpi看板/` 创建飞书表格 → 每周一开会用
3. 配合 CEO 完成 A 类拜访后续

### 客户成功团队

1. 用 `客户成功话术录音版.md` → 上岗前 1 周培训
2. 完成笔试 + 模拟演练
3. 每天接听数据填入飞书 KPI 看板

### CFO

1. 看 `财务影响测算/100家财务影响测算.xlsx` → 6 个 Sheet
2. 把核心数据嵌入投资人路演 PPT
3. 每月 review 实际数据 vs 预测

### 投资人沟通

1. 用 `财务影响测算/100家财务影响测算.md` 的关键数据：
   - 单引擎 vs 双引擎 ROI 对比（+131%）
   - 留存率提升（+17%）
   - 老用户改革 ROI（30 倍 vs 单引擎）

## 5 大交付物速览

### 1. UI 改版原型（3 个 HTML 页面 + 1 个导航）

可在浏览器直接打开预览，包含：

- **首页双入口**：保留库存浏览（蓝） + 新增发起询价（金色 NEW）+ 行情快报
- **卖家中心改版**：我的库存（保留）+ 我的询价（NEW）+ 收益看板（NEW）+ 老用户专属礼包
- **我的询价页**：3 条待处理 + 库存匹配标签 + 一键报价 + 卖家可关闭新功能

### 2. CEO 拜访行程

- **4-5 天行程**：唐山 2 天 + 天津 2 天 + 聊城 1 天 + Buffer 2 天
- **30 家 A 类商家**：按地理位置精细排路线
- **单次 90 分钟 SOP**：开场 5 分 + 听声音 30 分 + 介绍 30 分 + 邀请 15 分 + 收尾 10 分
- **完整话术**：开场 / 5 个深挖问题 / 异议处理 / 收尾
- **拜访纪要模板**：4 小时内必须完成
- **预算**：¥5 万

### 3. 客户成功话术（培训用）

- **15 分钟完整电话脚本**：每一分钟讲什么
- **15 种异议处理**：找钢网对比 / 利润 / 关闭 / 隐私 / ...
- **培训考核**：笔试 + 模拟演练 + 真实接听
- **心态培训 5 条心法**
- **关键数据卡**（口袋卡，必背）

### 4. 财务影响精细测算

**核心结论**：

| 维度 | 单引擎 | 双引擎 | 变化 |
|---|---|---|---|
| 12 月留存 | 60 家 | 70 家 | +17% |
| 12 月营收 | ¥36 万 | ¥83 万 | **+131%** |
| 流量费占比 | 0% | 60% | 新增 |
| 黑金升级 | 0% | 25% | 新增 |

**6 个 Sheet Excel**：
1. 现状基线
2. 单引擎预测（无改革）
3. 双引擎预测（改革后）
4. 成本投入（¥250 万）
5. 敏感性分析（3 大变量）
6. 含新用户全景

**Excel 字段定义可直接导入飞书**。

## 关键提醒

1. **不要省 CEO 拜访**：30 家 A 类，CEO 必须亲自走，不能授权
2. **不要省客户成功培训**：未培训直接上岗会失败
3. **KPI 看板每周一必看**：发现红色立即处置
4. **财务对比要做完整**：投资人会问"凭什么 +131%"
5. **UI 原型用 Figma 转化**：HTML 是基础，最终上线要 Figma 高保真稿
