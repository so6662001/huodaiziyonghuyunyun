货袋子改版原型 · 双引擎模式

配套 docs/09-过渡方案 的产品改版高保真稿。这是在原平台/小程序上的模块化扩展，不是新小程序。

🎯 改版核心

  • 原有功能（库存浏览、库存发布）100% 保留
  • 新增"💬 询价"入口，老用户可一键关闭
  • 数据共享：卖家发的库存自动接询价，不需要学新东西
  • 渐进灰度：5% → 25% → 60% → 100%
改版重点

"🔍 浏览库存"（保留）+ "💬 发起询价"（新增，金色 NEW 标） + 行情快报 + 库存瀑布流（保留）。

🎨 设计要点

  • 顶部信息条：M5 上线时展示"平台已升级！您发的库存能接询价了"，30 天后消失
  • 双入口卡片：左侧蓝色（老功能）+ 右侧金色（新功能 NEW）
  • NEW 标签：所有新功能用金色 NEW 标识，3 个月后移除
  • 一键关闭：每个新功能页都有"关闭新功能"链接（不显眼但可见）
  • 老用户专属：礼包卡片高亮提示，金色背景
  • 库存匹配标签：卖家收到询价时，平台自动识别"您的库存可匹配"，绿色背景
