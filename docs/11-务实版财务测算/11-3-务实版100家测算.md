# 务实版 100 家财务影响测算

> 对应 `10-执行落地工具/财务影响测算/100家财务影响测算.md` 的务实版修正。

## 一、关键认知修正

### 1.1 100 家是"累计入驻"，不是"100 家活跃付费"

**关键发现**：

```
平台显示 300 家入驻（不是 100 家），但：
  - 真正付费活跃：约 200-220 家（约 70%）
  - 其他 80-100 家可能是"已入驻但已沉默"
  - 真正活跃使用的"老用户"约 100 家
  
这 100 家才是我们要做改革的对象。
```

### 1.2 单卖家真实付费意愿

```
旧版假设：
  - 平均年费 ¥6000（统一）
  - 100% 续费

务实版假设：
  - 平均年费 ¥4500（高低混合）
    * 基础会员（¥3000）：40 家
    * 标准会员（¥6000）：40 家
    * 黑金会员（¥9800）：20 家
  - 续费率分层：
    * A 类 85%
    * B 类 65%
    * C 类 45%
    * D 类 8%
```

## 七、ROI 分析（务实版）

```

```

## 九、对 CFO 的建议（务实版）

### 1. 预算控制

```
12 月双引擎总投入：¥147 万

来源：
  - 启动金贡献 ¥80 万
  - Pre-A 贡献 ¥67 万

风险准备：
  - 留 ¥50 万应急金
  - 极端情景下 ¥147+50 = ¥200 万够用
```

### 2. 财务报表口径

```
老会员费：按权责发生制分摊 12 个月
新流量费：按消耗时点确认（非充值时点）
老用户专属补贴：计入"市场费用"（不冲减收入）
内测合伙人津贴：计入"运营费用"
反向邀请奖励：扣实付现金（不计提）
```

### 3. 投资人沟通

```
"老 100 家改革是为新用户增长铺路"

具体说法：
  - 老用户留存从 47% 提升到 61%（+30%）
  - 老用户营收 +74%
  - 改革投入 ¥147 万
  - 总 ROI（含新用户）3.2 倍

不要单看老用户短期账面。
```

## 十、对 CEO 的关键决策

### 1. 不要追求"激进改革"

```
务实续费率提升幅度：+10-15pp（vs 旧版每档 +10pp 但绝对值更高）

不要承诺"老用户全部留住"
不要承诺"流量费 80% 渗透"
不要承诺"3 个月扭转"

承诺：
  - 老用户留存提升 14pp（47% → 61%）
  - 改革后总营收提升 74%
  - 12 个月内做到不再衰减
```

### 2. 预算严控

```
¥147 万改革预算分摊：
  Q1: ¥50 万（一次性投入 + 3 个月运营）
  Q2: ¥30 万
  Q3: ¥30 万
  Q4: ¥37 万（保留应急）

任一季度超支 20% → 立即评估必要性
```

### 3. 现金流监控

```
关键指标（每周看）：
  - 老 100 家留存数（>= 90 家警告，<85 家红色）
  - 流量费充值续充率（>= 60%）
  - 新功能开通率（A: 90%, B: 70%, C: 40%）
  - 老用户 NPS（>= 50）

任一红色 → 暂停 + 复盘
```

## 十一、最终总结

```
旧版（乐观）：双引擎 +131%，听起来很美
务实版：双引擎 +74%，做起来可达成

旧版要花：¥250 万
务实版要花：¥147 万（少 41%）

旧版要 5 名客户成功
务实版要 3 名（精益）

旧版风险：超额承诺，达不到目标失信
务实版优势：合理承诺，超额达成会增信
```

**关键判断**：用务实版做内部预算和 KPI，但**改革本身仍然要做** ——
- 不做：12 个月老用户营收衰减到 ¥25 万
- 做：12 个月营收提升到 ¥43 万
- ROI 仍然非常合理
