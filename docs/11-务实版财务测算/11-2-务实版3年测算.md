## 七、务实版融资计划

### 7.1 资金需求

```
Y1 净亏：¥282 万
```

| 阶段 | 时点 | 金额 | 估值 | 稀释 |

### 7.3 关键洞察

```
"少融资" ≠ "钱不够"
"少融资" = "估值更高" + "稀释更少" + "决策更自由"

务实版下：
  - Pre-A 估值 ¥5000-8000 万（vs 旧版 ¥7000 万实际差不多）
  - A 轮估值 ¥1.5-2.5 亿（vs 旧版 ¥3-5 亿）
  - B 轮估值 ¥8-15 亿（vs 旧版 ¥10-15 亿）

虽然每轮估值数字小一点，
但因为少融资 + 少稀释，
创始团队最终持股从 30% → 50% +
```

## 九、风险预案

### 9.1 三档场景的应对

**保守情景**（M12 营收 ¥110 万，比基准低 30%）：

```
触发：买家增长慢 + 流量费付费率不达 30%

应对：
  - 进一步精益（团队不再扩张）
  - 重点服务现有 100 家
  - 推迟 A 轮，再融 Pre-A+ ¥500 万
  - 12 个月内做到单月盈亏平衡
```

**常规情景**（基准）：按计划推进。

**乐观情景**（M12 营收 ¥210 万，比基准高 35%）：

```
触发条件：买家爆发 + AI 杀手锏验证

应对：
  - 加速扩团队（务实版 50 人 → 70 人）
  - A 轮可提前 3 个月
  - 启动 B 轮预对接
```

## 十、给 CEO 的关键决策

### 1. 现金跑道按务实版

```
¥300 万启动金 + 月烧 ¥30 万 = 10 个月跑道
不要按 4 个月跑道做应急决策
→ 允许从容做产品迭代
→ 允许 M8-M9 才融资（估值更高）
```

### 2. 团队不要超配

```
M1：12 人即可（不要 25 人）
M3：18 人（不要 30 人）
M6：30 人（不要 60 人）
M12：50 人（不要 100 人）

每个岗位上岗前问："3 个月能产出明显价值吗？"
```

### 3. 收入预期对外按常规，对内按务实

```
对投资人："我们目标 M12 月营收 ¥150 万"（常规版务实估）
对内 KPI："M12 月营收 ¥130 万"（务实版）
对自己心理预期："M12 月营收 ¥100 万也可以接受"（保守版）

→ 永远超出预期，永远不让团队/投资人失望
```
