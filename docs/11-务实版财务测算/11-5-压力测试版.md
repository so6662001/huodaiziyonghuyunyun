## 六、压力测试下的应对策略

### 6.1 触发条件

```
M4 末发现以下任一：
  - 月新增卖家 < 15 家（vs 计划 35）
  - 流量费付费卖家 < 30 家（vs 计划 47）
  - 月营收 < ¥9 万（vs 计划 ¥12.8 万）

→ 立即进入压力测试预案
```

### 6.2 立即动作（M5 内）

```
1. 紧急复盘会（CEO + 各 VP）
2. 数据深度归因（哪个环节出问题）
3. 卖家委员会临时会议（如涉及双引擎反弹）
4. 100 家 CEO 紧急回访（A 类 + B 类）
5. 客户成功加大触达频率
```

### 6.3 成本压缩方案（M5-M7）

```
团队冻结：
  - M5 起停止扩招
  - 现 12 人撑到 M8
  - 月人员成本从 ¥22 万 → ¥22 万（不变）

非必要成本砍掉：
  - 服务器升级延迟：节省 ¥5,000/月
  - 数据采购改用免费：节省 ¥8,000/月
  - 市场地推砍 50%：节省 ¥15,000/月
  - 行政办公搬小一点：节省 ¥10,000/月
  
新月成本：¥30 万 → ¥26 万（节省 ¥4 万/月）
12 个月节省 ¥48 万
```

### 6.4 加速 Pre-A 募资

```
正常时点：M7-M8
压力测试时点：M5-M6

策略：
  - 接受较低估值（避免再砍 30%）
  - 接受较小金额（¥500-800 万也够）
  - 接受老股东加投
  - 必要时接受可转债 / 桥贷
```

### 6.5 业务方向调整

```
如果纯钢贸 B2B 起不来，考虑：

方向 1：转向"行情数据 + 工具"商业模式
  - 卖家会员降为免费
  - 重点收买家行情订阅费
  - 降低 GMV 焦虑

方向 2：聚焦区域 + 单品类
  - 砍掉所有非唐山+热轧业务
  - 区域内做到 80% 渗透
  - 再考虑扩张

方向 3：被战略投资
  - 联系宝武/沙钢/南钢
  - 接受被战投控股
  - 创始团队保留运营权
```

## 八、给 CEO 的关键决策

### 1. 心理准备

```
"压力测试版"不是用来吓人的，
而是用来"心里有底"的。

最坏情况：
  - Y1 营收只有 ¥200 万
  - 需要 Pre-A ¥1000+ 万救命
  - 盈亏平衡推到 M20+
  - 3 年累计 ¥4500 万

但即使最坏情况，业务模式仍然成立：
  - 单位经济模型健康
  - 估值仍可达 ¥3-5 亿
  - 创始团队保留 30-40% 股权
```

### 2. 预案三档

```
A 计划（精细务实版基准）：
  - 团队 12→50 人
  - Pre-A ¥500-800 万 @M7-8
  - A 轮 ¥2000-3000 万 @M18-22
  - 3 年累计 ¥0.84 亿

B 计划（压力测试预案）：
  - 团队冻结 12 人到 M8
  - Pre-A ¥1000-1500 万 @M5-6（提前）
  - A 轮推迟到 M24+
  - 3 年累计 ¥0.45 亿

C 计划（极端情况）：
  - 战略转向 + 被战投
  - 创始团队保留运营权
  - 3-5 年退出
```

### 3. 触发 B 计划的判断

```
每月 1 号财务月报必看：
  
如果 M3 末：
  - 月营收 < ¥10 万 → 警惕
  - 月营收 < ¥8 万 → 触发 B 计划

如果 M6 末：
  - 月营收 < ¥15 万 → 触发 B 计划

如果 M9 末：
  - 月营收 < ¥30 万 → 触发 C 计划
```
