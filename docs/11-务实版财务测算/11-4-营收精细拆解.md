# 营收精细拆解（CFO 工作底稿）

> **这份文档把务实版营收拆到"每分钱可追溯"的颗粒度**。配套 `营收精细拆解-工作底稿.xlsx` 使用。

## 一、拆解原则

每个数字必须能回答 3 个问题：

```
1. 怎么算出来的？（公式）
2. 公式里每个变量取什么值？（参数）
3. 这个值有什么依据？（来源）
```

## 二、5 大收入项公式

```
① 卖家会员费 = 活跃付费卖家数 × 加权年费 / 12
② 流量费   = 活跃卖家数 × 付费率 × 平均月消费
③ 订阅     = 活跃卖家数 × 订阅率 × 平均月费
④ 增值服务 = 活跃卖家数 × 渗透率 × 平均月费
⑤ 买家 SaaS = 累计签约买家 × 月均价值
```

## 十一、给 CFO 的工作流程

### 每月一次（每月初）

```
Step 1: 拉数据
  - 当月新增卖家数（实际 vs 计划）
  - 当月流失数
  - 各收入项实际值

Step 2: 录入 Excel
  - Sheet 3：卖家数实际值
  - Sheet 4：营收实际值

Step 3: 对比偏差
  - 实际 vs 计划 > ±20% 触发预警
  - 触发预警 → 调参数 + 重算未来

Step 4: 汇报
  - CEO 月报：实际数据 + 调整后的预测
  - 提示资金跑道剩余
```

### 每季度一次（季度初）

```
Step 1: 大对比
  - Y1/Y2/Y3 实际 vs 精细预测

Step 2: 调整 12 个参数
  - 哪些假设需要修正？

Step 3: 重新生成预测
  - 通过 Excel 自动算

Step 4: 给董事会
  - 务实版 vs 实际
  - 乐观版对外路演用
```

## 十二、常见误判（避免）

### 误判 1：M12 一定能盈亏平衡

```
之前粗估：M12 +¥15 万 → 平衡
精细推算：M12 -¥22 万 → 还差一点
真实平衡：M15-M16

→ 不要承诺 M12 盈利
→ 给团队留余地
```

### 误判 2：流量费早期就有规模

```
真实：
  M3 仅 ¥9000（30 家种子）
  M6 ¥4.2 万
  M9 ¥11.5 万
  M12 ¥23.9 万

不要指望流量费救命，
M3-M6 主要还是靠会员费。
```

### 误判 3：M12 累计卖家 5000 家

```
真实：M12 累计活跃付费 854 家
（注册可能 1500-2000，但付费 854）

→ 不要按 5000 家做对外承诺
→ 按 800-900 家承诺，做到 1000+ 是惊喜
```
