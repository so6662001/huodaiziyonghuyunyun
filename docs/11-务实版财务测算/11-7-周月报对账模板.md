# 周报 / 月报 / 季度报告对账模板

> **用途**：定期对账，发现偏差立即调整。
> **配套**：飞书表格 + Excel 模板（待生成）。

## 一、报告体系总览

| 报告 | 频率 | 受众 | 长度 | 用途 |
|---|---|---|---|---|
| 日报 | 每日 | 运营 | 1 屏 | 监控关键指标 |
| **周报** | 每周一 9:00 | 全员 | 2 页 | 周战术对齐 |
| **月报** | 月初 5 个工作日 | CEO+VP | 5 页 | 月度复盘 |
| **季度报告** | 季末 7 个工作日 | 董事会 | 10+ 页 | 战略对齐 |
| 半年报 | 半年末 | 投资人 | 15+ 页 | 融资沟通 |
| 年度报告 | 年末 | 全员+投资人 | 30+ 页 | 全面总结 |

### 3.7 月报对账重点

#### 财务对账（CFO 主导）

```
1. 营收对账
   - 实际 vs 精细务实版计划
   - 偏差 > 10% → 找原因
   - 偏差 > 30% → 调整模型参数

2. 成本对账
   - 实际 vs 预算
   - 超支项必须有解释
   - 持续超支 → 削减下月预算

3. 现金对账
   - 实际余额 vs 计划余额
   - 跑道是否充足
   - 是否需要提前融资
```

#### 业务对账（COO 主导）

```
1. 用户增长
   - 实际新增 vs 精细版计划
   - 来源分析（口碑/地推/反向邀请）
   - 流失原因分析

2. 漏斗
   - 每一步转化率 vs 目标
   - 找瓶颈步骤
   - 产品/运营改进

3. 100 家健康度
   - 分层变化
   - 流失/回流故事
   - CEO 拜访效果
```

## 八、常见偏差与应对

### 偏差 1：月营收低于计划 20%

```
可能原因：
  - 流量费付费率低（最常见）
  - 新增卖家不达预期
  - 老卖家流失加速

应对：
  立即：客户成功加大触达，CEO 亲电 A 类
  短期：流量费产品迭代（价格/价值组合）
  中期：调整精细版参数
  长期：评估是否进入压力测试预案
```

### 偏差 2：月流失率超过 2%

```
可能原因：
  - 双引擎产品体验差
  - 客户成功不到位
  - 区域竞争激烈

应对：
  立即：CEO 拜访流失商家了解原因
  短期：产品紧急迭代
  中期：客户成功流程改进
  长期：考虑战略调整
```

### 偏差 3：成本超预算 30%

```
可能原因：
  - 团队扩张过快
  - 市场地推超支
  - AI 服务成本超出

应对：
  立即：暂停非必要招聘
  短期：地推预算重新评估
  中期：AI 服务降级/换厂商
  长期：精益化重新设计
```

### 偏差 4：现金跑道 < 4 个月

```
🚨 紫色预警

立即：
  - CEO 亲自接触投资人
  - 团队冻结扩招
  - 砍掉所有非必要支出

短期：
  - Pre-A 接受较低估值
  - 接受老股东加投
  - 考虑桥贷

中期：
  - 战略调整
  - 业务方向 pivot
  - 极端情况下被战投
```
