# 反向邀请激励财务测算模型

## 一、模型说明

本模型用于测算"卖家邀请买家"激励机制的 ROI、CAC、LTV，建议在 Excel 中建表，分三个区域：**假设区、计算区、敏感性分析区**。

## 二、假设区（可改参数）

| 字段 | 单元格 | 值 | 说明 |
|------|-------|----|------|
| 邀请激活卖家数 | B2 | 200 | 参与邀请的活跃卖家数 |
| 单卖家月均发出邀请数 | B3 | 5 | 卖家每月对外邀请数 |
| M1 注册转化率 | B4 | 25% | 邀请 → 注册认证 |
| M2 首发需求转化率 | B5 | 60% | 注册 → 7 日发需求 |
| M3 有效互动转化率 | B6 | 50% | 发需求 → 有效互动 |
| M4 首单成交转化率 | B7 | 25% | 互动 → 首单成交 |
| M5 月活留存率 | B8 | 70% | 成交后次月活跃 |
| 反作弊命中率 | B9 | 8% | 作废比例 |
| 单买家月均 GMV | B10 | 500000 | 元 |
| 平台 take rate | B11 | 0.5% | 含流量费+服务费 |

## 三、计算区（公式）

| 字段 | 公式 | 示例值 |
|------|-----|------|
| 月发出邀请总数 | =B2*B3 | 1000 |
| M1 注册数（毛） | =D25*B4 | 250 |
| 反作弊作废数 | =D26*B9 | 20 |
| M1 注册数（净） | =D26-D27 | 230 |
| M2 发需求数 | =D28*B5 | 138 |
| M3 有效互动数 | =D29*B6 | 69 |
| M4 首单成交数 | =D30*B7 | 17.25 |
| M5 次月活跃数 | =D31*B8 | 12.08 |

### 成本测算

| 字段 | 公式 | 示例值 |
|------|-----|------|
| M1 奖励成本 | =D28*B14 + D28*B20 | 18,400 |
| M2 奖励成本 | =D29*B15 + D29*B21 | 11,040 |
| M3 奖励成本 | =D30*B16 | 6,900 |
| M4 奖励成本 | =D31*B17 + D31*B22 | 8,625 |
| M5 奖励成本（总） | =D32*B18*B19 | 7,245 |
| **月度总激励成本** | =SUM(...) | **52,210** |

### 收益测算

| 字段 | 公式 | 示例值 |
|------|-----|------|
| 新成交买家月度 GMV | =D31*B10 | 8,625,000 |
| 平台月新增收入 | =D39*B11 | 43,125 |
| 单买家 LTV | =B10*B11*B12 | 30,000 |
| M4 总 LTV | =D31*D41 | 517,500 |
| **ROI（LTV/CAC）** | =D42/D38 | **9.91** |
| CAC（成本/M4 买家） | =D38/D31 | 3,026 |
| CAC / LTV | =D44/D41 | 10.1% |
| 回本周期（月） | =D44/(D40/D31) | 14 |

## 四、关键洞察

按上述假设：
- **每月投入 ¥5.2 万激励，能拉来 17 个 M4 优质成交买家**
- **每个买家 CAC = ¥3026，LTV = ¥30000**
- **LTV/CAC = 9.9，CAC/LTV = 10.1%（健康标准是 <30%）**
- **回本周期 14 个月**，累计 12 个月 ROI 显著为正

## 六、风险与对冲

| 风险 | 数值影响 | 对冲 |
|------|---------|------|
| 反作弊命中过高（>20%） | 实际净注册降 15% | 升级风控引擎 |
| M4 成交率不达 25% | LTV/CAC 跌至 5 以下 | 配套悬赏找货+流量曝光 |
| 单买家 LTV 高估 | ROI 减半 | 第 3 个月按真实 LTV 校准 |
| 留存月数<12 | 整体 LTV 跌穿 | 用月卡/年卡锁定留存 |

## 七、月度财务预算（M0-M12）

| 月份 | 激励成本 | 平台新增月收入 | 累计买家 LTV | 净现值 |
|------|---------|------------|--------------|--------|
| M1 | 26,100 | 7,200 | 86,250 | +60,150 |
| M3 | 52,210 | 43,125 | 517,500 | +465,290 |
| M6 | 78,300 | 129,375 | 1,552,500 | +1,474,200 |
| M12 | 130,500 | 388,125 | 4,657,500 | +4,527,000 |

**结论**：这套激励模型 12 个月累计 ROI > 30 倍，强烈建议立即上线。

## 八、激励规则配套设计

### 5 级里程碑

| 里程碑 | 判定 | 卖家奖励 | 买家奖励 |
|--------|------|---------|---------|
| M1 注册 | 营业执照认证 | 30 元券 | 50 元运费券 |
| M2 首发需求 | 7 天内首次询盘 | 50 元券 | 30 元积分 |
| M3 有效互动 | 14 天内有效沟通≥3 次 | 100 元券 | / |
| M4 首单成交 | 30 天内≥5 万元 | 300 元现金 | 200 元券 |
| M5 月活买家 | 次月仍活跃 | 200 元/月×3 | 优质买家认证 |

### 反作弊规则（结算前必跑）

```
R1: 邀请人和被邀请人同一手机号根、同设备 ID、同 IP 24h、营业执照法人/股东重叠 → 关系作废
R2: 被邀请人 7 日内仅有"邀请关系激活"动作 → 作废
R3: 高速激活异常（注册→成交全部在 1 小时内完成） → 作废
R4: 单卖家邀请买家 >60% 只与该卖家沟通 → 标记"过度自循环"，激励减半，超 80% 停止激励
```

### 提现风控

```
单次提现 >¥1000：人工审核
单月累计提现 >¥5000：人工审核
单月累计提现 >¥10000：财务+风控双审

提现到账户必须与营业执照法人匹配
```

## 九、配套工具

1. **卖家后台"我的邀请"看板**：邀请数、转化数、奖励金额、提现入口
2. **每个卖家专属邀请二维码 + 邀请短链**
3. **专属落地页**（"XX 公司李总邀请你加入货袋子"）
4. **周/月度排行榜**（铁圈吃面子，比奖金更管用）

## 十、关键指标监控

| 指标 | 目标 |
|------|------|
| 邀请发起率（活跃卖家发起邀请的占比） | ≥ 40% |
| 邀请-注册转化率 | ≥ 25% |
| 注册-M4 成交转化率 | ≥ 10% |
| 单卖家月均邀请有效买家数 | ≥ 1.5 |
| 反作弊命中率 | <8%（高了说明拉新质量低） |
